# 影院域原型 · 三风格 × 午夜场完整功能版

> 通用规则见 `docs/prototype-first.md`；本文件只记影院域的落地形态与特例。

## 形态

`prototype.html` = 评审壳（core 四链 + 本域 `styles.css`，组件样式零内联），内含三个风格区块。
**午夜场为完整功能版**（探索稿 p1 的全部页面与弹窗实现），场刊/放映室为主列表静态版：

| 风格 | id | 信息架构 | 状态 |
|---|---|---|---|
| 午夜场 | `midnight` | 左栏 + 海报网格（900×620） | **完整功能版**（黑金，亮默认） |
| 场刊 | `gazette` | 报头 + 特稿/排片双栏 | 主列表静态 |
| 放映室 | `booth` | 场记板 + 胶片帧列表 | 主列表静态（暗厅默认氛围） |

桌面 900×620 与移动 396×780 两端并存；壳顶栏切风格/亮暗/还原数据，URL `?style=…&theme=…`。

## 午夜场功能清单（与插件 ui.ts 功能面对齐）

- 主列表：分类树（类型+状态，rail-foot 视图入口）、主头行（筛选名+计数+添加）、搜索（名称/导演/主演/影评）、
  三档排序、网格（状态角标/星轨/未评分态/列数设置生效）、空态（清空筛选）、移动 chips + 搜索 + 工具钮。
- 详情弹窗：海报+片名+类型/状态 chip+星+评分+日期+影评+「豆瓣信息」kv+豆瓣链接+简介+找同类/编辑/删除。
- 添加/编辑表单：名称（必填/重名校验 toast）、类型 choice（14 tag 组色点）、状态 choice、
  评分滑杆+读数（仅已看显示）、影评（仅已看显示，非已看不保存）、保存→写库+toast。
- 右键菜单（桌面）/长按抽屉（移动，含海报头）：打开详情/标记在看/标记已看（按状态显隐，流转刷观影日期）/
  找同类/在豆瓣打开/编辑/删除。
- 删除确认：三段式（警示图标+标题+问句+回收站语义说明）。
- AI 荐片页：待机（偏好行+开始+模拟失败）→ 等待（spinner）→ 结果卡（片名+豆瓣搜链+meta+推荐理由+加入想看/已在库中禁用）+换一批；失败态+重试。
- 观影分析页：19 板块全量（ADR-0090 对齐 analysis.ts）：类型分布/年度趋势/片龄/片长（无数据空态）/
  月度分布/观影节奏/评分分布/评分趋势/打分习惯（宝藏·失望榜）/题材·国家·导演·主演 TOP10/真爱重复/
  影评关键词/高分 TOP10/系列追踪/追剧深度/想看清单——全部从 50 部真实数据即时统计。
- 设置弹窗：默认排序/默认状态筛选/网格列数（2-12，即时生效）/移动默认全屏开关/影视文件夹（只读）。
- toast、Esc/遮罩关闭、数据增删改 localStorage 持久化（顶栏「还原数据」一键复位）。

## 结构约定（落域契约）

- 桌面面板根：`.bz-cinema--<style>`；移动面板根：`.mob.bz-cinema--<style>`；
  内部类名保留探索稿原样，规则一律 scoped 在风格锚类下。
- 午夜场弹窗/子页面类：`.cn-ovl/.cn-modal/.dm-*/.f-*/.cn-menu/.cn-sheet*/.cn-confirm/.sp-*/.ai-*/.rec-*/.sec/.bar-*/.soft-*/.cn-toast`（均为 .bz-cinema--midnight scoped）。
- 清单唯一事实源：壳演示 JS 里的 `CINEMA_STYLES`，落域时上岸 `constants.ts`，
  设置键 `cinemaStyle`（默认 midnight）/ 挂类 / 测试全读它。

## 域内特例与已知事项

- **移动端 DOM 独立**：三风格移动形态是探索稿同款独立自绘 DOM（.mob 自带 396×780 框）。
- **放映室不随亮暗主题翻转**：变量组方向反转（本体=碳黑暗组，`.theme-light` 回退牛皮纸组）。
- **壳层同页适配（不改视觉值）**：探索稿元素 id 改 `j-*` 类挂钩；亮暗跟 body；
  AI 结果卡绑定在 `aiBind` 内、依赖 `midnightRefresh` 调用链。
- **午夜场弹窗/子页面坑**：分析页条形填充 `.bar-fill/.soft-fill` 必须显式 `display:block`
  （span 默认 inline 宽高无效）；AI/分析视图无 `.j-add`，`midnightRefresh` 内按钮绑定须判空。
- `prototype-data.js`：真实 vault 导出 50 部（有海报者），海报为 vault 绝对 `file://` 路径；
  重新导出用 `.zcode/ui-prototypes/fetch-movie-data.js` 后按其头部注释转换 poster 字段。
- 已知演示偏差（落域走真实现）：AI 结果与理由为 mock 池；「加入先后」排序=导出序；
  分析页片长板块空态（frontmatter 无时长字段）。
- 未入选风格（策展厅 / 年报大屏）原型留在 `.zcode/ui-prototypes/cinema-5/` 备查。
