## Install

The video uses a one-click script; manual works too.

1. Download `bz-<version>.zip` from [Releases](https://github.com/yeshimei/bz/releases)
2. Extract it into `<your vault>/.obsidian/plugins/` so you end up with a `bz/` folder
3. Restart Obsidian → Settings → Community plugins → find **bz** → enable

To upgrade, overwrite the extracted files and restart. You can also use BRAT: install BRAT, then *Add Beta Plugin* with this repository.

## Offline assets

Skins, tool packs, the manual and the cinema index are normally fetched from GitHub / jsDelivr. Behind a corporate proxy, with no route to the CDN, the download button in the plugin just spins — use `bz-offline-<version>.zip` from the same release page.

Extract it and drop the resulting `downloads/` folder into the plugin directory:

```text
.obsidian/plugins/bz/
├── main.js
├── manifest.json
├── styles.css
└── downloads/
    ├── manifest.json
    ├── skins/
    └── tools/
```

Then hit download again — a local copy that passes the sha256 check is used as-is, no network. The pack must match your plugin version; an old one fails the check and silently falls back to the network. The plugin itself is not in this pack, so upgrades still mean overwriting those three files. If you have an internal static server, point 设置 → 通用 → 在线资源 → 镜像源 at it instead.
