# 包仔（bz）

**包仔**是一个一站式 Obsidian 个人信息管理插件：写日记、管待办、追剧观影、读书复习、专注计时……把日常记录与生活管理装进一个笔记库里，页角还住着一只桌宠猫「小橘」。

- **20 个功能域**，全部从「主页」磁贴一键进入
- **桌面端 + 移动端**通用（要求 Obsidian ≥ 1.4.0）
- **数据全在你自己的笔记库里**，除你主动配置的 AI 服务外，什么都不上传
- **老数据零迁移**，装上就能接着用

## 快速上手

1. 在 设置 → 第三方插件 中启用「包仔」。
2. `Ctrl/Cmd + P` 打开命令面板，输入「主页」回车——所有功能都在这块磁贴墙里。
3. 单击磁贴打开对应功能；**长按磁贴**进入编辑模式：拖动排序、调整大小、增删磁贴，还能把其他插件的命令也钉上来。
4. 每个功能窗口右上角都有 **⚙️ 按钮**，打开该功能自己的设置；全局设置在 设置 → 包仔。

# 功能域一览

## 🏠 入口

### 主页

所有功能的入口，一面可自由布置的磁贴墙。

- 单击磁贴即打开对应功能；磁贴可以拖动排序、调整大小（最大 2×2）、随意增删
- 不只包仔自己的功能——其他插件的命令也能做成磁贴上墙
- 支持手势唤起：双击 / 三击 / 下滑打开主页，桌面与移动端可分别设置
- 失效磁贴（所属插件被禁用等）会灰显保留，恢复后自动复活

## ✍️ 记录生活

### 日记本

写日记、翻日记的地方。

- 一天可写多条日记，每条以「表情 + 时间」开头，滚动滚轮即可切换日期
- 自定义标签体系（主标签 + 二级标签），按标签筛选浏览
- 选中其他笔记的文本，一键存为「摘抄」写入日记，并留下可跳转的引用链接
- 单条日记可加密隐藏，不输密码看不到内容
- 看过的影视、收到的信也会自动汇入当天的日记流

### 备忘录

待办事项清单。

- 场景分类（剪藏 / 工作 / 学习 / 生活……）、优先级、多种排序与归档
- 有重要或到期的备忘时，启动 Obsidian 或打开相关笔记会自动弹窗提醒
- 新保存的网页剪藏若对应某条待读备忘，会自动关联并把备忘标记完成

### 归物本

个人物品登记册。

- 记录每件物品的名称、分类、价格、购买日期
- 跟踪状态流转：使用中 → 闲置 → 已转卖 / 已丢弃

### 收藏本

链接收藏夹。

- 内置 GitHub 🐙 / 桌面软件 💻 / 网站 🌐 / 大模型 🧠 等 9 类标签
- 添加收藏时点「✨ AI 整理」，自动补全标题、简介和分类；GitHub 链接还会自动抓取仓库信息
- 大模型条目可直接查询 API 余额
- 收藏可以关联到笔记，笔记改名或移动后关联自动跟随

## 📖 阅读与观影

### 剪藏本

集中阅读你存进笔记库的网页剪藏文章（比如用浏览器剪藏扩展保存的内容）。

- 搜索、按来源站点过滤、多种排序
- 显示哪些笔记引用了这篇文章，点击即可跳转
- 桌面单击整卡直接打开原文；移动端长按弹出操作菜单（打开 / 复制双链 / 复制原文链接 / 删除）

### 聚合讯

资讯阅读流。

- 订阅源内容定时入库（目前支持果壳科学人、知乎日报），像刷信息流一样阅读
- 读到喜欢的文章，一键保存成剪藏笔记留档
- 需配合可选的资讯抓取小工具（见下文「可选的外部工具」）

### 书库

书架式读书管理。

- Markdown 书目笔记与 EPUB 电子书并列上架，统一浏览
- 读书笔记按书目归档成树，随时回顾
- EPUB 的划线与想法按章节分组展示，点击可深链跳回书中原位置，想法还能直接修改

### 阅读分析报告

基于整个笔记库阅读数据的统计报告。

- 年度阅读统计、阅读热力图、阅读习惯分析
- EPUB 电子书的阅读数据一并计入

### 影视

观影记录管理。

- 想看 / 在看 / 已看三态管理，星级评分、观影日期
- 配合可选的豆瓣抓取工具，新片条目自动补全豆瓣信息与高清海报

### 影视分析报告

你的观影数据，一张图看透。

- 类型分布、年度与月度趋势、片龄 / 片长画像
- 你的评分对比豆瓣评分：宝藏片榜 & 失望榜
- 最爱导演与主演、系列电影追踪、追剧深度分析

## 🎯 学习与专注

### 复习计划

间隔重复算法驱动的笔记复习，对抗遗忘。

- 任意笔记一键加入复习计划；指定「监听文件夹」后，目录里的新笔记自动收编
- 到期弹窗提醒，文件树里给逾期笔记染色标记
- 每轮复习篇数上限、复习间隔缩放均可调
- 可选用「做题测难度」：AI 根据笔记出题（含多选题），按答题表现安排下次复习时机

### 番茄钟

番茄工作法专注计时。

- 中央大弹窗倒计时 + 状态栏迷你计时双形态
- 11 个科学预设 + 完全自定义时长，专注 / 短休息 / 长休息自动循环
- 强制专注模式：专注中禁止暂停和跳过
- 窗口被遮挡或最小化时自动暂停，回来接着计
- 关机重启不补算时间，历史记录真实可信

### 第二大脑

你的笔记向量库总管，让写作时相关的旧笔记自己浮现。

- 主面板：向量库规模、来源分布、增长趋势一目了然，一键 AI 概括全库近况
- 屏幕右侧速记窄窗：自动吸附缩起、悬停展开，随手记不打断写作
- 写作时自动检索库内相关笔记，浮现在侧边供你参考（本地语义检索，需本机运行 Ollama；未安装则退回普通关键词检索）
- 「AI 对话」：让 AI 引用你的笔记来回答问题

### 自动摘要

后台常驻的剪藏小秘书。

- 开启后自动监听剪藏目录，新剪藏落盘即生成 AI 摘要与标签
- 全程无感，没有独立窗口，设置里开关即可

## 🔒 安全

### 密码本

加密存储的密码管理器。

- 密码加密存储，主密码不上传、不留存、无法找回
- 内置随机密码生成器，长度与字符集随心调
- 安全模式：关闭窗口立即自动上锁

### 保险箱

真·加密，把整篇笔记连附件一起藏起来。

- 加密时笔记连同它引用的图片 / 视频一起移出笔记库，原位置直接消失
- 密文存放于侧栏看不见的隐藏目录，防误删防窥探
- 解锁后原样还原回原位，「借出来用」
- 图片 / 视频密文自带压缩预览，看得清又不占流量
- 安全模式下关闭面板即自动上锁

## 🧰 工具

### 附件搬移

一条命令整理当前笔记的附件。

- 把当前笔记引用的全部图片、音视频等附件搬到指定文件夹
- 全库指向它们的链接自动更新，不用手动改
- 目标文件夹有同名文件时自动加序号，不会覆盖

### B站下载器

本地网页版的 B 站视频下载工具（仅桌面端）。

- 输入链接即可解析封面、标题与清晰度并下载
- 支持多段剪辑、合并、压缩，字幕还能转成文字稿
- 插件命令负责唤起它，实际操作都在它自己的网页里完成
- 工具本体需单独安装运行（见「可选的外部工具」）

## 🐱 陪伴

### 小橘

住在页角的桌宠猫。

- CSS 绘制的猫咪悬浮在编辑器角落，13 种皮肤任选，可拖动、可隐藏
- 它有自己的心情起伏和性格成长，会观察你写了日记、读完书、看完电影，时不时嘟囔两句
- 双击它开始聊天——聊的是你的笔记生活，因为它记得你记过什么
- 长按打开它的设置；「小橘数据面板」可以查看它的记忆、心情和你们相处的时间线

## 关于 AI 功能

在 **设置 → 包仔** 顶部选择 AI 服务商并填入 API Key 即可启用 AI 能力。用到 AI 的地方：

- 自动摘要、第二大脑 AI 对话与概括、小橘聊天与自言自语
- 收藏本的「✨ AI 整理」、复习计划的做题出题

**不配置 AI 也完全不影响使用**，只是上述功能不可用或降级运行。「第二大脑」的语义检索需要在本机运行 [Ollama](https://ollama.com)，没装也会自动退回普通检索。

## 数据与隐私

所有数据都保存在你自己的笔记库内，备份整个笔记库就备份了一切。除你主动填写的 AI 服务外，任何数据都不会离开你的设备。

> ⚠️ **主密码无法找回**：密码本、保险箱、加密日记共用同一把主密码。它不存储在任何地方，遗忘意味着对应密文永久无法恢复，请务必牢记。

## 移动端

手机和平板上功能完整可用。每个主窗口在自己的 ⚙️ 设置里有「**移动端默认全屏**」开关：开启后窗口铺满全屏，关闭则为居中卡片，可逐个功能调整。主页手势同样支持移动端，可单独配置。

## 安装

要求 **Obsidian ≥ 1.4.0**，桌面端与移动端均可。

- **手动安装**：下载 `main.js`、`manifest.json`、`styles.css` 三个文件，放入 `<你的库>/.obsidian/plugins/bz/`，重启 Obsidian 后启用「包仔」。（本仓库根目录自带最新构建产物，直接下载即可）
- **BRAT 安装**：安装 BRAT 插件后，用 *Add Beta Plugin* 填入本仓库地址。

## 可选的外部工具

以下能力依赖独立运行的辅助小程序，均为可选。**不安装它们，插件其余功能完全不受影响**：

| 工具 | 作用 |
|---|---|
| 豆瓣信息抓取 | 后台守护进程，为影视笔记自动补全豆瓣信息与高清海报 |
| 资讯抓取 | 定时抓取果壳科学人、知乎日报，供「聚合讯」阅读 |
| B站下载器 | 本地网页版 B 站视频下载工具，「B站下载器」命令负责打开它 |

安装与运行方法见仓库 `tools/` 目录下各自的说明文档。

## 常见问题

**旧数据需要迁移吗？**
不需要。数据格式完全沿用，装上插件即无缝接管旧数据。

**忘记主密码了怎么办？**
无法找回，这是真加密的代价。重设主密码会生成全新空清单，旧密文永久无法恢复。

**不想用任何 AI 功能可以吗？**
可以。AI 只影响自动摘要、第二大脑对话与概括、小橘聊天、AI 整理、做题出题这几处，其余全部功能照常工作。

**为什么有些窗口在手机上是全屏、有些是卡片？**
这是「移动端默认全屏」设置决定的，可在各功能的 ⚙️ 设置里逐个调整。
