# 包仔（bz）

**包仔**是一个一站式 Obsidian 个人信息管理插件：写日记、管备忘、读书观影、订阅资讯、复习专注、密码加密……把日常记录与生活管理装进一个笔记库里，页角还住着一只桌宠猫「小橘」。

- **21 个功能域**，全部从「内容首页」一键进入
- **桌面端 + 移动端**通用（要求 Obsidian ≥ 1.4.0）
- **数据全在你自己的笔记库里**，除你主动配置的 AI 服务外，什么都不上传
- **老数据零迁移**，装上就能接着用

## 快速上手

1. 在 设置 → 第三方插件 中启用「包仔」。
2. `Ctrl/Cmd + P` 打开命令面板，输入「内容首页」回车——所有功能都从这块首页进入。
3. 左侧栏 Ribbon 常驻「备忘录」「日记本」两个快捷图标；每个功能也有自己的命令，可在设置里指定快捷键。
4. 每个功能窗口右上角的 **⚙️ 按钮**会打开统一的**设置面板**并直达该功能的设置组；全局设置（AI、目录等）在 设置 → 包仔。

# 功能域一览

## 🏠 入口

### 内容首页

所有功能的入口。

- 顶部问候与周历，中间是各功能的入口（桌面为入口行，移动端为两列瓦片），单击直达对应功能
- 「活动河」时间线聚合近七天的记录动态，周历可切天回看；还有即将到期事项的预告
- 移动端带统计条，一屏看全当天概况
- 入口的顺序与显隐可以在 设置面板 → 首页 → 入口 里拖动调整，不要的入口可以移除、随时加回

### 今日回顾

一键回看今天都留下了什么痕迹。

- 把当天日记、影院观影、书库阅读、备忘录、番茄钟专注五类动静聚成一条时间轴
- 「生成今日总结」让 AI 把今天写成一段话，写进当天的日记；已生成可重新生成替换
- 面板全程只读，不会改动任何数据

### 设置面板

全部功能设置的聚合窗口。

- 每个功能域一个设置组，从各功能窗口的 ⚙️ 直达对应位置
- 「通用」组里有**数据体检**入口等全局动作
- 移动端全屏、外观等跨域设置也在这里统一管理

### 数据体检

给整个插件的数据做一次只读体检。

- 四类检查：JSON 文件是否可解析、数据字段是否漂移、引用是否失效（孤儿条目）、同源数据是否一致
- 部分问题（剪藏残留、收藏失效关联等）支持**一键修复**，且带撤销
- 只读巡检不动原数据，结果缓存，重开面板还能看到上一次结果

## ✍️ 记录生活

### 日记本

写日记、翻日记的地方——一座按月份章节陈列的媒体回忆墙。

- 真实图片 / 视频 / 音频瀑布流，按日期分节；左侧章节栏按年月分组，滚动自动高亮、点击定位
- 全屏灯箱看图、播视频、听音频，支持左右连看；加密条目的媒体同样受保护
- 类型标签（主标签 + 二级标签）胶囊筛选，带计数；「那年今天」横滑条带你回到同一天
- 写日记：一天可写多条，每条以「表情 + 时间」开头；支持从其他笔记选中文本一键存为「摘抄」并留下可跳转的引用
- 条目级加密：把分类改为「加密」，整条日记连同图片视频一起移入保险库，不输主密码完全不可见
- 看过的影视、收到的信、书库的阅读痕迹也会自动汇入对应日期的流里

### 备忘录

待办事项清单，一面场景工作台。

- 左侧场景栏（全部 / 今日 / 重要 / 自定义场景），条目支持优先级、截止日期、关联笔记、搜索与多种排序
- 行内勾选完成；桌面右键、移动端长按弹出操作菜单
- 有重要或到期的备忘时，启动 Obsidian 或打开关联笔记会自动弹窗提醒
- 记剪藏场景的备忘时粘贴链接，自动抓取页面标题预填
- 「专注这个」一键联动番茄钟，计时归属直接记到这条备忘名下
- 笔记改名或删除后，备忘录里的关联自动跟着维护

### 归物本

个人物品登记册，一张「瑞士大字报」风格的大字网格。

- 大字卡片记录名称、分类、价格、购买日期，带编号与状态徽章
- 状态流转：使用中 → 闲置 → 已转卖 / 已丢弃；转卖可记售价、出离可记日期
- 头部 KPI 一眼看清：在库件数、在库投入、日均成本、已离场；下方年度时间轴逐件回顾
- 分类图标联想补全，也可 ✨ AI 归类；流转与删除都可撤销

## 📖 阅读与观影

### 剪藏本

集中阅读你存进笔记库的网页剪藏，外加一条订阅未读流。

- 左侧点线索引：全部未读、各来源站点（知乎日报、果壳科学人、RSS 订阅源、B站 UP 投稿）、剪藏本归档
- 打开即已读，但会话内目录不重排；已读 / 已收分两段折叠收纳，干净不吵
- 阅读面用 Obsidian 原生渲染，表格代码块全保真；读到喜欢的文章一键保存成剪藏笔记留档
- B站视频条目保存时直接转入知识盒的视频文献任务
- 数据源开关、UP 主名单、RSS 订阅源管理、过期保留策略都在本功能设置里（抓取需配合外部工具，见下文）
- 移动端目录化浏览，长按弹出操作菜单

### 书库

书架式读书管理——一堵会长大的书脊墙。

- Markdown 书目与 EPUB 电子书并列上架；书脊高度 = 阅读时长、厚度 = 字数，按题材分区装箱
- 已读盖「讫」印、在读抽带、未读倒扣灰置，检索 / 排序 / 分类签行筛选一应俱全
- 五套面板皮肤 × 明暗两档，共十种外观
- 借书卡（纸卡 + 印章）承载全部书目编辑；读书笔记按书目归档成树
- EPUB 的划线与想法按章节分组展示，双击深链跳回书中原位置，想法还能直接修改
- 「继续在读」命令直达最近在读的那本

### 阅读分析报告

基于整个笔记库阅读数据的统计报告，内嵌在书库面板里。

- 年度阅读统计、阅读热力图、阅读习惯分析、时段与分类分布
- EPUB 电子书的阅读数据一并计入
- 报告里点作者或分类，直接回到书架并预填筛选

### 影院

观影记录管理，午夜场风格。

- 想看 / 在看 / 已看三态管理，星级评分、观影日期、影评
- 新片条目自动补全豆瓣信息与高清海报（需可选外部工具，仅桌面端）
- ✨ AI 荐片按你的口味推片；详情页「找同类」以任意一部为基准找相似
- 「随机抽一部」解决片荒选择困难
- 影视分析报告内嵌面板：类型分布、年度月度趋势、你的评分对比豆瓣、最爱导演主演、追剧深度分析
- 看过的影视自动汇入当天日记

## 🗂 收集与知识

### 收藏本

链接收藏夹。

- 内置 9 类标签（GitHub、桌面软件、网站、大模型、pi、Claude、skills、酒馆、DeepSeek Harness），可多选
- 添加收藏时点「✨ AI 整理」自动补全标题、简介和分类；GitHub 链接自动抓取真实仓库信息
- 大模型条目可直接查询 API 余额
- 置顶、关联笔记（改名自动跟随）、归档冷存与「已归档」视图，删除可撤销

### 第二大脑

你的笔记向量库总管，让写作时相关的旧笔记自己浮现。

- 主面板：向量库规模、来源分布、增长趋势、存储占用一目了然
- 写作时右侧速记 / 参考窄窗自动吸附，检索到的相关笔记浮现在侧边供你参考
- 「AI 对话」让 AI 引用你的笔记来回答问题
- 自动双链：指定范围内的笔记由本地语义检索 + AI 裁判自动建立 `related` 关联，Obsidian 图谱原生可见；存量笔记启动时自动补链，正文大改后自动重跑
- 语义检索需本机运行 [Ollama](https://ollama.com)（移动端可连局域网内的桌面 Ollama），没装则自动退回关键词检索

### 知识盒

把视频和术语炼成文献笔记的枢纽，分文献 / 卡片 / 主题三部。

- **术语录入**：输入一个术语，AI 生成一段百科式简介，预览确认后写入文献笔记
- **视频录入**：粘贴 B站链接进任务队列，自动下载转文字（需可选外部工具），AI 生成带视频嵌入的文献笔记；支持批量与历史回看
- 文献目录词典式列表 + 只读预览；「提炼成卡」把文献浓缩进卡片盒，铁律是连一张旧卡 + 写一句为什么
- 卡片与源文献自动互相链接（Obsidian 原生双链），主题笔记一览陈列

## 🎯 学习与专注

### 复习计划

间隔重复算法驱动的笔记复习，对抗遗忘。

- FSRS v4 调度，并按你的复习历史拟合个人记忆参数，越用越懂你
- 任意笔记一键加入；指定「监听文件夹」后，目录里的新笔记自动收编
- 面板三区队列（已逾期 / 今天到期 / 未来），「开始本轮」把到期笔记批量送进复习冲刺
- 可选用「做题测难度」：AI 根据笔记出题（含多选题），答对自动进下一题，忘了或答错自动安排待重做
- 到期聚合通知带「去复习」按钮直达；文件树里给逾期笔记染色标记
- 统计弹窗：连续天数、评级分布、复习负载日历热力图；另有置顶、随机抽查、归档与复习分析报告

### 番茄钟

番茄工作法专注计时。

- 中央大弹窗倒计时 + 状态栏迷你计时双形态，关掉弹窗计时照走
- 11 个科学预设 + 完全自定义时长，专注 / 短休息 / 长休息自动循环
- 强制专注模式：专注中禁止暂停和跳过；窗口被遮挡或最小化时自动暂停，回来接着计
- 关机重启不补算时间，历史记录真实可信
- 今日专注统计、近 7 天柱状图、时段分布一眼可见

## 🔒 安全

### 保险库

真·加密，把整篇笔记连附件一起藏起来。

- 加密时笔记连同它引用的图片 / 视频一起移出笔记库，原位置直接消失
- 密文存放于侧栏看不见的隐藏目录，防误删防窥探；解锁后原样还原回原位，「借出来用」
- 图片 / 视频密文自带压缩预览，看得清又不占流量
- 日记条目级加密也走这里：加密日记在解锁前完全不可见
- 安全模式下关闭面板即自动上锁；内置体检可清理异常残留密文

### 密码本

加密存储的密码管理器。

- 三栏工作台：平台聚合导航、账号卡片、详情查看，一键复制
- 内置随机密码生成器，长度与字符集随心调；「快速生成」「快速复制」命令不开面板直取，剪贴板 60 秒自动清空
- 安全模式：关闭窗口立即自动上锁
- 与保险库**共锁同库**：一把主密码管到底

## 🧰 工具

### 自动摘要

后台常驻的剪藏小秘书。

- 开启后自动监听剪藏目录，新剪藏落盘即生成 AI 摘要与标签写回 frontmatter
- 摘要长度三档、标签开关与数量、立即 / 懒触发时机均可调
- 命令「重新生成当前剪藏摘要」可对当前笔记重跑
- 全程无感，没有独立窗口，设置里开关即可

### 附件搬移

一条命令整理当前笔记的附件。

- 把当前笔记引用的全部图片、音视频等附件搬到指定文件夹，执行前可预览勾选
- 全库指向它们的链接由 Obsidian 自动更新，不用手动改
- 目标文件夹有同名文件时自动加序号，不会覆盖；搬完还能一键撤销

## 🐱 陪伴

### 小橘

住在页角的桌宠猫。

- CSS 绘制的猫咪悬浮在编辑器角落，13 种皮肤任选，可拖动、可隐藏
- 双击它开始聊天，长按打开设置——聊的是你的笔记生活，因为它记得你记过什么
- 它有自己的心情起伏和人格成长：会观察你写了日记、读完书、看完电影，时不时嘟囔两句，偶尔主动关心你
- 指定「记忆目录」后，文件夹里的笔记会成为它的长期记忆，日记还会按时间段拆成一条条
- 「小橘数据面板」可以查看它的记忆、心情、你们相处的时间线和每周报告

## 关于 AI 功能

在 **设置 → 包仔** 顶部选择 AI 服务商（主流云服务商与 OpenAI 兼容端点均可）并填入 API Key 即可启用 AI 能力。用到 AI 的地方：

- 自动摘要、收藏本的「✨ AI 整理」、影院的 AI 荐片与找同类
- 复习计划的做题出题、知识盒的文献生成
- 第二大脑的 AI 对话、库概括与自动双链裁判
- 今日回顾的总结、小橘的聊天与自言自语

**不配置 AI 也完全不影响使用**，只是上述功能不可用或降级运行。「第二大脑」的语义检索需要在本机运行 [Ollama](https://ollama.com)，没装也会自动退回普通检索。

## 数据与隐私

所有数据都保存在你自己的笔记库内，备份整个笔记库就备份了一切。除你主动填写的 AI 服务外，任何数据都不会离开你的设备。

> ⚠️ **主密码无法找回**：密码本、保险库、加密日记共用同一把主密码。它不存储在任何地方，遗忘意味着对应密文永久无法恢复，请务必牢记。

## 移动端

手机和平板上功能完整可用。每个主窗口在自己的 ⚙️ 设置里有「**移动端默认全屏**」开关：开启后窗口铺满全屏，关闭则为居中卡片，可逐个功能调整。

少数依赖本地外部程序的能力仅桌面端可用（影院海报抓取、知识盒视频批量处理），移动端对应设置会置灰标注，不做静默降级。

## 安装

要求 **Obsidian ≥ 1.4.0**，桌面端与移动端均可。

- **手动安装**：下载 `main.js`、`manifest.json`、`styles.css` 三个文件，放入 `<你的库>/.obsidian/plugins/bz/`，重启 Obsidian 后启用「包仔」。（本仓库根目录自带最新构建产物，直接下载即可）
- **BRAT 安装**：安装 BRAT 插件后，用 *Add Beta Plugin* 填入本仓库地址。

## 可选的外部工具

以下能力依赖独立运行的辅助程序，均为可选。**不安装它们，插件其余功能完全不受影响**：

| 工具 | 作用 |
|---|---|
| 豆瓣信息抓取（douban-poster） | 为影院条目自动补全豆瓣信息与高清海报；插件会在桌面端自动调用它 |
| 资讯抓取守护（obsidian-news） | 定时抓取知乎日报、果壳科学人、B站 UP 投稿与 RSS 订阅源，供剪藏本未读流阅读 |
| B站下载器（bili-dl） | 知识盒视频录入的无头批处理：下载视频、转写文字稿，交回插件生成文献笔记 |

安装与运行方法见仓库 `tools/` 目录下各自的说明文档。

## 常见问题

**旧数据需要迁移吗？**
不需要。数据格式完全沿用，装上插件即无缝接管旧数据。

**忘记主密码了怎么办？**
无法找回，这是真加密的代价。重设主密码会生成全新空清单，旧密文永久无法恢复。

**不想用任何 AI 功能可以吗？**
可以。AI 只影响上文列出的那些功能，其余全部功能照常工作。

**为什么有些窗口在手机上是全屏、有些是卡片？**
这是「移动端默认全屏」设置决定的，可在各功能的 ⚙️ 设置里逐个调整。

**为什么剪藏本里没有新资讯？**
未读流依赖外部抓取守护定时入库，确认它已安装并在运行（见「可选的外部工具」）。
