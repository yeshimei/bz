## 安装

1. 到 [Releases](https://github.com/yeshimei/bz/releases) 下载最新的 `bz-<版本>.zip`
2. 解压到 `<你的 vault>/.obsidian/plugins/` 下，得到一个 `bz/` 文件夹
3. 重启 Obsidian → 设置 → 第三方插件 → 找到「bz」→ 启用

## 离线资源包

在线资源（皮肤、工具包、手册、影视索引）下不动时，用 `bz-offline-<版本>.zip`。解压出的 `downloads/` 整个放进插件目录，再回插件点一次下载——本地校验通过就直接用，不联网。

```text
.obsidian/plugins/bz/
├── main.js
├── manifest.json
├── styles.css
└── downloads/
    ├── manifest.json
    ├── skins/
    └── tools/
```

## 开发

包管理用 pnpm：`pnpm install` / `pnpm run dev` / `pnpm run build` / `pnpm test`。想提交代码先看 [CONTRIBUTING.md](CONTRIBUTING.md)；架构约定见 [AGENTS.md](AGENTS.md)，术语表见 [CONTEXT.md](CONTEXT.md)。

`issues/` 是作者内部的问题与设计记录，不是反馈入口。
