# 40 — 黑匣子三类录入弹窗

**What to build:** 录入弹窗（`bz-blackbox-capture`）从「素材+感受」单一形态升级为三类型切换：🧩 概念（AI 生成知识卡片，仅确认是否录入，**无感触外壳**）、📎 文献（摘抄+来源+名词表勾选关联+可带出想法）、💡 想法（核心知识）。情绪标签去掉强度（24 词多选 ≤3）。涉及的人本票暂为文本多选（ticket 41 升级为画像选择器）。

**Blocked by:** 39 — 黑匣子 schema v2 扩展 + v1 数据迁移

**Status:** ready-for-agent

## 验收标准

- [ ] 弹窗顶部三类型胶囊切换（🧩 概念 / 📎 文献 / 💡 想法），切换保留已填内容不丢
- [ ] 概念流程：名词输入 → ✨ 生成 → AI 卡片预览（定义 + AI 自动关联的已有概念名）→ [确认录入] / [重新生成]；概念条目不显示感触外壳；AI 失败可重试、可降级提示
- [ ] 文献流程：摘抄 textarea + 来源输入 → ✨ 分析 → 名词表勾选（AI 建议预勾，可增删）→ 「带出想法？」展开想法输入（同一次保存写入 thought 条目）→ 感触外壳
- [ ] 想法流程：想法 textarea + 可选 AI 辅助（⚡ 联想 / 🔍 查概念 / ❓ 追问，均不打断录入流）→ 感触外壳
- [ ] 感触外壳：情绪 24 词多选 ≤3（无强度 UI）；涉及的人为多标签文本输入（逗号/回车分隔，存 string[]）；场景/指向/链接折叠展开
- [ ] AI 不可用时：三类纯文本录入仍可保存（无 AI 辅助/无卡片生成，toast 提示），黑匣子永不拒收
- [ ] 测试：三类型切换与保存、概念生成流程（mock AI）、名词表勾选、带出想法、情绪 ≤3 校验、去强度后旧 UI 断言更新
