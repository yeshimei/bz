# 50 — 黑匣子录入打磨 + 新概念流转 + 面板标签升级（grilling 2026-08 封板）

**What to build:** grilling 会话（2026-08）确认的六项录入体验打磨 + 一项面板升级：

1. **录入面板大间距**：🧩 概念面板概念名（标题）与定义（正文）之间、📎 摘抄面板摘抄内容/想法框/来源之间，统一大间距（~18px 级，「好看就行」）；💡 想法面板不动。
2. **摘抄想法框手输**：想法输入框从③感触步移到②内容步，插在**摘抄文本与来源之间**（摘抄 → 想法 → 来源 → 📋分析名词）；**不用 AI 提炼**（分析结果 insight 不再自动填入）；想法框空 → 保存只出摘抄笔记（既有规则保留），非空 → 仍创建 thought 条目（`来自：[[摘抄]]`）。
3. **书内来源只读显示书名**：EPUB 选区录入（externalSel）时来源 input 只显示**纯文字书名**（解析 `[[书路径#定位符|书名]]` 别名/路径尾段），readOnly + 锁定样式；**保存的 source 字段仍是完整双链**（保 cfi 定位符，点击跳回书内功能不丢）；笔记选区来源（`[[来源笔记]]`）与 URL 保持可编辑。
4. **删「新建画像」按钮**：全部三类录入流程的「涉及的人」区删除「➕ 新建画像」按钮与 mini 表单（现场新建画像不再可能，只能匹配已有画像 / 仅存名字）；`createProfileWithSeed` 导出保留（主面板人物弹窗仍用）。
5. **新概念流转**（核心）：摘抄名词表勾选 ✦新概念 → 保存摘抄时**不再落空定义概念条目** → 同弹窗依次流转概念录入（概念名预填**可编辑**、来源**继承摘抄来源**、✨生成卡片→✅确认录入）→ 全部完成 → **回填摘抄笔记关联概念**（新概念 id 追加 terms：frontmatter + 正文 `关联概念：` 行）→ 直达模式自动关闭 / 引导模式回类型选择。跳过或关窗 = 该概念不创建、摘抄不加；确认录入时与既有概念**重名** → 提示 + 不新建 + 摘抄直接关联既有概念；流转模式概念保存**跳过原位注入**（摘抄保存时已注入）。
6. **摘抄不分类**：保存后 autoClassify 仅对 concept 调用，文献永远留 `黑匣子/摘抄/` 根目录；概念保留 AI 分类；存量已分类摘抄不迁移（用户已自行处理）。
7. **面板标签升级**：🧩/📎/💡 三标签带数量 `(n)`（各类型条目总数，原始数据统计）；类型筛选改**单选**（点概念只显示概念，再点取消，切文献即切）；点「概念」标签选中 → 展开**子分类行**（概念分类文件夹 `entry.category` 分组，带数量，按数量降序，样式仿日记二级标签）；点子分类 → 只显示该分类概念（其他类型隐藏），再点取消；`category` 空的「未分类」概念不设子分类，概念全览可见。
8. **概念面板加「来源」**：概念内容步 名称 → 定义 → **来源 input（最下面，主按钮之上）**，显示/编辑/锁定规则与摘抄来源一致（externalSel 只读书名；笔记选区自动填 `[[来源笔记]]`；URL 可编辑）。

**Blocked by:** 无（46/47/48/49 已完成）

**Status:** ready-for-agent

## 验收标准（User Stories）

- [ ] 概念面板：概念名输入框与定义 textarea 之间大间距（~18px 级）；来源 input 位于定义之下、主按钮之上；externalSel 时来源只读显示纯文字书名（无 `[[` 包裹、无 cfi），其余模式可编辑
- [ ] 摘抄面板内容步顺序：摘抄 textarea → 想法 textarea（手输 placeholder，无 AI 预填）→ 来源 input → 📋分析名词，相邻字段间均大间距
- [ ] 摘抄分析名词后③感触步：**无** AI 提炼想法框；仍有名词表（✦新概念标记）/情绪/涉及的人/场景/💾存入
- [ ] 涉及的人区：三类流程均无「➕ 新建画像」按钮与 mini 表单；匹配补全 + 仅存名字仍可用
- [ ] 新概念流转：摘抄勾选 ✦新概念并存入 → 不落空定义概念笔记 → 弹窗流转为概念表单（概念名=该名词、可编辑、来源=摘抄来源）→ ✨生成定义 → ✅确认 → 下一个新概念依次流转 → 全部完成后摘抄笔记 `terms` frontmatter 与正文 `关联概念：` 追加全部新建概念（去重）；直达/EPUB 模式全部完成后自动关闭，引导模式回类型选择
- [ ] 流转中途：跳过（关闭弹窗/ESC）→ 已确认的概念创建并回填，未确认的概念不创建、摘抄不加
- [ ] 重名守卫：流转确认录入时改名与既有概念同名 → 提示「已有同名概念」、不新建、摘抄 terms 关联该既有概念
- [ ] 摘抄保存后不再触发 AI 分类（留 `黑匣子/摘抄/<标题>.md` 根目录）；概念保存后仍 AI 分类入 `黑匣子/概念/<分类>/`
- [ ] 面板：三标签各带 `(n)` 总数；单选切换（点概念选中+展开子分类行，点文献切文献，再点当前取消）；子分类行列出全部概念分类（数量降序），点子分类只显示该分类概念；未分类概念仅概念全览可见
- [ ] 面板文献卡片：来源行位于正文 + 关联概念 chips **之后**（卡片最底）；来源显示可读名（epub=书名、笔记=笔记名、URL 原样），点击跳转行为不变；概念卡片来源同样显示可读名
- [ ] 面板概念卡片：来源行仍在关联 chips 之后（最底），显示可读名
- [ ] 笔记格式冻结：frontmatter 字段与正文关联区格式不变（source 完整双链、terms 追加仅增不改）；ADR-0015/0016 语义不变

## 实现决策

- **纯函数先行**：`source-jump.ts` 新增 `bookTitleFromSourceLink(sourceLink)`（书内双链 → 纯文字书名：别名优先，无别名取路径尾段去扩展名）与 `sourceDisplayText(source)`（epub → 书名；`[[笔记]]` → 别名/尾段可读名；URL/纯文本原样）——录入弹窗只读显示与面板列表来源行共用同一函数。
- **流转状态**：capture.ts 模块级 `pendingConceptQueue: string[]`（待录入概念名）+ `flowLitId: string | null`（回填目标摘抄 id）+ `flowCreated: { id: string; name: string }[]`（已确认概念，回填用）。`resetEntry()` 清空。`activeType` 切到 `concept` 复用既有概念表单（预填名、继承来源、definition 清空）。
- **回填接口**：`data.ts` 新增 `appendEntryTerms(data, entryId, conceptIds)` —— 摘抄 terms 追加去重 + `updateEntryNote` 重写笔记（frontmatter terms + 正文关联概念行）+ save。概念确认后由 UI 层依序调用。
- **重名守卫**：`saveConcept` 确认录入时按概念名匹配既有 concept（同名判定沿用 analyze 的 includes 双向匹配）；命中 → notice 提示、不建新卡、把既有 id 计入回填集。
- **注入豁免**：流转模式下概念保存跳过 `injectIntoSourceNote`（摘抄保存时已对来源笔记注入摘抄标题，二次注入会覆盖选区原文）。
- **分类收敛**：`saveEntry` 的 autoClassify 调用加 `type === 'concept'` 守卫；`autoClassify`/`applyCategory` 函数本身不动（概念仍用）。
- **面板筛选状态**：panel.ts 新增 `selectedCategory: string | null`（子分类单选）；`getFilteredEntries` 增加分类过滤（选中子分类 = `type==='concept' && category===selectedCategory`）；类型标签改单选（点击设置唯一项/取消）；标签数量与子分类数量均基于 `data.entries` 原始统计（不随搜索变化）。
- **子分类行**：类型标签栏下新增常驻容器，仅「概念」选中时显示；分类排序按数量降序、同量按名称；点击设置/取消 `selectedCategory` 并重渲染。

## 测试决策

- 只测外部行为（DOM 结构与数据落盘结果），不测内部状态实现。
- **source-jump.test.ts**：`bookTitleFromSourceLink`（`[[书架/x.epub#weave-cfi=…|书名]]` → `书名`；无别名 → 路径尾段去扩展名）、`sourceDisplayText`（epub/笔记别名/笔记无别名/URL/纯文本五形态）纯函数用例。
- **capture.test.ts**：摘抄内容步顺序与想法框手输（分析结果 insight 不预填）；③感触步无 AI 提炼框；无「新建画像」按钮；新概念流转全流程（勾选✦ → 存入 → 流转概念表单 → 生成确认 → 回填摘抄 terms 笔记与内存）；跳过不建不加；重名守卫；摘抄不触发 autoClassify（mock Ollama 顺序响应仅概念消耗）。
- **capture-epub.test.ts**：externalSel 来源 input 显示纯文字书名 + readOnly；保存后 source 仍为完整双链（cfi 不丢）。
- **panel.test.ts**：三标签数量文本；单选切换行为；概念标签展开子分类行（数量降序）；子分类筛选流内容；文献卡片来源行位置（正文与 chips 之后）与显示名（epub 书名/笔记名）；概念卡片来源显示名。
- 既有测试受影响处同步改写（insight 自动填入、新建画像按钮、多选类型标签断言）。

## Out of Scope

- 💡 想法面板间距调整（未要求）
- 存量已分类摘抄迁移回根目录（用户自行处理完毕）
- 子分类排序配置化 / 「未分类」子分类
- 概念分类行为变更（保留 AI 自动分类）
- 笔记格式与 ADR-0015/0016 任何字段语义变更（来源仍存完整双链）
