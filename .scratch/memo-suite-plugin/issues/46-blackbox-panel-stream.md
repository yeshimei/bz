## 验收标准

- [ ] 面板结构：header（左标题「🕳️ 黑匣子面板 · N 条内容」，右动作区 ✏️/👤/🕐/⚙️/❌ 关闭在最后）；类型标签栏三胶囊；搜索框；时间流容器；`#bz-blackbox-panel` / `bz-blackbox-panel-mask` DOM id 保留（外部约定）
- [ ] 类型标签栏：多选（Set），点击切换选中态；**默认空集 = 显示全部**；选中 = 只显示选中类型并集
- [ ] 搜索：输入防抖 300ms；范围 = 名称/定义/文本/来源 + 情绪标签 + 涉及的人名（personLabel 显示名）
- [ ] 时间流：三类条目混排按 `createdAt` 降序（新在上），同日按时间降序；日期分隔条（YYYY-MM-DD）吸顶 sticky；批次渲染（BATCH=20）+ 滚动到底加载下一批 + 全部渲染完显示「已显示所有内容」；空态（无条目/无匹配）
- [ ] 卡片纯展示三铺法：🧩 概念 = 头部 emoji+HH:MM + 名称 + 定义全文 + 关联概念 chips（纯展示）；📎 文献 = 头部 + 来源 + 摘抄全文 + 名词表 chips + 链接 🔗 行；💡 想法 = 头部 + 全文 + 情绪/人物/场景 chips；**无任何 click/touch 交互**
- [ ] 五标签逻辑删除：bz-blackbox-wall/shelf/pool/people/timeline 容器不再由面板创建（grep 确认无外部依赖）
- [ ] 旧面板测试改写：五标签切换测试 → 流式渲染/排序/类型筛选/搜索/批次/空态测试（弹窗测试在 ticket 47）
