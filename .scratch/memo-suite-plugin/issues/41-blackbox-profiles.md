# 41 — 黑匣子人物画像全栈 + 主面板框架

**What to build:** 人物画像（派生层）端到端可用 + 主面板五标签框架落地：录入时「涉及的人」从画像库选择或现场新建（冷启动双路径），未建画像只存名字；新建画像后 AI 从已有条目提炼初始画像；**五标签主面板框架（🧩 概念墙 / 📎 文献架 / 💡 想法池 / 👤 人物 / 🕐 时间线，新命令 `bz-blackbox-panel`「黑匣子面板」打开）**，人物标签页展示画像卡片墙与详情（用户印象区字段级锁 + AI 观察区可采纳 + 情绪聚合）；复盘产物新增「新人物提示」（高频提及未建画像的人）。

**Blocked by:** 39 — 黑匣子 schema v2 扩展 + v1 数据迁移

**Status:** ready-for-agent

## 验收标准

- [ ] 涉及的人选择器：输入名字自动补全匹配已有画像；可选已有画像 / 现场新建画像 / 仅存名字文本；多条可选（上限 5）
- [ ] 新建画像（名字 + 可选关系）→ AI 全量扫描已有条目生成初始画像（印象 + 关联条目）；用户可重生成
- [ ] 主面板五标签框架（`bz-blackbox-panel` 打开；切换保留各页状态）；未填充的标签页（概念墙/文献架/想法池/时间线）先空态占位，由 ticket 43/44 填充
- [ ] 人物标签页：画像卡片墙（名字/关系/印象摘要/事件数/情绪聚合）；详情 = 用户印象区（可编辑，**字段级锁**：用户改过 AI 不再覆盖）+ AI 观察区（虚线框，持续追加，可一键「采纳」进印象区，采纳后一并锁定）+ 情绪聚合统计（关联条目情绪标签计数）+ 时间线占位（事件投影由 ticket 43 接入）
- [ ] AI 提炼增量：新条目关联画像后自动更新 AI 观察（不覆盖用户印象）
- [ ] 复盘产物：发现高频提及但未建画像的人名 → 「新人物提示」（建画像入口）
- [ ] 测试：选择器交互、提炼 mock、字段级锁（用户改后 AI 不覆盖）、采纳流转、情绪聚合纯函数、复盘提示
