# 42 — 黑匣子事件提炼全栈

**What to build:** 事件（派生层）数据与提炼逻辑端到端：AI 全自动从条目中提炼「发生了什么」（有具体行动/变化/时刻），带置信度（推测事件标记）；参与人物引用画像（主角/配角）；用户编辑过的事件 AI 不再碰（字段级锁同画像）；复盘产物新增「事件汇报一句话」（这周整理 N 件新事件，其中 M 件推测）。推测事件的确认/删除交互在 ticket 43 时间线页落地。

**Blocked by:** 41 — 黑匣子人物画像全栈（事件参与人物引用画像 id）

**Status:** ready-for-agent

## 验收标准

- [ ] 复盘时 AI 批量提炼新事件：识别「事件」（非纯情绪/纯知识），生成标题/摘要/时间（条目记录日期）/参与人物（关联画像，标主角）/证据链（来源条目 id）/情绪聚合；全自动写入，无确认清单
- [ ] 推测标记：AI 自评置信度，意图/计划/梦境等非事实内容 `inferred: true`（虚线 + ❓ 展示语义由 43 落地，本票数据正确）
- [ ] 编辑锁：用户编辑/删除/合并过的事件 `edited: true`，后续提炼不再覆盖/重复生成（同字段级锁语义）
- [ ] 人物投影数据正确：事件按人过滤 = 画像时间线（单份存储，无复制）
- [ ] 复盘产物：追加「事件汇报一句话」（N 件新事件 / M 件推测）；手动复盘同逻辑
- [ ] 测试：提炼 mock（事件/非事件判定）、推测标记、edited 锁、按人过滤纯函数、汇报文本
