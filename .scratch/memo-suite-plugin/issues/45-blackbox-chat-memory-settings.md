# 45 — 黑匣子对话记忆扩展 + 设置 2 项

**What to build:** 对话（`bz-blackbox-open`）三层记忆扩展：检索上下文加入画像概要（印象一句话 + 最近 3 个事件标题）与命中条目关联事件标题，包仔从此「认识你的人际世界」；⚙️ 域设置弹窗新增 2 项：推测事件显示开关、情绪词表可编辑（增删，24 词预置）。

**Blocked by:** 41 — 黑匣子人物画像全栈；42 — 黑匣子事件提炼全栈

**Status:** ready-for-agent

## 验收标准

- [ ] 对话检索上下文组装：基础感触检索（跨三类）+ 画像概要（名字/印象一句话/最近 3 个事件标题，预算控制不超限）+ 命中条目的关联事件标题（若有）
- [ ] 画像/事件数据缺失时（尚未提炼）对话行为与 v1 一致（优雅降级，不报错）
- [ ] ⚙️ 设置新增「推测事件显示」开关（默认开，存 settings.showSpeculativeEvents，时间线消费见 ticket 43）
- [ ] ⚙️ 设置新增情绪词表编辑（增删词，预置 24 词，存 settings.words；录入弹窗与校验实时消费新词表；删除词不影响存量条目）
- [ ] 既有设置 5 项（AI provider/URL/model/复盘阈值/对话历史）保留不动
- [ ] 测试：上下文组装（含画像概要/事件标题/缺失降级）、词表增删持久化与消费、开关默认值与持久化
