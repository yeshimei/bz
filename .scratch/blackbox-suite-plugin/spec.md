# Spec: 黑匣子域（bz 插件新域，第 19 域）

Status: `ready-for-agent`
Type: spec
Feature: blackbox-suite-plugin

## Problem Statement

用户（叫我包仔）希望有一个长期累积个人「感触」的容器——**黑匣子**：任何想留下的信息（想法、从别人那里看到的有感触的东西、想搞懂的概念）都录入其中，AI 作为黑匣子的**意识体「包仔」**（有名字、有记忆、有偏好的「他者」，终局为可交流、可陪伴的伴侣）从这些内容中长出人格，未来可与用户交流。

bz 现有 18 个域均为"工具"（待办/剪藏/复习…），无"人格化记忆容器"。闪念虽具备「快速捕获 + 向量检索 + AI 对话」，但其定位是捕获-检索工具，不是累积-成魂的记忆体。黑匣子为新域，与既有域平行（不做元层聚合），未来可能纳入次级内容（备忘录/日记/bz 使用过程，当前不接入）。

设计经 grilling 会话逐轮敲定（2026-08，术语见 `CONTEXT.md`「黑匣子域」节），本 spec 为唯一事实源。

## Solution

bz 新域 `src/blackbox/`：单 JSON 数据文件 `CONFIG/STORAGE/blackbox.json`（受 ADR-0009 storagePath 约束），三类条目（概念与实体 / 文献笔记 / 核心知识）+ 两个派生层（人物画像 / 事件时间线）。UI = 中央录入弹窗（`bz-blackbox-capture`）+ 中央对话弹窗（`bz-blackbox-open`）+ 五标签主面板 + 复盘（`bz-blackbox-review`）。AI 复用 `core/createAI`（DeepSeek 优先 → Ollama 回退，同闪念模式），对话检索沿用 v1 已实现的 TF-IDF（不引入向量）。

### 领域模型

- **感触外壳**：文献笔记与核心知识共享的维度集合——时间（自动）、情绪标签（24 词多选 ≤3，无强度）、涉及的人（画像选择器）、场景/指向/链接（可选）。**概念与实体无感触外壳**（纯知识卡片）。
- **三类条目**：
  - **概念与实体 (concept)**：用户给名词 → AI 生成知识卡片（定义一句话/一段话）→ 卡片间关联由 AI 自动构建 → 用户仅确认是否录入。
  - **文献笔记 (literature)**：用户摘抄文本 + 来源 → AI 提取概念/实体并匹配已有概念 → 名词表勾选关联 → 可带出想法。
  - **核心知识 (thought)**：用户自己的想法（可随文献带出，可独立录入），三类中的核心层，前两类是其知识背景。
- **人物画像 (profile)**：派生层。AI 从条目中提炼维护，用户可改。字段：名字/关系（用户手填）、印象（用户版，字段级锁）、AI 观察区（AI 持续写入，可采纳进印象）、事件投影（按人过滤）、情绪聚合（关联条目情绪标签统计）。冷启动双路径：录入时「涉及的人」可主动新建画像；不建则只存名字文本，AI 复盘时提示。虚拟角色（历史人物/偶像/纸片人）同样可建画像。**第一版不实现遗忘权**（删除/断链/忽略持久化后置，Q23）。
- **事件 (event)**：派生层。AI 全自动提炼"发生了什么"（有具体行动/变化/时刻），带置信度（推测事件虚线+❓，确认或删除；**忽略=删除，无持久化忽略清单**）；用户可编辑/删除/合并，改过的 AI 不再碰。单份存储，画像时间线与全局时间线均为其投影。事件参与人物 AI 标主角/配角，涉及的人多选上限 5。
- **人格档案 (persona)**：种子（名字「包仔」+ 一句话性格 + 示例语气，模板）+ 生长（复盘更新自我认知）。
- **记忆（对话时）**：三层——感触检索（三类条目，TF-IDF 沿用 v1）+ 人格档案（概要）+ 对话历史（短期）；人物画像/事件以概要级进入检索上下文（画像：印象一句话 + 最近 3 个事件标题；事件：命中条目附事件标题）。
- **复盘**：每 10 条新感触自动触发 + 手动；静默执行不打扰（不弹窗）；产物公开写入对话面板（用户打开时可见）——含人格档案更新、新人物提示、事件汇报一句话（"这周我整理了 N 件新事件（其中 M 件推测）"）。
- **录入辅助**（可选，不打断录入流）：🔍 查概念（文献/想法选中词查定义）、⚡ 联想（"这条让我想起你 X 月记过的那条"）、❓ 追问（感受太短时问"为什么这条触动你"）。

### 命令 id 全清单

| id | 动作 | 说明 |
|---|---|---|
| `bz-blackbox-capture` | 打开录入弹窗（顶部三类型切换：🧩 概念 / 📎 文献 / 💡 想法） | 外部约定，launcher 磁贴/热键依赖 |
| `bz-blackbox-open` | 打开对话面板（中央弹窗，意识体交流） | 外部约定 |
| `bz-blackbox-review` | 手动触发复盘 | 外部约定 |

域内不重复 addCommand，仅在 main.ts COMMANDS 表注册一次（ADR-0004）。

### 设置项总表（域设置弹窗 ⚙️）

| 项 | 默认 | 说明 |
|---|---|---|
| 复盘阈值（条） | 10 | 每 N 条新感触自动触发复盘提示；**读取优先全局设置 blackboxReviewThreshold（v1 兼容），settings.reviewThreshold 兜底并同步** |
| 推测事件显示 | 开 | 时间线是否显示推测事件（关=只显示确认事件） |
| 情绪词表 | 24 词内置 | 可增删（词表存 blackbox.json settings 段，第一版预置 24 词，内容可编辑、字段结构不改） |

AI 设置跟随全局设置页（createAI/DeepSeek/Ollama 回退），黑匣子不设独立 AI 配置（Q27：不搞隐私分层）。

### 情绪词表（第一版 24 词，预置）

触动、温暖、喜悦、平静、释然、难过、孤独、委屈、焦虑、愤怒、敬佩、想念、遗憾、感激、害怕、心动、幸福、骄傲、迷茫、疲惫、厌烦、羞耻、嫉妒、希望

### 数据格式（CONFIG/STORAGE/blackbox.json，第一版定全，字段不可改）

> v1 已实现（ticket 33-38，blackbox.json v1：impressions/reviews/chat）。本 schema 为 **v2（版本化扩展，ADR-0013）**：load 时 version===1 自动迁移（impressions → entries，映射见 ticket 39），save 写 v2。

```jsonc
{
  "version": 2,
  "settings": {
    "reviewThreshold": 10,      // 兜底默认；实际读取优先全局设置 blackboxReviewThreshold（v1 兼容）
    "showSpeculativeEvents": true,
    "words": ["触动", "温暖", "喜悦", "平静", "释然", "难过", "孤独", "委屈", "焦虑", "愤怒", "敬佩", "想念", "遗憾", "感激", "害怕", "心动", "幸福", "骄傲", "迷茫", "疲惫", "厌烦", "羞耻", "嫉妒", "希望"]
  },
  "persona": {
    "name": "包仔",
    "seed": "…",
    "toneExample": "…",
    "selfViews": [{ "ts": "", "view": "" }]
  },
  "entries": [
    {
      "id": "bb_<ts>_<rand>",
      "type": "concept" | "literature" | "thought",
      "createdAt": "ISO8601",
      // concept 特有（无感触外壳）：
      "name": "提喻法",
      "definition": "AI 生成的定义文本",
      "related": ["bb_<conceptId>"],   // 关联概念（AI 自动构建）；与外壳 links（URL/笔记链接）区分
      // literature 特有：
      "source": "URL 或书名/出处",
      "text": "摘抄内容",
      "terms": ["bb_<conceptId>"],   // 名词表勾选
      // thought 特有：
      "text": "想法内容",
      // 感触外壳（literature / thought 持有；concept 无）：
      "emotions": ["想念", "难过"],      // ≤3
      "people": ["pf_<id>"],             // 涉及的人，≤5（画像 id 或纯名字文本）
      "scene": "",
      "toward": "",                      // 指向（self/others/world）
      "links": ["https://…", "[[笔记]]"] // 链接数组（v1 逗号分隔多链接原样迁移）
    }
  ],
  "profiles": [
    {
      "id": "pf_<ts>_<rand>",
      "name": "前女友",
      "relation": "前任",
      "impression": "",                  // 用户版印象（字段级锁）
      "aiObservations": ["AI 观察（可采纳进 impression）"],
      "pinnedEvents": ["ev_<id>"],
      "createdAt": ""
    }
  ],
  "events": [
    {
      "id": "ev_<ts>_<rand>",
      "title": "给妹妹买吉他",
      "time": "YYYY-MM-DD",
      "inferred": false,                  // true = 推测事件
      "summary": "",
      "people": ["pf_<id>"],
      "mainPerson": "pf_<id>",           // 主角
      "evidence": ["bb_<id>"],           // 证据链（来源条目）
      "emotions": ["温暖"],
      "edited": false                     // 用户编辑过 → AI 不再碰
    }
  ],
  "reviews": [
    {
      "ts": "",
      "text": "复盘产物：一段话",
      "impressionCount": 0,
      "newSelfView": "",
      "eventReport": "",                  // v2 可选：事件汇报一句话（旧记录无此字段）
      "profileHint": ""                   // v2 可选：新人物提示（旧记录无此字段）
    }
  ],
  "chat": [{ "role": "user" | "assistant", "text": "", "ts": "" }],  // 短期记忆（保留 v1）
  "meta": {
    "lastReviewAt": "",
    "totalEntries": 0,
    "totalEvents": 0
  }
}
```

**复盘计数口径**：三类条目（concept/literature/thought）均计入复盘阈值（任何输入都是养料）。

**检索机制**：对话记忆检索沿用 v1 的 **TF-IDF**（非 bge-m3 向量；闪念才用向量），v2 索引文本 = entry.text（v1 的 material+feeling 合并后检索覆盖不变）。

### 主面板（五标签，`bz-blackbox-open` 同源入口或面板内切换）

| 标签 | 内容 |
|---|---|
| 🧩 概念墙 | 概念卡网格（名称+定义摘要+关联数），点击展开详情 |
| 📎 文献架 | 文献列表（来源+摘抄摘要+名词表关联） |
| 💡 想法池 | 想法列表（文本+情绪标签+涉及的人） |
| 👤 人物 | 画像卡片墙（名字/关系/印象摘要/事件数/情绪聚合）+ 新建画像；详情 = 印象（锁定）+ AI 观察（虚线，可采纳）+ 事件投影 + 情绪聚合 |
| 🕐 时间线 | 按年月分组的纵向事件流；事件卡：日期+标题+人物+情绪色点+证据链入口；推测事件虚线+❓+[确认][删除]；筛选（人物/年份） |

### 录入弹窗（capture）结构

- 顶部三类型切换胶囊（🧩 概念 / 📎 文献 / 💡 想法）
- 概念：名词输入 → [✨ 生成] → AI 卡片预览（定义+自动关联）→ [确认录入]/[重新生成]
- 文献：摘抄 textarea + 来源输入 → [✨ 分析] → 名词表勾选（AI 建议预勾）→ 「带出想法？」展开想法输入
- 想法：想法 textarea + AI 辅助按钮（⚡ 联想 / 🔍 查概念 / ❓ 追问）
- 感触外壳（literature/thought 显示；concept 不显示）：情绪标签胶囊多选（≤3）+ 涉及的人（画像选择器：匹配已有/新建）+ 场景/指向/链接（折叠）
- 底部 [取消] [保存]

### 对话面板（open）结构

- 中央弹窗（非窄窗，避免与闪念窄窗冲突）
- 三层记忆组装：TF-IDF 检索 TOP_K 相关条目（跨三类）+ 画像/事件概要 + 人格档案 + 最近对话历史 → 提示词 → AI 回复
- 复盘产物（人格档案更新摘要/新人物提示/事件汇报）以"包仔的话"形式出现在对话流中

### 样式（styles.css 收敛，bz 惯例）

- 弹窗：`#blackbox-capture-mask` / `#blackbox-capture-popup`、`#blackbox-dialog-mask` / `#blackbox-dialog-popup`（沿用 add-diary/add-todo 的 mask+popup 骨架：居中、圆角 12px、`--background-primary`、z-index 10001/10002）
- 面板：`#blackbox-panel` 五标签（标签胶囊复用日记标签按钮样式 `.diary-tag-selector-btn` 或新增 `.blackbox-tab-btn`）
- 事件卡：`.blackbox-event-card`（确认态实线）+ `.blackbox-event-card.speculative`（虚线 + ❓）
- 画像卡：`.blackbox-profile-card`；AI 观察区虚线框 `.blackbox-ai-observation`
- 情绪胶囊：`.blackbox-emotion-btn`（激活态高亮）；涉及的人标签 `.blackbox-people-tag`
- 移动端适配（@media max-width）：面板与弹窗宽 95%

### 降级链

1. **AI 不可用**（DeepSeek 失败 + Ollama 不可达）：概念生成/名词表分析/事件提炼/复盘/对话全部降级——录入仍可用（纯文本保存，无 AI 辅助），面板浏览/画像手动编辑可用；toast 提示「AI 服务不可用」。
2. **AI 部分失败**：DeepSeek 失败回退 Ollama（同闪念 `AI.ask` 模式）；单条失败不影响已保存内容。
3. **数据缺失/损坏**：blackbox.json 解析失败 → 按空库初始化并备份坏文件（jsonStore 语义）；旧字段缺失按可选字段处理（第一版无旧数据兼容义务）。
4. **检索不可用**（索引异常）：对话检索降级为关键词/最近条目（文本检索兜底），不阻断对话。

### 测试计划（tests/blackbox/）

- 数据层：条目 CRUD（三类）、感触外壳校验（情绪 ≤3、涉及的人 ≤5）、词表校验、画像投影（事件按人过滤）、事件 edited 锁（用户改过 AI 不再更新）、推测事件确认/删除
- 纯函数：词表默认值、情绪去重、时间线分组（按年月）、情绪聚合统计
- UI 层（jsdom）：录入弹窗类型切换、概念生成流程（mock AI）、名词表勾选、感触外壳折叠、五标签切换、画像详情（AI 观察采纳）、事件卡确认/删除、复盘产物入对话流
- mock fetch：AI 生成卡片/名词表/提炼/复盘（mock DeepSeek/Ollama）
- smoke.test.ts 命令清单同步新增 3 条命令

### 边界与后续（不在第一版）

- 次级内容（备忘录/日记/bz 使用过程）接入（Q2）
- 遗忘权：画像删除/断链、事件忽略持久化清单（Q23）
- 事件实际发生时间推断的校准（初版用记录日期）
- 语音/图片素材（第一版素材仅文字）
- 写 vault 的"仪式感"（复盘信件/纸条，Q6 后期项）

## User Stories

1. 作为用户，我希望通过 `bz-blackbox-capture` 打开录入弹窗并在顶部切换三种类型（概念/文献/想法），以便按内容形态录入。
2. 作为用户，我希望概念录入时输入名词由 AI 生成知识卡片（定义+自动关联），我只确认是否录入，以便零负担建知识背景。
3. 作为用户，我希望文献录入时粘贴摘抄与来源，AI 提取概念给出名词表勾选关联，以便摘抄与已有知识建立联系。
4. 作为用户，我希望文献录入可展开"带出想法"，摘抄引出的想法同一次录入完成，以便记录完整语境。
5. 作为用户，我希望想法录入时可选 AI 辅助（查概念/联想旧感触/追问），以便录入不被打断又有伴侣在场感。
6. 作为用户，我希望文献与想法条目有感触外壳（情绪标签≤3、涉及的人、场景/指向/链接），概念条目没有，以便记录"此刻的我"而非只存内容。
7. 作为用户，我希望主面板五个标签（概念墙/文献架/想法池/人物/时间线）浏览全部内容，以便按维度回看。
8. 作为用户，我希望「涉及的人」可从已有画像选择或现场新建画像，未建画像的人只存名字，以便冷启动不打扰。
9. 作为用户，我希望人物画像由 AI 从条目中提炼维护（印象/情绪聚合/事件投影），我可编辑且改过字段 AI 不再覆盖，以便画像既有 AI 维护又有我的主权。
10. 作为用户，我希望画像详情有 AI 观察区（持续更新的虚线框），我可一键采纳进印象区，以便我的版本与它的版本并存。
11. 作为用户，我希望事件由 AI 全自动提炼整理，推测事件以虚线+❓显示并可确认/删除，以便零负担获得时间线又不被幻觉误导。
12. 作为用户，我希望事件可编辑/删除/合并，改过的 AI 不再碰，以便我有最终纠正权。
13. 作为用户，我希望画像时间线是事件按人投影（同一事件在全局时间线与画像详情中一致），以便数据单一来源。
14. 作为用户，我希望每 10 条新感触（或手动）触发复盘且静默执行不打扰，复盘产物（人格档案成长/新人物提示/事件汇报一句话）出现在对话面板中，以便看到包仔在生长。
15. 作为用户，我希望通过 `bz-blackbox-open` 打开中央对话面板，包仔基于三层记忆（感触检索+画像事件概要+人格档案+对话历史）与我交流，以便它"认识我"。
16. 作为用户，我希望 AI 服务不可用时录入与浏览仍可用（仅 AI 辅助降级），以便黑匣子永不拒收我的输入。
17. 作为用户，我希望情绪词表在设置中可增删（第一版预置 24 词），以便词表随我的语言生长。
18. 作为用户，我希望黑匣子所有数据在本机 blackbox.json（storagePath 约束），以便数据属于我。
