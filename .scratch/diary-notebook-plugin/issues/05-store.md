# 05 — 数据层

**What to build:** 数据生命周期（不碰 DOM）：分批并发加载三个目录的条目并统一排序、按时间序写回日记文件（emoji 序列由标签生成）、新增/删除条目（写文件/删空文件）、单文件与影视/信文件的增量刷新、文件变更监听（节流、内部写入防回环）。数据变化通过全量/轻量刷新回调通知 UI 层（回调由外部注册，保持本层无 DOM 依赖）。

**Blocked by:** 03 — 标签配置、类型与状态, 04 — 解析层

**Status:** ready-for-agent

- [ ] 加载：批量并发、进度上报、排序、加密条目过滤（保留在数据映射中）、id 生成
- [ ] 写回：时间升序、`# emoji 时间`+空行+正文格式、空列表删文件、文件不存在时创建
- [ ] 增删：插入位置按时间、删除同步数据映射与文件、空文件删除
- [ ] 刷新：单文件重解析 upsert、外部修改节流合并、内部更新不触发回环
- [ ] 回调：全量刷新（重筛+重渲染信号）与轻量刷新（仅标签重建信号）触发时机正确
