## 一、这次改了什么（用户拍板）

把「放大镜搜索」从旧的「在原册子里跳到命中页 + 上一个/下一个 + 单页荧光笔」，改成**和分类册一样的一本「搜索册」**：

1. 输入词后，把全量日记里所有命中的条目**单独重排成一本册子**，翻页即可看完全部命中，不再需要「下一个」。
2. 命中词**整本每一页都划荧光笔**（不再只标当前那一页）。
3. 搜索词挂在书签条上，点「取下」回全本；与分类册 / 加密册互斥（进一个退另一个）。
4. 匹配口径放宽：全角半角 / 大小写 / 标点空白 / NFD 组合记号都能命中。
5. 取消解锁进加密册时，原搜索册原样保留（状态、书页、书签都不动）。
