# 更新日志

## ✨ 新增

- **影院** ：可以从豆瓣一次导入想看 / 在看 / 看过，影院里已有的会跳过不重复导入
- **影院** ：豆瓣上写的那句短评会一起导进来，直接成为这部片的影评
- **影院** ：片单行右键（手机长按）可以整单收录进影院、改名或移除

## ⚡ 优化

- **影院** ：评分、导演、主演、海报都改从豆瓣详情接口取，ApiZero Key 不再必填
- **影院** ：导入进度会自己收尾，关掉弹窗就停止继续抓取
- **影院** ：读到上次抓的名单会写明抓取时间，随时可以点「重新导入」再刷一次

## 🐛 修复

- **影院** ：中文输入法在搜索框打字不再被打断
- **影院** ：片单整单动作连点两次不会再跑一遍
- **影院** ：收录进影院时某一部写盘失败，不再连累后面的影片

# 安装

1. 到 [Releases](https://github.com/yeshimei/bz/releases) 下载最新的 `bz-1.38.0.zip`
2. 解压到 `<你的 vault>/.obsidian/plugins/` 下，得到一个 `bz/` 文件夹
3. 重启 Obsidian → 设置 → 第三方插件 → 找到「bz」→ 启用

# 离线资源包

在线资源（皮肤、工具包、手册、影视索引）下不动时，用 `bz-offline-1.38.0.zip`。解压出的 `downloads/` 整个放进插件目录，再回插件点一次下载——本地校验通过就直接用，不联网。

```text
.obsidian/plugins/bz/
├── main.js
├── manifest.json
├── styles.css
└── downloads/
    ├── manifest.json
    ├── skins/
    └── tools/
```
