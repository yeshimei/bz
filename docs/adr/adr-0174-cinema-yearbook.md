# ADR-0174 观影分析整篇重写为《观影志》：独立全屏 26 幕、只认 frontmatter 真字段、时间驱动表演

- 日期：2026-09-22
- 状态：已采纳
- 相关：ADR-0090（分析报告内嵌化）、ADR-0087（影院域）、issue 405 / 406（前两稿，已作废删除）

## 背景

观影分析（命令 `bz-cinema-analysis`「影视分析报告」）经历两稿：ADR-0090 把它做成影院面板内的
19 板块统计长列表，issue 405 又整页重做成「滚动放映室」（四本 22 幕，靠滚动进度 sticky 抽帧）。
两稿各留下三类问题：

1. **几何**：幕高/幕头位置全靠 `absTop` 与滚动进度换算，改一处错一处——实测出现过「一滚到底」
   （基准取错，把滚动量算了两遍）、幕与幕错位、sticky 钉因祖先 `overflow:hidden` 全程不钉。
2. **取色**：影片挂在 body，拿不到面板皮肤的 `--gold` / `--red`，多处金色/朱红静默退化成墨色；
   又写了一批 `rgb(var(--x) / .2)`——逗号三元组不能配斜杠，整条声明被丢弃（柱子/日历格全透明）。
3. **数据**：演示数据是手抄的 50 条，抄丢了片长/季集/热门短评等字段；而修字段时又给演示数据编过
   不存在的「片长」——用户点名「不要去瞎造」。

2026-09-22 用户拍板：**把观影分析的代码全部删除，也不要有任何记忆；先查真实笔记里的属性，
按这些属性重写，仍然大刀阔斧，每幕都要高级且完整的动效**。前两稿实现
（`stat-film.ts` / `analysis.ts` 及 tests、CSS 段、草稿）一并删除，不做兼容层、不做迁移。

## 决策

1. **先查字段，再定画面**。vault `我的/影视/*.md` 686 篇的 frontmatter 实测 19 键，取其中
   覆盖 100+ 篇的 14 个通用字段（观影日期/评分/豆瓣评分/片长/季集/类型/制片国家地区/上映日期/
   导演/主演/影评/热门短评/海报/tags）作为唯一数据源；只覆盖 1–5 篇的杂键（SP/漫画/IMDb/编剧/语言 等）
   不进画面。**演示数据改为脚本从真库全量导出**（`scripts/_gen-cinema-demo.mjs`，缺字段留 null），
   从此不存在「演示数据与真库不同分布」这件事。
2. **一屏一幕，取代滚动抽帧**。26 节各占一屏（章高 = 滚动口高），翻一幕只是 `scrollTop = 幕号 × 屏高`：
   没有 sticky 钉、没有 absTop、没有幕内滚动进度——第一类问题在结构上不可能再发生。
3. **时间驱动表演，取代进度驱动**。一幕被翻到时从 t=0 自演一遍（进场编排 → 常驻呼吸 → 定格），
   翻走时引擎把它推到终态。每幕的进场用各自的手法（26 种互不重复），常驻是氛围循环，
   于是「完整」有了明确含义：任何一帧停下都该是一张可看的画面。
4. **一次手势只翻一幕**。滚轮按 340ms 分段（触控板惯性不连翻），右侧刻度尺点幕、方向键、
   底栏「自动」按钮（按各幕自身时长往下放）三条等价入口。
5. **配色自持**：`.bz-yb` 自带纸/墨/朱/靛四色 token，亮色默认 + `.theme-dark` 覆写；
   画布经 `kits.palette()` 读同一批 `--yb-*-rgb` 变量，DOM 与画布不可能两套色。
6. **命令契约不动**：`bz-cinema-analysis`（id/名称/icon/首页入口）保持原样，只是实现换成新片；
   独立全屏弹窗（挂 body）语义沿用，ESC / 右上关闭钮出口不变。

## 理由

- 26 幕的骨架统一（序号/幕名/字段来源 · 主构图 · 口径脚注）是「不混乱」的全部来源：
  上一稿每幕各画一套版式、各写一套颜色，26 幕摆在一起就不像一本书。
- 时间驱动比进度驱动更抗环境：窗口被遮挡时 iframe 的 rAF 会完全停摆（评审壳实测），
  进度驱动只是画面不动、时间驱动会僵在起始帧——故补一条 220ms 定时器心跳兜底。
- 主构图只换内容不换版式，动效手法就能一幕一种而互不打架：手法的差异承担「新鲜」，骨架的
  一致承担「秩序」。

## 追加（同日第二批）：机制与版面再推一档

首版落地后用户拍板「布局更复杂、动效再增强，全都做」，同日追加四类机制与七幕改版：

**机制（一套，26 幕同时受益）**
1. **过片**：换幕先把遮片合上（两片纸从上下合到中线，留一道朱红细缝），合上那一帧完成滚动与激活再打开——
   换幕是一刀切，不再「慢慢滑过去」。时长走台账（合 `--cn-m-fast`、开 `--cn-m-move`），
   替换掉原来的 `behavior:'smooth'` 滚动。
2. **指针层**：引擎把指针位置（客户端坐标 + 归一化 -1..1）交给每一幕的表演，`move/down/up` 三个钩子
   只在**当前这一幕**上调用。2026-09-22 用户拍板「鼠标的干扰全都做」后，26 幕里除 01 开卷（粒子斥力）
   之外的交互一并接线，口径见文末追加节。
3. **入场定格**：遮片打开后本幕内容轻轻落定（`is-in` + `ybSettle`，走 `--cn-m-move`）。
4. **翻页钟**：单点大数字（06 片长合计 / 13 均分 / 14 两栏均分 / 26 落款四格）由「滚动计数」改成
   机械翻牌——占位串位宽与终值一致（`zeroOf`），每位真翻一次；位宽变了会整串重建，那条路只作兜底。

**版面（七幕）**
- 04 星期节律 → **径向日晷**：七根辐条绕一圈，指针扫到最常落座那天，中心是总量；
- 05 连看与单日 → **时间缎带**：连看的日子成一条 SVG 带子（stroke 描画 + 带内流光），
  单日 82 部成 82 道刻线；
- 10 出品印章 → **护照页**：按国家地理中心落位（静态经纬表，表外回落虚线章），同经度附近上下交替避让；
- 12 片龄抽屉 → **片龄横轴**：0 → 101 年一条轴，每部片是一枚海报刻度，四档是轴上的色带；
- 13 我的评分 → **评分散点 × 观影年**（联合分布图：散点 + 右侧评分边缘直方 + 均分线）；
- 16 榜首三部 → **真领奖台**：台座三档高（冠军居中最高），卡片吃剩余高度、海报按空间裁切；
- 19 座上常客 → **常驻弧线**：卡片用 `rotate(θ) translateY(-R) rotate(-θ)` 真排在弧上（弧是版式不是动画）。

**动效加强（五幕）**
- 01 开卷：粒子**多段化形**（686 → 观影志）+ 指针斥力；
- 02 十二年：描画时**读数光标**（走到哪年报哪年，画完停在峰值年）；
- 06 片长画像：**胶片盘**（每分钟沿螺旋绕，每圈 24 小时）；
- 08 类型光谱：右侧**共现星图**（一部片挂两个类型就是一条边，边粗 = 共现次数）；
- 11 年代长河：**双河**（上河 = 上映年份 1915→2026，下河 = 观影年份 2015→2026）。

**这一批踩到的两个坑**（都留了注释）：`preserveAspectRatio="none"` 会把缎带上的圆点拉成椭圆；
`Number('12.86deg')` 得 NaN 会让指针永远停在起点（读带单位的自定义属性必须 `parseFloat`）。

## 追加：指针层铺满 26 幕（issue 408，2026-09-22 用户「全都做」）

**口径（三条，写在 `kits.ts` 段首）**
1. **命中判定一律走 `under()`**（浏览器自己的 `elementFromPoint`）：一幕里动辄上百个点，
   逐元素量 `rect` 会把布局读爆，而浏览器本来每帧就在算 hover。要算「离指针最近的那一枚」
   （画布里的节点、等分栅格）时用 `localAt()` + `nearest()`，且只读**一个**容器的 rect。
2. **`move()` 里只记状态，写样式留给 `update()`**：指针事件的频率跟着鼠标走、和帧率不同步，
   在事件里写样式会在快速划动时写出抖动；连续量（视差、斥力、跟手）一律逐帧算。
3. **浮签挂整屏根**（`.bz-yb`，`fixed inset:0`，客户端坐标即根内坐标），引擎在翻幕 / 指针离场 /
   `stop()` 时统一收掉。舞台上的表演用的是影片根（`buildPerfs(root, data, host)` 的第三个参数），
   两边**必须挂同一个元素**——否则一边建、一边清，切幕后上一层楼的读数会赖在画面上（实测踩过）。

**接进来的交互（按手感分档，全部实现）**
- 跟手：04 日晷指针跟指针转、盘心报那一格；09/11 河流被指针拨开；13 散点整块跟指针偏摆；
  16 领奖台整排让位 + 追光横移；17/25 两面板墙随指针转向，25 还按距离磁吸抬起（高斯衰减）。
- 悬停读数（`data-tip` 在版式层就写好，运动层只管显示）：03 日历 / 05 串珠与刻线 / 06 片长分箱 /
  10 印章 / 12 片龄海报 / 13 散点与直方 / 23 短评 / 24 矩阵格。
- 联动：08 类型条 ↔ 共现星图双向高亮；14 背靠背同档两侧一起站起来；
  12/13 悬停时其余点压暗（不给「谁被指到」留歧义）。
- 交互动词：07 指针在尺子上量出一档（朱红读数线 + 「上下 12 分钟里有多少部」）；
  15 打分天平**按住**一侧托盘才沉（全片唯一有手感的器件，松手弹回数据那一档）；
  23 弹幕悬停减速到 12%（长句在弹幕里根本读不完，位移因此从无状态取模改成逐帧累积）；
  19 弧线随指针转、被点到的卡站出来；20 扇面摊开；22 卡片按卡内位置做 3D 倾斜；26 四格翻页钟倾斜。
- 不做：点击类交互（刻度导航 / 自动 / 关闭已占住点击）、全片统一的跟随光晕（各幕器物不同，
  统一视差会把它们压成同一张纸）、07 拖端点改阈值（那是数据交互不是装饰，要另立一版）。

**门槛**：新写的 CSS 过渡仍走 `var(--cn-m-*)` 台账（`motion-ledger.test.ts` 会挡）；
指针层的契约测试在 `tests/cinema/yearbook-pointer.test.ts`（工具箱纯函数 + 版式钩子 + 引擎只发给当前幕）。
