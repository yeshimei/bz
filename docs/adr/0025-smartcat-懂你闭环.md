# ADR-0025：小橘「懂你」闭环——情绪温和共振 + 全通道上下文 + 数据诚实化

- 日期：2026-08-23（用户反馈「小橘的东西配合不密切、数据给得不恰当」后拍板）
- 状态：Accepted
- 关联：ADR-0021（记忆流）、ADR-0022（PAD 心情）、ADR-0023（MATE 人格）、ADR-0024（RL 校准）

## Context

走查小橘各子系统后发现四类接缝与六处「数据名不副实」：
情绪只作标签不进心情（vault 活动恒定增益）、认知趋势只在文本里出现、记忆只喂聊天通道、
作息/关系/趋势不进系统提示；trust warm 恒真、preferredHour 假众数、聊天记忆全量落地、
检索词法 query 噪音、周报 padAvg 抄当前值、文档漂移。目标是让小橘形成
「感知（观察）→ 共情（心情/情绪）→ 记忆（长期理解）→ 表达（各通道统一带上下文）」闭环。

## Options

1. **温和共振**（采纳）：推翻 ADR-0022 时期「情绪不直接改写 PAD」的旧拍板——观察/聊天情绪
   经 `emotionToVAD` 换算为 PAD 差量（calm/neutral 趋近 0、负面略强于正面），走既有
   `updatePad`（人格乘数/抵抗力/衰减自然生效），另同步 `currentEmotion`；情绪趋势
   （近 48h declining/improving/高波动）经 30 分钟节流定时器温和回写心情。
   对比：直接镜像用户 VAD（副本化，否决）、仍只作标签（闭环不成立，否决）。
2. **全通道上下文**（采纳）：新增纯函数 `buildCompanionContext`（作息 + 情绪趋势 + 信任/依恋 +
   检索记忆），`generatePrompt` 增 `companionContext` 节注入系统提示；聊天/自言自语/欢迎回来/
   书评/主动关心统一携带。
3. **数据诚实化**（采纳）：聊天记忆去重（近 20 条同内容跳过）+ 限流（非 calm 情绪或
   importance≥0.55 才落库）；`trustUpdate` 增 neutral 语义（click/note_* 不动 trust）；
   `preferredHour` 改由作息画像真众数（无记忆数据兜底当前小时）；矛盾检测动词表补
   看了/读了/记下；周报 `padAvg` 改取周内观察情绪 VAD 均值（无样本回退当前 PAD）；
   检索词法模式用纯用户消息 query（语义模式保留情绪/时段增强）。

## Consequences

- A 面：小橘的心情会温和跟随用户近期情绪——「你难过它也低落、你开心它也亮」，但有四层约束
  （差量小、calm 趋 0、人格调制、60s 衰减回基线 50），不会变成用户的情绪镜子。
- B 面：所有 AI 通道共享同一份「懂你」背景，表达一致性提升；系统提示长度小幅增长（有裁剪）。
- C 面：记忆流质量提升、聊天 LLM 往返减少（importance 打分仍在，去重先于打分短路）；
  信任语义明确（中性事件不再侵蚀/升温）。
- 文档同步：CONTEXT.md「情绪」词条由「不直接改写 PAD」改为「温和共振」；α 三因子更新为
  0.66/0.95/1.5（RL 进化第 3 轮重标定）；新增「懂你上下文块」共享术语。
