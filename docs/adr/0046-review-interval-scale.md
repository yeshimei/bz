# ADR-0046：复习间隔缩放（FSRS 相位间隔乘系数）

日期：2026-08-26 ～ 状态：Accepted ～ 关联：ticket 100、ADR-0044（铁律 1 解冻先例）

## Context

用户要求暴露 FSRS 参数/遗忘率以调节复习密集度。排查代码（src/review/fsrs.ts）发现：本幂律模型 `R(t,S) = (1 + t/(S·d))^(-d)` 的 `d=0.9` 虽形似「遗忘率」，但**间隔天数恒等于新稳定性**（`nextInterval` 返回 `days = newS`），`d` 不参与间隔计算——直接把 d 暴露成「遗忘率」是个假旋钮（改它只影响 R(t) 显示与稳定性成长曲线，不动下次间隔天数）。若实现「真遗忘率反解」（按目标保持率反解 t），将令全部既有间隔口径突变（现模型等效约 51% 保持率处复现，反解后间隔大幅缩短），属字段级行为破坏。

## Decision

**间隔缩放系数**（用户拍板选甲方案）：新增设置项 `reviewIntervalScale`（默认 1，范围 0.1-5，UI「复习间隔缩放」）——`markReview` FSRS 相位计算出的间隔天数 × 系数后写 `nextReviewDate`：

- **只作用于 FSRS 相位**（stage ≥ 10，`result.days * scale`）；阶梯阶段（stage 0-9 固定分钟/小时/天阶梯表 `FSRS_FIRST_INTERVALS`）不受影响
- 系数钳制：非正数/越界一律回退 1（UI 侧 onChange 已钳 0.1-5，读取侧兜底 `Number > 0 ? Number : 1`）
- 幂律公式本体、19 权重、S/D 计算零改动；R(t) 显示值不参与缩放
- 旧数据零迁移（新键默认兜底 1）

**铁律 1 解冻声明**：这是继 ADR-0044（多选计数）后第二处用户拍板解冻项——非改公式，而是新增一个乘数参数，既有排期行为在默认值 1 下完全不变。

## Options

- **O1 真遗忘率反解**（暴露目标记忆保持率 %，按 R(t)=r 反解 t）——❌ 需重排幂律语义，全部存量间隔突变，破坏兼容与既有排期节奏；不透明
- **O2 暴露 19 权重（d 等）**——❌ 专家级裸参，用户无感知映射，误调毁排期
- **O3 间隔缩放（采纳）**——✅ 一个乘数，语义直白（小=密、大=松），默认 1 完全兼容，可逆

## Consequences

- FSRS 相位复习节奏可调（默认不变）；阶梯阶段节奏固定（前几轮分钟/小时级刻意快速）
- 系数影响 `reviewHistory` 之外的排期字段（只写 nextReviewDate，稳定性不受影响——重排期不重塑记忆强度）
