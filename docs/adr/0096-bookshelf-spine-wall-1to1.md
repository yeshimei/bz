# ADR-0096：书库面板换血为书脊墙 1:1 复刻

日期：2026-09-06　状态：已采纳　域：bookshelf　关联：issue 218、ADR-0081（回忆墙只读）、ADR-0095（待办皮肤）

## 背景

bookshelf-10 原型批次中 P4「书脊墙」拍板后，用户在真实数据全功能版（p4-full.html，162 本）上确认交互与形态，要求**1:1 复刻进插件、完全抛弃旧书库布局**（原封面网格/左栏/统计卡/月柱/筛选抽屉/移动专用布局），并明确「原型里没有的一律不要」。拷问访谈被用户跳过 = 按推荐档定案（本文记录）。

## 决策

1. **面板 = 原型本身**：木匾刊头 + 纸质统计标签行 + 工具行（检索 + 三档排序）+ 分类分区动态装箱墙体 + 倒叠区 + 墙尾格言。统计卡（在读/今年读完/累计时长）、近 12 月月柱、纪念日卡、左栏、封面网格、筛选抽屉全部退役，代码与样式不保留。
2. **书脊语义**（原型口径）：高度=累计阅读时长（150~230px 开方标尺）、厚度=字数（22~56px 开方缩放；md 书新增解析 `wordCount`/`pages` frontmatter，EPUB 无字数回退批注密度×800）；颜色=分类（色板 + 散列兜底 + 同分类 ±7% 明度抖动）；已读盖「讫」印、在读抽出一截垂书签带、未读收墙尾「倒 叠 区」倒扣灰。
3. **动态装箱**：每排按当前墙宽实测逐条塞满才换排（分区隔板从排首占位参与测宽；单条超宽硬塞防死循环）；窗口 resize 防抖 150ms 整墙重排。
4. **长书名**：按「：」拆主/副题双竖列（丛书书脊范式），`text-orientation: upright` 拉丁直立，字号 14→9px 保底，列宽上限 64px，省略号兜底。
5. **移动端同构**：不保留独立移动布局；窄墙自动多排（媒体查询只缩距不换形）。移动全屏设置键沿用。
6. **借书卡详情**：纸卡排版（pull-note/台账/批注密度条/印章「讫·阅·藏」）+ 现有全部编辑能力融卡内（状态 choice/进度 range/读完日期/书评/直达原文/读书笔记/删除/撤销回滚），功能零回退；EPUB 只读语义不变。
7. **报告视图**：内嵌容器与命令 `bz-reading-report-open` 保留（冷开/热切/返回/同面板筛选/自动刷新全链路不变），但**墙面无入口**——报告不再占用书脊墙版面。
8. **十肤随迁**（ADR 链 issue 216）：皮肤类照挂面板根与弹窗根；样式两层——`--bz-*` token 层照旧（弹窗件通吃），新增 `--bsw-*` 墙变量映射（墙/架/纸/铜/墨/线/章十值随肤换）。默认雪松白不变。
9. **设置面收敛**：删除「网格每行列数」（bookshelfGridColumns 键随网格退役全删）；「默认排序」键 bookshelfSortMode 存量值不迁移（date/author→recent、progress→time 在 applyDefaultView 零感知映射）；「默认筛选」映射初始状态标签。

## 后果

- 旧网格渲染链（renderSide/renderDash/bookCardHTML/renderShelves/openFilterDrawer 等）与样式整体删除；ui.test.ts 按 1:1 口径重写（109 例全绿），walkthrough C-1/C-3/C-5 断言随契约更新。
- 书脊 DOM 量 = 书数（162 本实测无压力）；装箱为渲染期测量，无布局抖动残留。
- 正名（issue 207「书库」）与面板标题暂以原型刊头「书脊墙」为准——若需回归「书库」显示名仅改刊头文案。
