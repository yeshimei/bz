# 0014 黑匣子暂为平行新流，次级内容未来接入（不做元层聚合）

黑匣子的两类输入（我的想法、别人的东西带给我的感触）与既有域（闪念/日记/剪藏）高度重叠，设计时曾考虑「元层」方案——黑匣子作为意识体直接聚合读取 vault 全部既有数据。用户决策：**暂做平行新流**——黑匣子 v1 仅收「感触」一条输入流（`CONFIG/STORAGE/blackbox.json`），与闪念/剪藏/日记并列；备忘录、日记、bz 使用过程等作为「次级内容」，未来以独立机制接入，v1 不做元层聚合。理由：先让感触流独自长大、验证"素材+感受"复合单元与三层记忆（感触检索+人格档案+对话历史）的有效性，避免首版承担聚合复杂度；次级内容接入是明确的演化路径而非否定。

**Consequences**: 未来读者看到黑匣子"不读日记"会困惑——答案在此 ADR。次级内容接入时经独立机制（如新增 ingestion 通道），不改 v1 感触 schema（ADR-0013）；黑匣子与闪念的向量检索（bge-m3/tfidf）可复用不重复造轮子。
