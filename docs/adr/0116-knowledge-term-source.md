# 术语文献「来源」：统一 source 键 + 单框智能分流（内部笔记 / 外部链接）

背景：知识盒术语录入（文字录入·术语）只记「术语名 → AI 生成简介 → 落一篇术语文献」，没有任何出处记录。用户在移动端全屏录入术语时，来源通常是「正在读的某篇笔记」或「正在看的某条外部链接（b 站视频、知乎日报等）」——拍板为术语录入加一个**可选**的「来源」输入框。设计经 grill-with-docs 三轮盘问收敛，关键语义澄清来自用户一句修正：「笔记中的 related 不是来源，是关联，是 Obsidian 中原生的双向链接」——来源（出处溯源）与 related（关联网络）在领域语言里严格两分。

## 拍板要点

1. **一个术语文献至多记一个可选来源**（录入是「顺手记一笔」，多来源靠以后编辑笔记补），落库即 frontmatter `source` 键；外部方向抓到的页面标题另落 `sourceTitle`（可选，抓取失败静默降级为纯链接）。
2. **键的语义归属**：外部来源落 URL 原文、内部来源落原生双链 `[[路径|名]]`——`source` 是出处键；不搭 `related` 便车（related 在系统里已承担卡片↔源文献的双向互链 + Obsidian 反向链接，混入来源会污染读侧）、不冒充视频文献专属的 `url` 键（部壹预览「原文」块与抽屉语义绑定视频链接）。
3. **单框智能分流**（用户否决两段式切换与自由文本直存）：一个输入框，整串无空白的 URL/域名样式文本（宽松域名字样判定：`http(s)://` 前缀 或 形如域名 ≥2 标签、末标签≥2 字母——含 `b23.tv` 这类单标签+TLD；**不做平台特判**，BV 号等纯代码串不识别）→ 外部链接 chip；其余输入走 vault 笔记联想（复用 core/ui/suggest.ts，候选 = 全部 .md 路径）→ 点选成内部笔记 chip。chip 带 ✕ 一键清除。空白整串保护：含空白的文本永不判为外部（防笔记搜索被域名误吞）。
4. **仅记录 + 展示，零联动**：来源不喂 AI（保持 ticket 142/155 的零上下文生成形态）、不回写源笔记（录入门径无副作用）；展示面 = 术语预览属性卡第 4 行「来源」（内部点击开笔记/外部开浏览器）+ 部壹笔记预览外部来源可点；列表行/首页快照/recap 等派生视图一律不加。
5. **预填仅限命令入口**：`bz-knowledge-note-term`（选中词场景）自动带当前活动 md 笔记为来源、可一键清除；主窗「文字录入」按钮入口无上下文、不预填。
6. **附带同批**：主窗移动端真全屏（此前 `.bz-kb-window.bz-panel-mtop` 样式规则已备但从未挂载）+ 头栏移动端 ✕ 关闭出口（手机无 ESC、全屏后无遮罩边缘可点）；术语/添加弹层补挂 `.kb`（纸墨皮变量作用域缺失 → `var(--panel)` 失效、弹窗背景透明——现场目击 bug）。

## Considered Options

- 来源键复用 `related` / 复用视频的 `url`（均否：用户明确「related 是关联不是来源」——Obsidian 原生双链语义；`url` 在系统内是视频文献专属键，术语复用会让部壹预览/抽屉语义错位）
- 两段式类型切换（内/外先选再输入）：语义零歧义但移动端多一次点击、桌面多一个控件——被拍板单框智能分流
- 自由文本直存（手写 `[[双链]]` 或 URL）：实现最省但用户要背格式——否
- b 站 BV 号/短链特判（顺 b23.tv 自动补全）：对一家平台特殊化——否，宽松域名判定已覆盖粘贴出来的完整链接
- 来源喂 AI / 回写源笔记互链（与提炼成卡同构）：违背「录入轻快、无副作用」——否，仅记录+展示
- 移动端全盒全屏 / 弹层也全屏：用户拍板**仅主窗口**全屏，弹层维持浮层形态

## Consequences

- 术语文献 frontmatter 自五键扩展为「五键 + 可选 source/sourceTitle」，键序不变（date 后追加）；旧笔记零迁移（无 source 即不显示）
- 术语来源与「提炼成卡」的 related 源链在语义上明确两分：related=关联网（双向互链、Obsidian 反向链接），source=出处（单向溯源）；未来任何读侧都不得混读
- 内部来源以原生 `[[路径|名]]` 落键 → Obsidian 属性/反向链接面板原生可溯，术语文献与来源笔记自动出现在彼此链接视图
- 移动端主窗全屏的顶部避让统一交全站 `.bz-panel-mtop`（components.css 44px + 安全区）接管，知识盒自带规则只负责铺满几何与底部安全区——防止双份顶距
- 数据契约：`generateTermNote` 增可选 `source`（TermSource：external{url,title?} | note{path,name?}），序列化唯一入口在 `src/knowledge/source.ts`（`serializeTermSource`），UI/落盘共用
- 实现与验收细节见 `issues/257-knowledge-term-source.md`
