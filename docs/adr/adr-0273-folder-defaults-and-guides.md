# ADR-0273：域目录缺省留空，未配置走「本域形制」的引导

- 状态：已采纳
- 日期：2026-10-30
- 相关：ADR-0115（日记与回忆墙）、ADR-0087（影院接管影视）、ADR-0072（文献盒迁出）、
  ADR-0199（皮肤包区间校验）、ADR-0272（移动端启动开关）

## 背景

六个域（日记本、剪藏本、影院、书库、游戏库、知识盒）的目录设置一直有写死的缺省：
`我的/日记`、`归档/网页剪藏`、`我的/影视`、`书库`、`我的/游戏`、`文献盒` 等。

对老库没问题（值早就随 `data.json` 落盘了），对**全新库**有三层伤害：

1. **替用户猜位置**。新装用户打开日记本，内容写进了他从没同意过的 `我的/日记`；
   想换地方还得先去设置里找。
2. **猜错了就静默失败**。`diary/store.ts` 的 `addEntry()` 直接 `vault.create()`，
   不建父目录——全新库里 `我的/日记` 不存在就是 `ENOENT: ... open 'E:\...'`，
   给用户看的是磁盘错误，而不是「你还没定文件夹」。
3. **空值语义分裂**。设置里清空之后，读的地方各自回落字面量（`home/river`、`recap`、
   `smartcat`、`core/path-classify` 六处），于是「设置里是空的、后台还在扫老目录」——
   比配置错了更难查。

图片类目录（剪藏配图、影院海报、游戏封面、知识盒配图、书库封面）还有第四层：它们
本可以直接跟随 Obsidian 的附件位置，却让用户重填一遍。

## 决策

**1. 六个域的主目录缺省一律留空**，空 = 「未配置」。老库零影响（`data.json` 已有值）。

**2. 未配置时，域主界面自己给引导，而不是打开设置页/弹确认框。**
`core/folder-setup.ts` 里一张表（域 → 必填目录 / 可选图片目录 / 推荐值 / 设置分区），
`folderState()` 是唯一判定，`mountFolderGate()` / `folderSetupEmpty()` 是唯一渲染。
引导的形制**跟随本域皮肤**，不用 core 的通用空态卡（宿主配色 + 实心主钮贴进午夜场、
纸面期刊里都像另一个软件）：影院复用 `.cn-empty-page` + `.dm-btn`，剪藏复用纸面衬线，
知识盒用墨字墨线钮，剪藏移动端单独一屏。

**3. 两种空态严格分开。**
| 状态 | 长什么样 | 有没有按钮 |
|---|---|---|
| 未配置 | 引导卡「X 还没定文件夹」 | 「打开设置」（滚到该行并高亮） |
| 已配置但没内容 | 各域原有的空态（「这本册子还是空的」等） | 没有设置入口 |

**4. 图片类目录跟随 Obsidian 附件位置。** `core/attachment-dir.ts` 统一解析：
设置值 → `app.vault.getConfig('attachmentFolderPath')`（仅「固定文件夹」形态可跟，
`''` / `'./'` / `'./xxx'` 不跟）→ 域内缺省 `<主目录>/assets`。

**5. 空值必须一路解释成「该域不参与」。** 读取点不再回落字面量；后台活儿（资讯抓取、
日记预热、自动摘要目录监听、游戏库同步、影院豆瓣补抓）与写盘入口（网页剪藏、
`bz-diary-write`、`bz-cinema-add`）全部过同一道闸。

**6. 书库旧键一次性迁移。** `bookshelfFolderPath` 空而 `libraryFolderPath` 有值 →
写入新键并落盘，之后只认新键（否则老用户会被当成「没配置」，明明他早就有一个书架）。

## 代价与边界

- **每次打开都拦**（不是只拦第一次）：否则用户「先不用」一次就再也找不到入口。
- **引导卡上不列「还差哪几项」**（2026-10-30 用户拍板去掉）：点「打开设置」后由设置页
  高亮目标行，卡片只回答「为什么打不开」。
- **未配置时不写盘**：宁可什么都不做，也不要落到一个用户不知道的老目录里。
- 真正写盘时仍要**逐级建目录**（`diary/store.ts` 的 `addEntry` 已补）：用户自己选的
  目录同样可能还不存在，那次失败会直接吞掉他刚写的字。

## 后果

- 全新库第一次打开任一域 = 一张说人话的引导，不是错误页、不是空列表。
- 删掉了六处字面量回落与一条旧键回落链，`core/path-classify` 不再把没配置的路径
  认成某个域。
- 评审壳（`prototypes/*/prototype.html`）的「文件夹」开关随之扩成三档
  （未配置 / 空册 / 有内容），未配置档就是真实新库的第一屏。
