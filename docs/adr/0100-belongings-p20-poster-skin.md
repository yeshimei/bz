# ADR-0100：归物本「瑞士大字报」域内皮肤 + 完全原型化

P20 拍板落地。视觉为归物本专属（纸面 #f5f2ec/墨黑/赤橙海报 token + 大字网格 + 硬阴影弹窗），按铁律 6 以 `.bz-bel--poster` 等三壳作用域 token 覆盖 + 域内 `.bz-bel-*` 装饰类实现（先例：ADR-0097 收藏本亚麻、issue 210 待办皮肤）；按钮/输入/chip/segmented/空态/菜单/抽屉基线继续消费组件库不新造。头行跟进 issue 219b/c 完全原型化判例（删壳头行、⚙ 收敛、移动专属窄头行）。数据与交互契约零改动（同 ADR-0083/0089 就地重写范式）。桌面点卡新增详情弹窗（右侧动作菜单保留，issue 202 语义不冲突）。
