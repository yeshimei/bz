# ADR-0285：藏书票改版（读毕印章）与「读完」收录判据

- 状态：已采纳（2026-11）
- 涉及域：diary
- 关联：ADR-0230 / ADR-0130 / ADR-0284

## 背景

日记本一直是四类混排：日记、影视（观影票根）、信、书（藏书票）。书这一路有两个遗留问题：

1. **收录条件太松**：`parseBookFile` 用 `completionDate ?? readingDate` 定日期，只要写了书评，
   「在读」的书也会进册。用户要的是「读完并且有书评」。
2. **形态不统一**：藏书票是「EX LIBRIS 双线框 + 左封右文 + 右下日期」，和影票（撕口、虚线副券、
   横版海报）不是一套语言，同页出现像两个插件的东西。

用户 2026-11-05 要求给书做「跟影院票根类似、适合一本书」的设计，看过三版原型（借书卡 / 票根姊妹 /
藏书票升级）后**采纳「藏书票」**。

## 决策

1. **收录判据收紧为「读完」**
   - `parseBookFile` 只认 `completionDate`，缺失或非法即返回 `null`；`readingDate` 不再兜底。
   - 与书库 `status === '已读'`（`readingDate && completionDate`）同一判据，两处不会各说各话。
   - 书评非空的前提不变（ADR-0230）。
2. **藏书票形态（用户采纳的方案 C）**
   - 外层卡纸 + 内层双线框（2px 实线 + 内缩 7px 的 1px 细线）；顶部 `EX LIBRIS` 居中、两侧细线。
   - 主体左封面（74×104，无封面时斜纹占位）、右侧书名 + 署名行 + 书评。
   - 书评带 2px 左侧竖线（引文样式）、4 行截断。
   - 右下角压一枚**读毕印章**：58px 圆、双线红环、`读毕` + 年份 / 月日两行，旋转 -12°、半透明，
     `pointer-events: none`（点整张卡仍是抽书评全文）。
3. **`extra` 加性补字段**
   - `publisher` / `pages` / `readingTime`（frontmatter 原键 `publisher` / `pages` / `readingTimeFormat`）。
   - 署名行按「作者 · 出版社 · N 页」拼，缺项直接省略，不会留下 `· ·`。
4. **纸面语言分工**
   - 影票是横版票根、副券在右；藏书票是竖版卡纸、印章压角。同一套纸/墨/虚线材质，两种实物形态。

## 后果

- 「在读但写了书评」的书从**日记本**消失（书库数据与书脊墙不受影响）；存量入库条目下次加载即按新判据过滤。
- `DiaryEntryExtra` 仍是加性可选字段，不新增写入契约，`content` 语义不变。
- 藏书票与影票共享纸面变量（`--bz-diary-paper` / `--bz-diary-ink-*`），深色主题下仍是一件纸质实物。
- 印章压在卡片右下角外 14px；日记页内容区（`.bz-diary-page-inner`）左右各有约 25px 余量，
  窄屏等比缩小后仍不裁切。
