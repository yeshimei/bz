# 文献笔记统一携带文献类型与领域分类

所有文献笔记（视频/术语）落盘时 frontmatter 统一携带 `type`（`'video'`|`'term'`，文献类型）与 `domain`（领域，中文值）。领域词表由设置面板维护（textarea 逗号分隔），**缺省为空**（AI 自由写）；AI 自动分类，用户可在术语预览或笔记编辑时改。旧笔记（无 type/domain）打开面板时**自动补全**（type 启发式推断：有 url/author/videoTitle → video、有 term → term；domain 用 AI 分类；补过落库不再重复；AI 未配置跳过并提示）。理由：主面板按类型/领域筛选并展示双徽标、分类语义全库一致。取舍：备选「不补全旧笔记/补全前弹确认」因用户拍板自动补全而弃用。
