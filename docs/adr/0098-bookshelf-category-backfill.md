# ADR-0098：书库分类定纲与全库 frontmatter 回填

日期：2026-09-06　状态：已采纳　域：bookshelf　关联：issue 220、ADR-0096（书脊墙）

## 背景

书库 240 本 md 中 166 本有 frontmatter，仅 33 本写了 `category`，且 7 个存量取值粒度不一（科幻×11、哲学×7、心理学×4、龙与地下城×3、生物学×3、天文学×3、摄影×2）。书脊墙（ADR-0096）的分类分区装箱、分类标签行点选筛选、读书报告分类筛能力齐备，分类数据却只有两成覆盖。经 grill-with-docs 拷问拍板（Q1~Q5）：零插件改动，交付纯数据回填。

## 决策

1. **分类存字段，不存文件夹不存标签**：题材写书目 frontmatter 的单值 `category` 字段（插件既有消费链）。`书库/` 下 15 个作者/系列文件夹保持原样不动；`tags` 保持 `book` 常量语义（插件认书通道），分类语义不复用 tags。
2. **单层题材 12 类，一书一类**：文学 / 推理·悬疑 / 科幻 / 奇幻 / 武侠 / 戏剧 / 历史 / 哲学 / 心理学 / 社科 / 科学 / 艺术与摄影。跨类书定一个主类，不引入多分类（分组/筛选/报告均按单类走）。
3. **存量值归并**：龙与地下城→奇幻、生物学/天文学→科学、摄影→艺术与摄影；科幻/哲学/心理学原值保留。终值已正确的 22 本不碰。
4. **回填范围 = 166 本有 frontmatter 的书**：实写 144 本（改值 11 + 新增 133）。74 本无 frontmatter 的裸书（东野圭吾 39、莎士比亚 35）用户拍板不动，维持不可见。两本 EPUB（红楼梦、血与蜜之地）无 md 笔记、分类通道在 weave-data `subjects`（空），零改动约束下保持「未分类」。
5. **行级手术写盘**：只替换/插入 `category:` 一行——YAML 不重排、正文零接触、BOM/CRLF 逐文件自适应；写前演练核对计划、写后逐本复检（正文逐字节尾部守卫 + category 恰一行断言）。
6. **映射免审直写**：映射表不经人工审查直接落盘（用户拍板）；写错的修正路径=手改 frontmatter 或改映射重跑脚本，无迁移链。

## 后果

- 分类覆盖 33/166 → 166/166：文学 60、奇幻 22、科幻 21、推理·悬疑 18、哲学 9、戏剧 7、心理学 7、科学 7、历史 5、艺术与摄影 5、社科 3、武侠 2；书脊墙「未分类」分区只剩 2 本 EPUB。
- 4 本 tags 为空的书（克苏鲁神话Ⅱ/Ⅲ、情女怨 爱情的礼赞 乐曲杂咏 凤凰和斑鸠、鲁迅全集）已照写 category，但插件认书失败仍不上墙——可见性归 tags 修复，不在本次范围；鲁迅全集 `author: undefined` 字面量脏值亦未动。
- 沉睡的森林.md 的畸形游离键（`reading:`、`"":`）按「只动 category」纪律原样保留。
- 完整映射与判断口径记录于 issues/220；回填工具在 gitignore 的 `.scratch/category-backfill/`（演练/复检双守卫脚本 + 映射 json），不入库。
