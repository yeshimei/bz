# ADR-0216 · 录音旁音过滤（轮级后过滤 + 自适应门限，仅 dual 模式）

日期：2026-09-29 · 状态：已采纳 · 关联：ADR-0213（分离管线）、ADR-0214（工具收编）、issue 516

## 背景

用户诉求：用声纹质心过滤掉录音里的「环境音、杂音」（电视中的声音、音乐播放器里的）。读源码核实后，
这个诉求的边界比字面窄：

- **纯音乐 / 环境噪声基本已被拦掉**——VAD（fsmn-vad）只对**语音**响应，非语音段进不了滑窗。
  质心判不了"是不是人声"，它能判的只有"像不像这两人"。分工是 **VAD 管有没有人声、质心管是谁**。
- **真缺口是第三人语音**（电视里的人声）。现管线是**两态** Viterbi（我 / 对方），没有"都不是"的出口：
  `?` 只在 `mean_abs_llr < FLOOR(0.05)`（两质心分不开）时出现，而第三人语音往往 **|llr| 很大**——
  会被**很自信地**判成我或对方。后果不是"多一条脏数据"，而是电视台词被当成对方原话写进画像证据。

## 决策

1. **引入第三态「其他」（旁音，Side Speech）**，判定落在**轮级**：该轮全部窗口对「我 / 对方」两质心的
   `max(sim_me, sim_peer)` 均值低于门限 → 整轮判旁音。
2. **实现取轮级后过滤，不动 Viterbi**（否决三态解码）。理由两条硬的：
   ① 方案 C 的 97.6% 真值准确率是拿**两态**校准出来的资产，动解码器等于作废校准（要重跑 `rec_groundtruth.py`
   三方案对比）；② 旁音的正确粒度本就是轮级——一段电视声是一整轮，无需把窗口级抖动塞进状态空间。
3. **门限自适应**：`bz-face refs` 建质心时把 holdout（留出的自己人样本）的 `max-sim` 分布落成
   `other_threshold` 写进 npz meta，`rec` 读它；缺该键的旧 npz 回落经验常量。
4. **取向宁可漏滤**：门限取 holdout `max-sim` 的**最小值再留余量**（保证留出样本全通过）。
   理由：电话录音里对方的声音经窄带压缩，与微信语音质心的相似度本就会掉——门限偏高会把**真正的对方
   原话**判成旁音，两人对话变独角戏；而电视声与两人的相似度通常明显更低，低门限照样抓得住。
5. **只在 dual 模式启用**，me-only / blind 显式不做（不是"做错"）：me-only 只有「我」一个质心，
   对方与我的相似度天然就低——按"不像我"判旁音会把真正的对方全判掉；blind 连身份都没有。
6. **旁音轮落点 = 留账（sidecar 保留 turns）+ 不进仓**，与既有"空转写轮不进仓"同口径；
   speaker 字面值 `其他`（`turns[].speaker` 取值域扩容，旧账本照旧读）；录音行 meta 显示「已滤 N 轮」，
   并由「查看轮次」入口可复核（**误杀可肉眼发现**，这是第 4 条敢取宽松取向的兜底）。

## 后果

- 旁音轮不进仓 → 不计入 media 的录音计数 / 总时长，也不进画谱素材（正确：旁音不是证据）。
- bz-face 需发版（落门限 + 判旁音），插件 `capabilities` 版本门跟着抬。
- **`?`（不确定轮）口径不动**：ADR-0213 真录音复核已量过，方案 C 下"不确定时长 ≈ 0"，改它收益极低而
  口径变更面不小（media 计数 / 画谱 prompt / 统计）。这是**知情的有偏项**——`?` 轮照旧进仓并落在对方侧；
  若将来 `?` 变多（换了录音设备等），再按旁音同口径处理。
