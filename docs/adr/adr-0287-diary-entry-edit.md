# ADR-0287：日记正文「改字」——书内原地改写、日子时辰锁死、外部改动先拦

- 状态：已采纳（2026-11-06）
- 涉及域：diary（主）/ core（无）
- 关联：ADR-0130 / ADR-0131（条目文件）/ ADR-0233（写作内页）/ ADR-0284（双格式）/ ADR-0286（整篇无头行的原生日记）

## 背景

用户（2026-11-06）：「日记本中，还缺少修改的功能。」

现状：日记本便签菜单只有「打开笔记 / 换张贴纸 / 收进信封 / 誊录正文 / 誊录位置 / 撕掉」。
一篇日记落笔之后，在册子上就只能看——想补一句、改个错字，只能点「打开笔记」跳去 Obsidian
编辑器改，改完再自己翻回来；书仍是收起的，回来还得重新翻开。写链路（ADR-0233）是一次性的，
没有第二次入口。

用户同时定了两条边界（当轮拍板）：

1. 修改范围 = 日记正文（影视 / 信 / 书各有自己的地方，不在此列）；
2. **日子与时辰锁死**，改写时不允许改。

## 决策

### 1. 便签菜单加「改字」，复用书内写作内页

- 菜单项排在「打开笔记」之后，只对**非加密的日记条目**出现：
  加密条目的密文在保险库（ADR-0017），影视 / 信 / 书是别的域的资产。
- 点它把这一篇的旧字摊回 `.bz-diary-wsp`（ADR-0233 那张纸）：正文预填、日戳显示这一篇的日子、
  贴纸按原样盖好。纸切到**改字态**：按钮「作罢 / 改好」、纸脚「— 旧字重写 —」、
  日戳上的「改日子 · 时辰」小签收起（CSS 按 `.bz-diary-wsp-editing` 藏，`openCal('write')` 同时拦一道）。
- 纸上有字时的让路 / 收起确认与新建同一条闸：翻页 / 索引 / 台历跳日让路；收起前问
  「接着改 / 先收着 / 改好」。

### 2. 写层 `updateDiaryContent`：按文件形状分派，只换正文

- **entry**：重写该文件的正文；frontmatter 契约两键（`date` / `type`）与契约外键原样保留
  （N4 口径，与改标签同一段插回逻辑）。文件名、日期、时辰一律不动。
- **day**：定位块（filePath + 块头行号，其次时刻），只替换该块「头行之后到最后一个非空行」
  这一段；块头行、块后空行、其他块一字不动。正文行数变了，回刷后按新行号重新定位。
- **整篇无头行的原生日记（ADR-0286）**：这是 ADR-0286 预留的写回分支——整篇替换正文，
  **不写 `# emoji HH:mm` 头行**，写回保持无头行。追加 / 改标签 / 删除仍走严格解析拒写；
  这条只放开「正文」。
- 正文为空不落盘（返回 null）；正文与磁盘一致（只差首尾空白）视作没变、不写盘。
- 写成功发 `diary:content-changed`；墙订阅它并按**保阅读位置**回刷（不当作「新落一篇」甩回册首）。

### 3. 外部改动先拦：`expectContent` + 冲突确认

进入改字态时记下册子里那份正文（`expectContent`）；落盘时在**同一个串行队列任务内**重读磁盘比对：

- 一致 → 直接写；
- 不一致 → 抛 `DiaryContentConflictError`（带磁盘现文），UI 弹一张纸：
  「这篇在别处刚改过。要以册子里的这份为准，盖掉那边的改动吗？」——
  「先不改」留在纸上（字不丢，可再点改好）、「以册子为准」带 `force: true` 强写。
- 不静默覆盖：日记是手写的字，Obsidian 编辑器 / 同步盘那边的改动同样值钱。

### 4. 贴纸随改：先写标签再写正文

改字态里贴纸 chips 可点。落盘时若贴纸有变，先 `updateDiaryTags`（只换头行 / frontmatter，不动正文与行号），
再 `updateDiaryContent`。整篇无头行的原生日记**不放贴纸**（写层拒改它的标签，ADR-0286），
菜单里的「换张贴纸」也对它隐藏——别让人盖完贴纸才被拒。

## 后果

- 改一篇日记不再离开册子；改完停在原页，不会甩回第 0 页。
- 改字不改日子时辰：要改时辰等于给这篇搬家（entry 换文件名、day 换块头甚至换文件），
  撞名 / 顺序重排的边界不在本条内，另票再做。
- 改完触发一次整册回刷（现有防抖 400ms + 重读重排），大库上有一拍停顿，与新写一篇同代价。
- 冲突拦截只在「册子读到之后磁盘又变了」时触发；册子自己写完的回刷会把 `expectContent` 更新到最新。
- 菜单多一项；加密条目、影视 / 信 / 书的菜单保持原样。
