# ADR-0206：小橘消息池——静态语料退役，AI 动态池化（用一条删一条）

日期：2026-09-27 ～ 状态：Accepted ～ 关联：ADR-0172（关系内在生命，其 recentPicks 防复读机制随本决策废止）、ADR-0025（懂你上下文——本决策明确不沿用记忆注入）、ADR-0021（结构化 JSON 通道）

## Context

`src/smartcat/messages.ts` 的 SMART_CAT_MESSAGES 是移植自外部 SmartCatMessages.js 的静态语料库（2026-09-19 审计裁剪后余 5 组 437 条：PET 200 / CONNECTED 100 / WELCOME_BACK 75 / THINKING_IN_PROGRESS 50 / SETUP 12），消费点共 4 处（抚摸 / 启动连接欢迎 CONNECTED-SETUP 分叉 / 自言自语生成中占位 / 离开归来欢迎），另有两处散落消息库外的内联硬编码（index.ts 欢迎回来时段语料 12 条、interaction.ts 自言自语无 key 兜底 4 条）。

问题：

- 语料与小橘当前特性（PAD 心情 / currentEmotion / OCEAN 特质 / 关系阶段）完全脱钩——再低落也只会说「幸福得快要融化了」，人格成长（ADR-0023）从未传导到日常闲聊文案；
- 437 条手写文案长期无人维护，风格无法收敛；
- 域内自言自语 / 主动关心 / 书评等通道早已逐次 AI 生成，静态语料是异类；
- ADR-0172 的 recentPicks 防复读是给「大池随机抽样」打的补丁，治标不治本。

## Decision

**「AI 预生成弹药库，用一条删一条」**——消息文案的唯一家搬进数据文件：

### 1. 池化范围

- pet / connected / welcomeBack / thinking 四类型入池；
- **setup 无池**：它只在「未配 AI」时展示，而无配 AI 无从生成——物理约束，恒走兜底语料层（12 条精选 3~5 条，余删，git 历史留档）；
- welcomeBack 的时段内联语料删除——时段改为生成上下文信号，比 12 条死文案贴合；interaction.ts 无 key 兜底 4 条一并收编。收编后消息文案不再有第二个家。

### 2. 数据结构与落盘

`SmartCatData` 新显式段 `messagePool: { pet: string[], connected: string[], welcomeBack: string[], thinking: string[] }`（不设 setup 字段；旧数据缺省容忍，零迁移）。消费 = shift + 标脏，落盘复用 MemorySystem 30s tick 防抖合并写——崩溃最多重复弹一条已删消息，无害。

### 3. 补货节奏（全写死，不进设置面板）

- 水位：池内 < 3 条触发；批量：每批 AI 生成 10 条；
- 触发点：启动 + 每消费一条后惰性检查 + 既有 30s 心跳兜底；
- 节流：单飞锁（生成中不重复发起）+ 冷却 10 分钟 + 单日 6 批上限；
- 生成走 `callChatJson`（ADR-0021 response_format），失败静默不通知。

### 4. 生成上下文（轻量特性快照）

喂 PAD 心情档 + currentEmotion + OCEAN 头部两三个特质 + 关系阶段 + 时段。**不掺具体记忆内容**：池是提前囤的通用弹药，「懂你」的针对性表达走既有自言自语 / 聊天通道（ADR-0025）——囤时懂、弹时已过期的记忆是噪音。风格锚定 = 生成器内写死 few-shot 示例 3~5 条（从旧语料精选），保证删库后猫语气不漂移。

### 5. 兜底（三种落水姿势共用）

池空（冷启动首弹）/ 生成失败 / 未配 AI → 每类 3~5 条静态兜底语料。语义是「离线兜底」而非「消息库」（与皮肤包首套离线兜底同构）；兜底短窗重复不做去重（小池罕见场景，不值得机制）。

### 6. 退役

`messages.ts` 整文件删除（437 条 git 历史留档）；`getSmartCatMessage` / `MESSAGE_KEYS` / recentPicks（ADR-0172 防复读）随之废止——池消费天然不重复（用一条删一条）；4 处消费点换线到统一消费接口。

## Consequences

- 消息随小橘特性而变：低落时的抚摸不再是「幸福到融化」，人格成长第一次传导到日常闲聊文案。
- 消息质量上限取决于用户所配 AI；未配 AI 用户退回兜底语料（等效现状的极小子集，不哑）。
- 每批生成一次 AI 调用，成本受水位 + 冷却 + 日上限三重约束（极端日 ≈ 6 次调用）。
- smartcat.json 增长受控：池上限 = 批量 10 × 4 类型，满池增量几百字节。
- ADR-0172 防复读机制废止；若未来兜底层需要去重，另立决策。
- 测试面：池取用即删 / 持久化标脏 / 水位触发 / 节流三件套（mock AI）+ UI 池空降级路径。
