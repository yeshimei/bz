# ADR-0098：收藏本完全原型化（推翻 ADR-0097 的骨架保留）

Grill 拍板（issue 219b）：ADR-0097 只换皮未换骨，不合「完全抛弃旧 UI」意图。决定：

1. **完全原型布局**：左 rail、「全部/N条收藏/添加收藏」主头行、搜索+排序工具行、移动搜索展开行全部退役。面板结构 = 壳头行（品牌/⚙/✕）→ 头区（手写体「亚麻记事板」+ 主按钮「添加收藏」）→ 磁贴标签行 → 白卡墙。桌面 960×640；移动同重排（磁贴行横滑+单列卡墙）。
2. **主头行不豁免**：三要素融进原型头区——标题=筛选名、计数（「N 张白卡」）、新建=主按钮（ADR-0098 豁免形式：以原型头区形态承载主头行语义）。
3. **搜索/排序整体退役**（用户拍板「都删掉」）：UI 入口、防抖、haystack、排序浮岛全删；固定「最新收藏+置顶恒前」。设置键 favoritesSortKey 保留兼容旧存量但 schema 不再暴露（键退役）。
4. 磁贴行统一桌面/移动（data-fav-tag 委托，「全部」「已归档」字面值）；计数气泡收编共享 .bz-chip-cnt；触屏 44px 档保留。
