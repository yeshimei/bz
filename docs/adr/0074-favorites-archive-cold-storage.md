# 收藏本归档 = 纯冷存不可见

收藏本此前只有「置顶」一个条目状态；抽屉要加「归档」时的语义选择：备忘录式「完成即归档」、文献盒式「进历史区可查」、或可找回的软隐藏。用户拍板**纯冷存**（ticket 140）：归档条目从界面彻底消失（主列表/搜索/标签计数全排除），唯一用途是删除前的缓冲区——要的是「眼不见」，不是「第二视图」。

数据落地上 favorites.json 做加法扩展：可选字段 `archived` / `archivedAt`（旧数据无字段 = 未归档，零迁移照常可读；ADR-0067 文献盒同款先例）。配套拍板：

- **无 UI 反悔**：不提供取消归档入口（无查看面 → 抽屉也不会出现在归档条目上），误触靠手改 favorites.json 救回；smartcat 观察流记录每次归档（短文案「你归档了收藏《X》」，行为流 action `archived`），是「归档过什么」的唯一可读痕迹。
- **归档需 openFlowDialog 确认**：因无 UI 反悔，误触代价接近删除，不沿用置顶式原地生效。
- **批量余额跳过已归档**：冷存的大模型条目不再发余额 API（实现上由唯一装载点过滤自然覆盖）。
- **动作序**：打开 → 置顶 → 跳转笔记 → 刷新余额 → 编辑 → 归档 → 删除（归档贴删除之前）。

Considered and rejected：⚙️ 弹窗折叠救援组、命令撤销最近归档——都会引入查看面，与「纯冷存不可见」相悖。
