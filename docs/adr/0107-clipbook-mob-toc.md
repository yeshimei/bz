# ADR-0107：剪藏本移动端目录化（编辑部皮 + site 章 + 已收折叠）

日期：2026-09-08 ｜ 状态：采纳（issue 248）

## 背景

桌面编辑部印刷风（issue 214，p1-final）落域时明确「移动双屏维持标准组件库皮肤不动」；
移动列表 = 源横滑条（全部未读 / site 动态聚合 / B站 UP / 剪藏本）+ 卡片列表，已读条目
随时间沉底堆积（几十~一两百篇），无收纳结构。用户发起移动端编辑部化五套原型对照，拍板
m3 目录索引与两个决策（完整替换移动端 / 章粒度按 site）。

## 决策

移动端双屏的第一屏从「源横滑条 + 卡片列表」改为**全站章目录**：

- **章 = site**：与桌面 rail 同一聚合口径（aggregateSites：剪藏全量 + 未读 news 面，按
  url 排重不重复计数），章序 = 总数降序 → 未读降序 → 名 zh 序。
- **章内分区**：未读/在读常显（目录精短可扫）；已收（saved 语义）整段折叠成点线行
  「已收 N 篇」，点按展开/收起——历史再多不淹没待办，回看 = 展开整章。方案①获用户拍板。
- **检索例外**：搜索态命中条目全平铺（含已收），折叠不生效——找历史是检索的职责。
- **源横滑条退役**：章目录本身即导航（章头吸顶）；UP / 剪藏本聚合入口并入目录语义
  （UP 主名保留在条目标题侧信息，B站条目作者名经条目标题/meta 可见，专属浏览改走检索）；
  源级「全部标为已读」从源行动迁移到**章头长按**（buildRailActions 同一动作源）。
- **视觉**：推翻 issue 214「移动端标准皮肤不动」——移动端同族编辑部皮（消费 .bz-clip-frame
  的 --clip-* 纸墨 token：直角细线 / 衬线 / 橘章印 / 状态点墨点·在读空心圈）。刘海安全区保留。

  > **修订（2026-09-08，issue 248 追）**：首版落域被用户驳「与 m3 原型差异大」，按拍板原型**逐字覆盖**
  > ——顶栏刊名 + 「搜索 / 关闭」小字动作（关闭 = 清搜索并收全部，无复位态时退出面板）、章头无吸顶、
  > 无 44px 触控档（动作钮一律衬线文字，原型定稿）、条目为单行 flex（点 · 标题 · [在读] · 时间）、
  > 折叠 = arch.hidden 属性驱动（.on 类翻转箭头）、目录空态 no-hit 文案、详情屏2 为原型逐字（文字返回 /
  > 居中「站名 · 目录」/ 文字「存为剪藏」钮 / 期次行「第 n 则 / N」/ 纯字状态方章 / 细线 / 读下一则脚）。
  > 打开笔记入口改由条目长按抽屉承担（原型屏2 无此脚）。

## 取舍

- 已读条目在 site 粒度归章后可精确回看（站级展开），比旧列表沉底可寻址性更强；
- 折叠展开态模块级记忆，详情返回不丢；面板重开重置。
- 单站全站目录随剪藏增长（几十站可滚）可接受：纯已收站折叠态只占「章头 + 一行」。
- 拍板原型优先于触控热区等通用规范：文字小钮（44px 抬升档随 icon 钮一并退役）为原型定稿形态。
