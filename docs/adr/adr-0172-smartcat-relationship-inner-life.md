# ADR-0172：小橘「更智能」批——关系阶段派生 / 她自己的事 / 情绪惯性 / 记忆自动纠错 / 追问线

- 日期：2026-09-20
- 状态：已采纳
- 相关：issue 386；`docs/smartcat-companion-research.md`（八节路线第一、三、四阶段）、
  `docs/smartcat-mechanism-audit.md`、ADR-0021（GA 记忆流）、ADR-0025（懂你上下文）、
  ADR-0036（credibility）、ADR-0039（洞察版本化/supersede）、ADR-0043（prompt 槽位）、
  ADR-0069（引用型记忆）、ADR-0122（滚动条/渲染单源，本批不涉及）

## 背景

2026-09-19 的机制审计与社区调研得出同一个结论：**小橘不浅在机制，浅在连线**。
PAD / 30 特质 / trust·attachment / 缺席阶段算得很精细，但出口只有两个——显示层与 prompt 素材，
**零条流向行为决策**；另两条同源根因是「无自主情绪源（纯镜像）」与「无纵向时间（每条互动独立结算）」。

用户随后拍板两条硬约束：
1. 记忆与情感**全自动、黑匣子**——凡「手工纠错 / 打卡情绪 / 维护关键词 / 选关系」一律不合格；
2. 要从「陪伴工具」变成**角色**——她有自己的事、不在场也积累情绪。

同时 `bz-369-smartcat` 有他人在途工作（`proactive-life-*.ts`，主动臂池与文案），
本批**不碰 `maybeProactiveCare`**（A1 效用闸门 / A7 臂池 / F5 文案合一仍留给 369 落地后做）。

## 决策

### 1. 关系阶段派生，不让用户选（`src/smartcat/relationship.ts`）

trust 0.45 + attachment 0.25 + 互动量 0.20 + 相识天数 0.10 → 分数；五阶段门槛
（初见/熟人/朋友/知交/老友）**同时卡分数、互动次数、相处天数三项「且」关系**——防「刷分秒变熟」，
也防「日子堆出来却没互动」。`stageProgress` 取三项进度的最小值，避免显示 100% 却卡着不升级。

理由：Replika 的关系状态由用户手选，是社区排除表里点名的反模式（违反零配置）；
Knapp & Vangelisti 的关系演进本就是行为涌现，不该是设置项。

消费面只有三处：prompt（阶段 + 相处方式 + 越亲近越允许她直说）、数据面板感情卡、后续调度层（本批只导出 `initiative`，不接线）。

### 2. 自我披露：她有自己的事（`buildSelfDisclosure`）

按她自己的 PAD 档位 / 时段 / 特质 / 缺席天数 / 待回访线数，确定性地合成一段第一人称近况，
注入为 `### 小橘自己的事` 节。**输入不含任何用户数据**——这是「她有独立内心」的最小可落地形态
（Altman & Taylor 社会渗透：披露是双向的）。

用「日键散列」选文案（同一天稳定、跨日变化），不用 `Math.random()`——否则同一场对话里她的说法会来回跳。

### 3. 情绪惯性（`MoodSystem.inertiaFactor`）

衰减速率乘一个 **≤1** 的系数：
- 偏离基线越远越慢（U 形，正负同侧）；
- 愉悦 <35 额外 ×0.7（Gross 情绪调节：未被处理的负面滞留更久）、>70 ×0.85；
- 唤醒 >75 ×0.8、<25 ×0.9。

只作用于速率，**不改半衰常量、不改增益路径**——「今天就气到了，明天还有点余温」。
这是缺口③「纵向时间」的第一块。

### 4. 记忆自动纠错：两条失效通道，都不删数据（`memory.ts`）

新增 `REVISION_MARKERS`（不再/改成/其实不是/戒了/搬家…）作闸门；命中后与旧条目比对
「是否同一件事」用双重近似：**内容 bigram 重叠 ≥2**，或**共有 ≥3 字连续子串**
（后者兜住「不再喜欢跑步」vs「喜欢跑步」这类虚词差异导致 bigram 不足的情况）。

命中后按被命中条目的类型分流，**不另起第二套语义**：
- **洞察** → 复用 ADR-0039 的 `supersededBy`（「旧洞察被新洞察推翻」就是它的定义）；
- **观察** → 新增 `invalidatedAt` / `invalidReason` / `revisesIds`，事实过期就是过期，观察没有 supersede 语义。

观察额外把 credibility 折半（下限 0.05，不归零——判错时痕迹还在，面板可核对）。
失效条目不删除（085 拍板：记忆流不裁剪），只在 `retrieve` 与 `formatMemoriesForPrompt` 前置剔除。

中文分词没有词典可用，**用 bigram 近似**：整段连续汉字当一个 token 会让
「我不再喜欢跑步」与「用户喜欢跑步」重叠为 0，判定直接失效（这是实现期踩到的真坑）。

### 5. 记忆回显的不确定语感（`memoryHedge`）

低可信 →（记不太清）；注入特征命中 →（你当时随口一提，我没核实）；入库 240 天以上且从未被检索 →（模模糊糊记得）。
只加前缀，不动内容、不动排序、不动 GA 公式（冻结契约）。

### 6. 追问线：接住没聊完的话（`src/smartcat/open-threads.ts`）

从用户消息里**确定性抽取**含前瞻标记（改天/下次/还没/打算/明天/下周…）的整句，落
`editingData.openThreads`（同 `proactiveCare` 先例，不新增顶层字段 → 零迁移）。
关键词同样用 bigram；同话题再现 → 刷新而非新增；TTL 21 天；进 prompt 上限 2 条 + 6 小时冷却（防复读）。

了结判定偏保守：重叠 ≥1 且带完成标记，或重叠 ≥3 且本条不是新的前瞻句。
**误收会让她再也不追问，比漏收更糟**（漏收的自然被 TTL 淡出）。

不做「调 LLM 抽取话题」——那会变成每条消息一次调用，且失败时静默丢线。
模型只在 prompt 里看到「有这么几条线」，提不提由它按语境定（社区结论：好问题必须含前文出现过的内容，
Zhang et al. WWW 2020；小冰优化 CPS 而非「记得多」）。

### 7. 表达护栏（`prompts.ts`）

角色设定里固定写入：她是 AI、不是真人也不是心理咨询师；边界三条
（可以有脾气但绝不侮辱/不鼓励自伤/不操控；危机措辞先陪着再建议求助，不诊断不替代）。

### 8. 主动消息复读抑制（`messages.ts`）

`getSmartCatMessage` 记住每个 key 最近返回过的 3 条并从候选里排除（池子小则按池长自适应，
不会因「全被排除」返回空串）。原先纯随机：200+ 条池子看着丰富，短窗口内极易重复，体感就是群发通知。

## 后果

- 用户视角：她能说出「我们现在算什么」、会讲自己的事、会在被推翻的说法上自我修正、
  会接住上次没聊完的话、深夜里不再随机复读同一句。
- 数据：新增三个可选字段（`invalidatedAt` / `invalidReason` / `revisesIds`）与一个运行态数组
  （`editingData.openThreads`），**旧数据零迁移**（缺省容忍）。
- 成本：全部零 AI 调用；冲突检测只在命中修正语气时触发，且倒序扫描有上限（400 条）。
- 未做（有意）：A1 效用闸门 / A7 臂池换具体事件 / F5 文案合一（369 在途）；
  心境一致检索（`retrieve` 的 GA 公式是 096 冻结契约，改它需单独裁定）；
  沉默退让（涉及主动调度计数，同上）。
- 已知遗留（本轮发现，未修）：域事件与聊天消息经 `routing.ts` 落**行为流**，
  记忆流里的「用户事实」主要由 reflect/digest 承载——即用户当场的说法要经一次反思才进记忆。
  这属于路由契约层，改动面大，另开票。
