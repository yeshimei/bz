# ADR-0067: 聚合讯视频条目「保存至文献」——B站条目保存转向文献盒与跳过行为流静音

日期: 2026-08-28
状态: 已采纳
前置: ADR-0065（视频转文献面板与批量处理）；ADR-0066（文献盒 v2 与域事件分发）；ADR-0062（小橘行为流全量日志）；ADR-0029（聚合讯逐篇观察）；ticket 123（2026-08-27「跳过也发」拍板，本决策部分推翻）

## 背景

聚合讯阅读器的 B站条目是 UP 主视频投稿（platform='B站'，url 存视频链接），用户对视频的消费出口不是剪藏正文，而是文献盒的转文献流程。现状「保存至剪藏」会把视频简介当文章落盘 `归档/网页剪藏`，价值低；且保存/下一篇两条点击都进小橘行为流，视频场景下是噪音（grilling 拍板）。

## 决策

1. **按钮替换仅 B站视频条目**：阅读器底栏对 `platform==='B站'` 且 url 非空的条目显示「📥 保存至文献」（data-action="save" 契约不变）；果壳/知乎等普通文章保持「📥 保存至剪藏」原样（含原有小橘记录）。B站条目 url 异常缺失时回退原剪藏按钮，保证按钮永远可用。
2. **点击行为 = 打开文献盒添加面板**：新增 bili-downloader 导出 `openBiliAddTask(app, {url, title?, uploader?})`（ensureBiliTasks → showMain → showAddDialog 预填）；点击后**不写剪藏文件、不标已读（不动 state/read）、不发任何 'news' 域事件**；阅读器保持打开停在本篇未读，看不看下一篇由用户决定。弹窗层级/ESC 由文献盒侧承接（动态 z-index 机制另行改造，news 侧只调入口函数不碰层级细节）。
3. **添加弹窗新增「视频标题（可选）」「UP主（可选）」两个输入框**（手动 ➕ 打开同样可见可填）：`BiliTask` 增可选字段 `title`/`uploader`，旧数据零迁移（铁律 1 数据冻结的用户主动豁免：可选字段追加）；**仅任务元数据**——队列行优先展示标题（无则回退链接）、编辑弹窗可改；不进转换流程，外部 CLI（tools/bili-downloader）与文献笔记生成完全不动。
4. **下一篇行为流静音仅 B站视频条目**：`markAsRead` 对 B站条目不发 `'news'` read 事件（**部分推翻 ticket 123「跳过也发」——普通文章跳过仍上报**）；news.json 阅读统计照记（域统计与行为流分离，不受影响）。
5. **文献盒面板内保存任务的 added 上报保留**（ADR-0066 既有拍板）：小橘记「文献盒里添加了任务 BV…」这个真实动作，不记聚合讯侧的点击；不为聚合讯入口加来源标记（避免多一条跨域耦合）。

## Consequences

- 插件侧：reader.ts 底栏文案分支 + `saveToLiterature()`（跨域 import bili-downloader 入口，对齐 movie/ui → movie-report 先例，无环）+ markAsRead emit 条件；bili-downloader types/data/ui 三处可选字段 + 弹窗两输入框 + 行展示分支 + index.ts 新导出；smartcat 零改动（静音在 emit 源头）。
- 测试：news reader-literature 新文件（按钮分支/预填调用/不标已读不发事件/下一篇静音仅 B站）+ bili data/ui 用例扩充（字段持久化/旧数据零迁移/弹窗预填/行展示）。
- 已知限制：文献盒面板盖在阅读器上期间按 ESC，文献盒自身 keydown 与 escManager('news') 各自响应，可能一并关闭两层（待动态 z-index 改造统一 ESC 层级后自然消解）。
- 兼容性：命令 id、DOM 契约（data-action/弹窗既有 id）、news.json/bili-tasks.json 既有字段全部不变；「保存至剪藏」→「保存至文献」为用户主动要求的文案变更（铁律 1 豁免，仅限 B站条目分支）。

## 未采纳方案

- **全部条目换「保存至文献」**：普通文章没有视频链接，语义不通（用户拍板仅 B站条目）。
- **保存至文献同时标已读/自动跳下一篇**：面板里取消添加时文章也已被消费，语义错位（用户拍板留在本篇）。
- **下一篇全局静音**：保留 ticket 123 对普通文章的拍板，只对视频条目降噪（用户拍板）。
- **title/uploader 灌进转换流程**（文献笔记 frontmatter 直接用）：需同步改 tools/bili-downloader 外部工具，跨仓库范围扩张（用户拍板仅任务元数据）。
- **聚合讯来源标记以静音文献盒 added 事件**：多一条跨域耦合，且「添加任务」本身值得记录（用户拍板保留上报）。
- **只弹添加弹窗不开主面板**：脱离「添加弹窗必在主面板之上」的既有结构，ESC/遮罩/刷新语义要单独开分支（复用 showMain + showAddDialog 既有路径）。
