# ADR-0208：RSS 源库与黄页订阅模型——源库只是可下载目录，订阅唯一事实源仍是 rssFeeds

- 日期：2026-09-27
- 状态：已采纳（实现见 issue 495）
- 相关：ADR-0121（RSS 订阅源）· ADR-0128（抓取内置）· ADR-0203 / 0205 / 0207（统一下载清单与在线资源组）· ADR-0204（归物分类表，同型「在线 JSON 数据资产」先例）· issue 495

## 背景

剪藏本内置 RSS 订阅（ADR-0121）后，「找好源」成了上手门槛：用户得自己知道 feed 地址。
社区有成熟维护的中文源清单（timqian/chinese-independent-blogs，MIT，约 1350 条带 feed 地址），
适合出版为在线资源供用户浏览订阅（issue 494 盘点里的「剪藏源清单」候选即此）。

由此产生一个必须先定的模型问题：**「内置源」与用户订阅列表是什么关系？**
两个候选：

- **黄页模型**：源库只是一份可下载的目录资产；「订阅」= 把目录条目拷贝进 `news.json` 的 `rssFeeds`，
  与手动粘贴添加的源同权同生命周期；「已订阅」态按归一 URL 匹配现算，不落任何来源字段。
- **引用模型**：订阅列表记录「来自源库」，包更新时可批量跟随、按来源管理。

## 决策

1. **黄页模型**。源库（RSS Catalog，`downloads/rss-catalog.json`）是纯目录：`{meta, categories, feeds[]}`
   （`feeds[] = {url, title, site?, tags[], cats[], via?}`）。订阅动作 = `addRssFeed(url, title)`
   拷贝入库；删库、更新库、不再下载库，都不影响已订阅源。`rssFeeds` 是订阅的唯一事实源
   （CONTEXT.md 既有口径不变，词条只补「来路可以是源库」注记）。
2. **源库走统一清单 doc 通道**（ADR-0203/0207）：`DOCS` 登记 + `ROW_ORDER` 登记，在线资源组零代码出第五行；
   插件侧资产层 `core/rss-catalog.ts` 仿 ADR-0204 归物分类表范本（validate / load / download + 查询纯函数）。
3. **schema 预留 `via` 字段**（本期恒缺省）：RSSHub 等路由型源下期接入时，条目只存路由路径、
   抓取期按用户配置的实例地址解析，不需要改包结构。
4. **订阅免试拉**：从源库订阅跳过「试拉校验」（与自定义添加的口径有意分叉）——条目在出版期已过测活门禁，
   再试拉只会让订阅动作卡在网络上；入库后抓取失败走既有静默语义。
5. **出版期测活，剔除口径收窄为确定性死亡**：并发测活（16 并发、8s 超时、重试一次），
   只剔 404/410 与「200 但无 feed 结构」；403（反爬）/429/5xx/超时/连不上**保留**并在
   `liveness-report.json` 标记——测活视角是发布环境，连不上 ≠ 源死了，宁可保留也不误杀。

## 备选与否决

| 方案 | 否决理由 |
|---|---|
| 引用模型（订阅记录来源，包更新批量跟随） | 「跟随更新」的现实收益（feed 搬家自动跟）极少发生，不值双向绑定；`rssFeeds` 从唯一事实源变成两处事实源，删除/更新语义全要重定 |
| 源库内置进插件构建（main.js 常量） | 1350 条随构建分发且不可更新，违背在线资源通道；荒废 ADR-0203 已建成的下载校验链 |
| 源库自出私有清单（不走统一清单） | 正是 ADR-0204 要消灭的「第二事实源」——sha256 与更新判定另立一套 |
| 源库订阅也走试拉校验 | 出版期已测活 + 订阅动作卡网络，违背「即时反馈」的验收口径 |
| 测活剔除一切非 2xx | 403 是反爬不是死亡（实测技术小黑屋 403 而博客健在）；发布环境连不上的源（v2ex 类）对用户可能完全可用 |

## 后果

- 新增/更新源库 = `pnpm rss-upstream`（刷新快照）→ `pnpm rss-catalog`（转换 + 测活 + 出版）→ `pnpm manifest`；发布顺序在 `catalog` 之后、`manifest` 之前。
- 源库资产对插件是**可选**的：没下载的用户一切照旧（黄页模型保证零耦合）。
- 「已订阅」识别依赖 URL 归一匹配（`normalizeRssFeedUrl`），包内 url 与 `rssFeeds` 内 url 归一后比对；不存来源字段意味着**无法反向追溯**某订阅「来自源库」——这是接受的代价。
- 订阅免试拉意味着「源库出版后源死了」要等抓取轮静默失败才暴露；`liveness-report.json` 随仓库提交，是唯一的事后审计面。
- CONTEXT.md 词条「RSS 源库 (RSS Catalog)」与「RSS 订阅源」来路注记随本 ADR 落笔。
