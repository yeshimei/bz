# ADR-0154 · 番茄钟周归档层：7 天明细拍板不变，裁剪时按自然周落账

日期：2026-09-16 · 关联：issue 357、F13 保留窗裁剪（ticket 27/30）

## 背景

pomodoro.json 的 history 在落盘前裁到近 7 个日历日（F13，防文件线性膨胀），长期专注
统计因此无数据可用——「月底回顾这个月共专注多久」无从回答。放宽保留窗会重回膨胀老路，
与既有拍板冲突。

## 决策

1. **归档层独立于明细**：`trimWithArchive`（data.ts）在裁剪前把将离开 7 天保留窗的条目
   按自然周（周一起始，本地时区）聚合成归档行 `{week, count, minutes, tasks?}`，追加到
   pomodoro.json 新增可选段 `archived`。「history 只留 7 天明细」的既有拍板原样保留。
2. **周 key 判重增量合并（幂等口径）**：同一周不建第二行——`mergeArchived` 以 week key
   判重后增量累加（count/minutes/tasks 求和）。调用方保证每次传入的 history 只含尚未
   被裁的明细，同一明细至多入账一次；归档与装载（initData）同一次 save 原子落账。
3. **月趋势两源合成不重复累计**：归档行只含已离开窗口的日子、明细只含窗口内日子，按日
   恒不交；`lastNMonths`（stats.ts）把归档行整周记入其周一所属月 + 窗口内明细按日归集，
   合成近 6 月柱状档，与近 7 天档在弹窗统计区并列切换。
4. **零迁移**：旧 pomodoro.json 无 archived 段照常工作（读取容错归一，空段不落键），
   首周起算；任务分布（tasks）为可选字段，随「专注这个」归属自然积累。

## 后果

+ 长期统计有了持久数据源，文件增长从 O(每次完成) 降为 O(每周一行)，保留窗拍板零改动。
+ 聚合/合并/合成全部是 stats.ts/data.ts 纯函数，测试无需 UI。
− 归档从本版本启用才开始积累，此前的历史已按旧拍板裁掉，无法回填（接受的既有代价）。
− 跨月周整周记入周一所属月（月视图不拆分跨月周，口径从简）。
