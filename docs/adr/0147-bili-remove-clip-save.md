# ADR-0147 B站条目去除保存至剪藏入口（推翻 ADR-0068 分流保存）

- 状态：已接受（2026-09-16，用户拍板；**已实现**）
- 关联：ADR-0068（B站保存分流文献盒——本 ADR 推翻其剪藏本侧入口）/ issue 329 评审跟进 / issue 333
- 影响：`src/clipbook/ui.ts`（条目菜单 + 移动详情头栏保存钮）、`src/clipbook/flow.ts`（flowSave B站分支）、`CONTEXT.md`、相关测试

## 背景

B站条目（视频源）的「保存」自 ADR-0068 起分流到知识盒影像录入（打开录入 + 回写已处理态）。
整体评审指出其动线与普通文章保存不一致（保存后不自动前进）；用户拍板：**不去对齐动线，
直接去掉视频相关文章的「保存至剪藏」按钮和功能**。

## 决策

1. **B站条目不再提供保存入口**：桌面条目菜单不下发「保存到剪藏本」；移动详情头栏保存钮
   对 B站条目隐藏（`platform === 'B站'`）。
2. **flowSave 的 B站分流分支移除**，留静默守卫（`return false`）防程序化误调；
   知识盒影像入口（`bz-knowledge-note-video` / 主面板影像按钮）不受影响——B站链接录文献照常从那里走。
3. 打开即已读等其余动线不变；smartcat 行为流不再收到 B站保存事件（消费端按缺席容忍，无代码改动）。

## 后果

- 剪藏本里 B站条目只读 + 删除/复制链接等其余动作；视频入文献一律走知识盒「影像」。
- `news:saved` 事件对 B站条目不再产生；原「分流后回写已处理态」随之退役——B站条目留在收件流，
  由用户显式处理（已读/删除）。
- 存量数据零迁移（分流保存本就不写剪藏目录）。
