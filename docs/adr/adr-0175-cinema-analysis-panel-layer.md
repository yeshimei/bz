# ADR-0175 观影分析改为覆盖影院面板的一层：点遮罩关闭、去关闭按钮、基字号随层框派生

- 日期：2026-09-21
- 状态：已采纳
- 相关：ADR-0174（《观影志》26 幕重写，本 ADR 推翻其中「独立全屏放映室」的形态）、issue 409

## 背景

ADR-0174 把观影分析重写成独立全屏长片《观影志》：挂在 body 上铺满整屏，右上角自带关闭按钮，
与影院面板互不依赖（面板没开也能看）。当时（2026-09-21）的拍板原文是「独立全屏放映室，
**不镶嵌在影院面板里**」，这句注释还留在 `ui.ts` 的入口分支上。

2026-09-21 用户改口径：**把观影分析镶进影院**——面板大小刚好被它盖住，点遮罩关闭，
关掉就露出影院面板；右上角关闭按钮去掉。同日追加：侧栏底片在 AI 荐片页固定在入口上。

两条形态各有代价，值得记清楚：

- 全屏：沉浸（26 幕按整屏排），但它是「另一个房间」——从影院面板点入口，视觉上是换了一整套
  界面（纸面铺满、面板消失），退出靠一个只属于它的关闭按钮，与面板的导航体系（侧栏/入口）无关。
- 覆盖层：它是「影院的一部分」——同一块地盘、同一个出口（点外/ESC），面板在层下原样待命，
  关掉即回；代价是 26 幕要在 900×620 里排，且**基字号不能再跟窗口跑**（见决策 3）。

## 决策

1. **层几何 = 面板矩形**。观影志渲染成 ``.bz-yb`（fixed inset:0，透明，只接「点外部」）>
   `.bz-yb-box`（左/上/宽/高由面板 `[data-cinema-root]` 的 rect 写入，纸面背景与圆角与面板同）>
   滚动口 > 影片`。面板矩形在开层时量，窗 resize 与面板 resize 各跟进一次。纸面从整层收到框内，
   `--yb-*` 取色变量仍挂层根（`palette(root)` 口径不变）。
2. **出口 = 遮罩 + ESC**，桌面去掉关闭按钮。面板的筛选/滚动状态在层下原样保留（层不是视图切换）。
   移动端面板＝满屏、没有遮罩可点，**保留右上角关闭按钮**当显式出口。
   命令 `bz-cinema-analysis` 与侧栏入口统一为「面板没开先开面板，再盖层」。
3. **基字号随层框派生**，不再 `1.15vmin + 4px`：`clamp(12, 12 × min(w/900, h/620), 19)` px。
   面板是固定尺寸，而 vmin 跟窗口跑——大窗口下真机会把 26 幕排得比原型的 920×640 密一档；
   改成随框派生后，插件与原型观感一致，26 幕的排版只需在一种尺度上调准。
4. **侧栏底片（滑动高亮）在 AI 荐片页固定在点亮入口上**。原行为是 ai/stat 页 rail 整体熄灭、
   底片无「回落目标」而隐去；现在 tool 入口按视图带 `is-on`，底片常驻其上。
   观影分析入口不加（层盖住面板，停留点不可见）。

## 后果

- 26 幕的排版基准从「整屏」收敛到「面板」这一种尺寸，原型（920×640 iframe）即真机
  （900×620 面板）——两处不再各排一版感觉，门禁的截图复验也从此可信。
- 沉浸感让位给「影院的一部分」；层内的底栏（幕号/幕名/自动 + 进度线）与右侧 26 格刻度仍是
  层内自己的导航，不并入面板侧栏。
- 移动端的关闭按钮是**刻意的例外**（满屏没有遮罩），不是遗漏；哪天移动端有了别的退出路径，
  这个按钮应连同本 ADR 的决策 2 一起复核。
- 面板层与影院自身的弹窗层（详情/表单/合集）是**两套浮层**：观影志盖面板时面板内的弹窗不该存在
  （入口只在列表页出现），故不开浮层互斥机制；若将来入口挪进弹窗，需要重新审视 z 序与 ESC 分层。
