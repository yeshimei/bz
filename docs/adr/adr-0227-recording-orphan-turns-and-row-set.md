# ADR-0227 · 录音行的集合口径与孤儿轮次出口（行 = 磁盘 ∪ 仓 · 有账就得有门）

日期：2026-09-30 · 状态：已采纳 · 关联：ADR-0221（单条删除范围与确认强度）、
ADR-0217（起点与派生物落点）、issue 528

## 背景

用户实测：「大琳，我删除了录音之后，并入的录音统计还是 410 条，没有被删除」。

只读解锁保库复核，实况是：

| | 值 |
|---|---|
| `大琳/recordings/` | 目录空（mtime **2026-09-29 08:40**） |
| 仓内 `rec:大琳 周一 10点40分✔️.aac:*` | **410 条**轮次仍在 |
| `kindCounts.录音` / `stats.recordingCount` | **410** / **410**（`storeStatsOf` 从仓内消息数） |

时间线对上了：「删除同时清仓内轮次」的 ADR-0221 决策 1 落地于 **2026-09-29 15:15**，
而原件是当天 **08:40** 没的——早上那次删除走的是**旧口径**，仓内轮次就此成了**存量孤儿**。

但根因不止是「历史遗留」，而是**两个集合之间没有任何一致性约束**：

- **行的集合** = `readdirSync(recordingsDir)` —— ADR-0221 背景节已点名；
- **统计的集合** = 仓内 `rec:*` 消息（`storeStatsOf`）。

原件一旦不是通过删除入口消失的（外部删除 / 旧版本删除 / 同步工具覆盖），仓内轮次就同时满足
两件事：**永远参与统计** + **永远没有删除入口**（行随文件一起消失，没人能再点它）。
ADR-0221 决策 3「上锁即不删」只防住了**将来**的删除，救不了**已经发生**的孤儿。

## 决策

1. **行集合 = 磁盘文件 ∪ 仓内已并入文件名**（`suppStoreInfo.mergedRecs`）。差值即孤儿行。
   这条不变式是本次的核心：**删除入口的存在性与统计的真实性从此同源**，不会再出现「有账没门」。

2. **孤儿行照常渲染**（状态仍是「已并入」，不是新状态——仓里那部分事实没变），
   但徽章写「**源已失**」，行上注明「原件已不在磁盘 · 仓内 N 条转写轮次仍在统计与素材」，
   并在列表上方挂一条提示块，说清「为什么统计退不掉、去哪清」。
   **用户看到的 410 就是那个 N** —— 数字对得上，才有得信。

3. **孤儿行只留「删除」**：不给「改起点」「查看轮次」——原件与 sidecar 都不在了，这两个动作没有对象。
   删除走**既有** `suppDeleteRecording`：它逐项 `existsSync` 判断，磁盘项全跳过、仓内 `rec:<文件>:*`
   照清、`kindCounts` 与 `stats` 同权重算。**不为孤儿行新开一条删除路径**（两条路径必然漂）。

4. **确认面板对孤儿行改文案、去掉「同时删除录音原件」勾选**：原件早已不在，勾了只是空动作。
   文案改为「原件已不在磁盘——删除会清掉聊天仓里那 N 条转写轮次」。

5. **不自动清理**：沿用 ADR-0221 / issue 516 Q3「只报不清」的一贯口径。删数据是破坏性动作，
   给入口、说清代价，但**要不要清由用户点**；进页只提示，不动手。

6. **不动统计口径**：这次只改「行的集合」，`storeStatsOf` 一个字不改。
   统计永远如实反映仓里的事实；**让不该在仓里的东西离开仓，是行与删除入口的职责**，
   不是统计的。反过来把「磁盘存在性」并进统计会让数字撒谎（文件临时读不到就少报），不取。

## 后果

- 存量孤儿（如大琳那 410 条）有了出口：原声页 → 标「源已失」的行 → 删除 → 410 归零。
- 将来再出现「原件被外部删掉」，同一入口立刻可用，不必等下一次代码修复。
- 边界：孤儿行**只在** `mergedRecs` 刷新后出现（`refreshSuppStoreInfo` 完成即重画），
  首帧可能短暂不显示——可接受，它不是要抢的那一秒。
- 孤儿行默认落在列表末尾（按文件名排序），不插进正常行之间。
- 测试面：
  - render 纯层——徽章「源已失」、行上的轮数说明、提示块、确认面板文案、不给改起点 / 查看轮次
    （`tests/people/supplement-ui.test.ts`）；
  - ui 端到端——真临时数据根 + 真保库：孤儿行出得来、点删除后仓内轮次清零且
    `stats.recordingCount = 0`、原件还在磁盘时不出孤儿行
    （`tests/people/rec-orphan-528.test.ts`）。
