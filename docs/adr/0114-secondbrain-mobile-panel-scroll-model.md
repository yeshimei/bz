# ADR-0114：第二大脑移动端主面板整体滚动模型

- 状态：已采纳（2026-09-09，grill-with-docs 访谈拍板）
- 关联：ADR-0110（第二大脑定稿原型落域）、issue 251

## 背景

定稿原型落域后，移动端（≤768）主面板沿用了桌面式的「面板固定近满屏 + `.bz-sb-grid` 内部滚动」结构，
且 grid 内部的「最近向量化」「库摘要」卡自身还带第二层内滚（`.bz-sb-recent`/`.bz-sb-ai-txt`
overflow:auto）。窄视口下卡片被压成固定高的窗口，内容在卡片内部滚——用户实测反馈「卡片都在内部滚动」，
预期是卡片内容全部展开、整屏一起滚。

## 决策

移动端（≤768）主面板改为**整体滚动、双固定**：

1. `.bz-sb-panel-content` 是面板内**唯一**滚动容器（隐藏滚动条）；
2. 头行（标题 + 索引健康 + 入口钮）在滚动容器之外，天然吸顶；
3. 底部操作行（增量更新 / 全量重建 / 日志）`position: sticky; bottom: 0` 吸底，
   负边距出血到面板左右边缘；
4. 中间内容全部自然高度展开：grid 单列、解除 `.bz-sb-recent`/`.bz-sb-ai-txt` 内滚
   （overflow visible、flex:none），趋势图保持图表固有高度（100px）。

桌面端（>768）**保持现状**：双栏 grid + 卡片内部滚动（定稿原型拍板过的设计，本次不动）。

## 后果

- 移动端只有一层滚动，滚动条隐藏靠手势/滚轮，与移动端 App 页面手感一致；
- 头行信息（索引健康）与操作行在任意滚动位置常驻可达；
- 「最近向量化 最新 10 条」「库摘要」不再被裁切，长内容自然撑高；
- 桌面/移动共用同一 DOM（零结构改动），差异全部收敛在 @media 块；
- AI 对话 / 灵感参考的移动抽屉（MobilePanel）不在此模型内，不受影响。

## 修订（issue 272，2026-09-11）

用户拍板：移动端窄卡兜底（100vw-24px）升格为**真全屏**（100vw × --bz-vvh，根挂 .bz-panel-mtop 出 44px 顶部避让），与影院/收藏夹等全屏主页拉齐；头行补右上角关闭钮（同款 bz-sb-fbtn 图标钮风格，全屏无遮罩可点需显式关闭键）。滚动模型（panel-content 唯一滚动容器/操作行吸底）原样保留，仅几何升级。
