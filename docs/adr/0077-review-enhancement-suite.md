# ADR-0077：复习计划增强套件（算法拟合 + 负载可视化 + 统计时间线 + 队列调度）

日期：2026-09-03 ～ 状态：Accepted ～ 关联：grilling 会话 2026-09-03、ticket 174

## Context

复习计划（src/review/，FSRS v4 调度）存在四类缺口，用户经 grilling 会话逐项拍板增强方向：

1. **记忆算法不学习**：19 个权重 DEFAULT_W 写死（fsrs.ts），从未按个人复习历史优化；reviewHistory 每条已存 timestamp/stage/rating/stability/R，拟合输入现成但无消费方
2. **无负载预知**：逾期队列仅按 nextReviewDate 升序 + 每日上限截断，不知道未来 N 天哪天会爆仓
3. **无统计回看**：reviewHistory 有完整历史却无任何展示入口（无全局指标、无单条时间线、无 streak）
4. **队列无优先级**：没有任何人为干预维度（置顶/筛选/抽查/R 优先级全缺）

## Decision

一次交付四个方向（用户拍板全部一次交付，不分批）。核心决策如下：

### 1. 记忆算法升级：FSRS 参数自动拟合（自研纯 JS 优化器）

- **实现方式**：自研纯 JS 梯度下降优化器（前向传播复用 fsrs.ts 调度公式 + 对数似然损失 + Adam，约 200-400 行），**不引 WASM 包**。原因：npm 无纯 TS 现成优化器；官方 `@open-spaced-repetition/binding` / `fsrs-browser` 为 Rust 编译 WASM，输出对应 FSRS-5/6（非本插件 v4）需公式映射，且 Obsidian Electron 渲染进程有 WASM worker/cross-origin isolation/Node 版本集成风险，集成成本高于自研（子代理调研结论，2026-09-03）
- **先子集后全参**：首版只拟合 w[0..7]（初始稳定性/难度 + 遗忘幂律），验证管线跑通后再放开全 19 参数；从 DEFAULT_W 初始化 + 学习率退火 + 参数范围约束（稳定性/难度为正等），log-sum-exp 防溢出
- **样本门槛**：≥300 条有效记录 → 全参拟合；100~300 条 → 只拟合参数子集；<100 条 → 跳过（不拟合）
- **触发时机**：全自动定期重算（用户拍板，非手动）——**每完成 N 次复习自动重拟合**（N 可配，默认 10），异步后台跑，完成后轻提示；失败/样本不足静默回退默认
- **落盘与回退**：拟合参数独立落盘（`fitParams` + `fitAt` 时间戳 + `fitCount` 样本数），**不覆盖** DEFAULT_W；调度时优先读拟合参数、缺失则回退默认；提供「重置为默认」入口；拟合参数导致 interval 离群（比默认差 >5 倍）则弃用
- **铁律 1 解冻声明**：不修改现有数据格式、不重排既有排期语义；默认参数路径下行为完全不变（拟合参数是叠加的新消费路径）

### 2. 负载可视化：未来 N 天分布 + 日历热力图 + 今日/明日预告条

- **并入统计弹窗**（面板头部「📊 统计」按钮 → 独立弹窗内分区/tab 展示），今日/明日预告条固定显示在复习面板顶部
- 负载 = 各条目 nextReviewDate 落在某天的数量；未来 N 天分布支持 N 切换（7/14/30 天）
- 纯计算 + UI 工作，无数据格式变更（nextReviewDate 已存 ISO）

### 3. 统计与历史回看：全局指标 + 单条时间线

- **统计弹窗**（面板头部按钮）展示全局指标：总复习次数、连续天数 streak、评级分布、逾期率、平均 R 变化趋势
- **streak 口径（宽松）**：所有评级都算，同一天多次复习算 1 次，仅去重（用户拍板，非保守口径）
- **防刷指标**：同一天多次复习算 1 次（去重），不因重复评级刷高 streak
- **单条时间线为主**：卡片抽屉加「查看历史」动作 → 展开该笔记复习时间线（reviewHistory 回放：每次评级/间隔/R 变化）
- 入口：统计弹窗 + 卡片抽屉「查看历史」（用户拍板，双击名称仍为打开原文）

### 4. 队列调度与优先级：置顶 + 文件夹筛选 + 随机抽查 + R 优先级

- **手动置顶/星标**：列表/抽屉加星标按钮；置顶条目**先于逾期队列**排序；同时**仅列表置顶**（纯 UI 排序，不影响调度）；**置顶与 R 优先级互斥**（置顶生效时不参与按 R 重排）
- **按文件夹筛选**（砍掉标签筛选）：筛选栏 chips 输入文件夹名，即时过滤复习列表，不落盘；**不做标签筛选**（复习条目无标签元数据，且用户明确砍掉）
- **随机抽查模式**：面板内「抽查 N 篇」按钮 + 输入框，直接触发（无确认窗）；从计划随机选 N 篇进入做题/普通复习流程；**纯抽查不排期**（不改变 nextReviewDate，评级仍写 reviewHistory）
- **R 值自动优先级**：逾期队列内按 R 升序排（遗忘风险最高优先）；普通复习（跳转）也按 R；置顶之后排 R（第三优先级）；R 目标阈值设置页数字行（默认 0.9，低于则视为可复习/提前）

### 交付

一次交付全部四方向（不分批），单 ticket 追踪。

## Options

- **O1 引 WASM 官方包**（@open-spaced-repetition/binding / fsrs-browser）——❌ 对应 FSRS-5/6 需公式映射、Electron WASM 集成风险、cross-origin isolation 线程版必堵，成本高于自研
- **O2 标签筛选**——❌ 复习条目无标签元数据，需从 metadataCache 额外读取，用户明确砍掉只做文件夹
- **O3 抽查计入调度 / 独占本轮**——❌ 用户拍板纯抽查不排期（突击复习语义）
- **O4 置顶影响调度 vs 仅列表**——✅ 用户拍板「先于逾期队列 + 仅列表置顶 + 与 R 互斥」双轨并存
- **O5 streak 保守口径**——❌ 用户拍板宽松口径（所有评级计入 + 同日去重）

## Consequences

- 复习计划从「固定 FSRS v4 调度」升级为「个人化记忆曲线 + 可预知负载 + 可回看历史 + 可干预队列」
- 新增设置项：拟合开关/每 N 次重算、R 目标阈值；新增 review.json 拟合参数落盘字段（fitParams/fitAt/fitCount）——**新增字段不破坏旧数据**（读取侧兜底，符合铁律 1）
- reviewHistory 从「只写不读」变为统计/时间线/拟合的数据源
- 文档：CONTEXT.md「复习计划」词条更新、spec.md 设置项总表、issue 174
- 测试：数据层（拟合计算、streak 口径、负载聚合、R 排序）+ UI 层（统计弹窗、时间线、置顶/筛选/抽查交互）全量
