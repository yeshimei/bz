# 洞察条数上限 + 记忆来源分布按追查目录 + 小橘对我的称呼

ticket 162 把「洞察条数」交给 LLM 自定（`smartcatInsightCount` 退役），但实测 AI 一次能产出 10 条——用户拍板要回一条硬上限（默认 3，设置面板可调）。同期用户在使用数据面板「记忆来源分布」时指出两个展示口径问题（note 引用条目被统标「记忆目录」、洞察完全不计数），并追加一个陪伴体验需求（小橘可用设置的称呼叫我，默认「包仔」，喂 AI 的记忆/行为内容里「你/用户」替换为称呼）。三事同源——都是「记忆流/行为流对外表达」的口径修正，合一票落地。

## 决策

### 1. 洞察条数上限（smartcatReflectMaxInsights）

- 新设置 `smartcatReflectMaxInsights`（默认 3，⚙️ 小橘设置「记忆巩固」组 number 行 1-10）。
- `getConsolidationConfig()` 增 `maxInsights`：负数回退 3、0 钳制到 1（0 无意义）。
- 反思 prompt 从「条数由你根据记忆内容自行决定」改为「最多 N 条（宁缺毋滥，超出只取最重要的）」；LLM 返回 `insights.slice(0, N)` **硬截断兜底**——prompt 声明是引导，截断是铁闸（LLM 不听话也超不出上限）。
- `smartcatInsightCount` 仍是退役键（ticket 162），新键独立，data.json 残留值忽略。

### 2. 记忆来源分布口径（dashboard 记忆页）

- **洞察计入**：type=insight（含周报洞察 source=weekly-report）按「洞察」单列一行——此前完全不计（只统计 observation），用户明确要看到。
- **note 引用条目按追查目录分行**：`source=note` 的条目（记忆目录流，description 存 ref 路径）不再统标「记忆目录」，而是按设置页「记忆目录」配置的**追踪目录**分行——`resolveTrackedDirLabel(m, dirs)`：ref 路径（或 description 路径段）前缀匹配首个配置目录 → 标签 = 该配置目录字符串（如「我的/信」）；未传目录/未命中 → 回退「记忆目录」旧标签（兼容无配置/已移除目录的存量数据）。与 `note-memory.resolveOwnerDir` 同语义，纯函数仅服务展示层。
- **行为小结保留**：source=digest 的 observation 仍显示「行为小结」行（用户确认保留）。
- 最近记忆列表 note 行标签同口径（「我的/信」而非「记忆目录」），与卡片一致。

### 3. 小橘对我的称呼（smartcatUserName + replaceUserReference）

- 新设置 `smartcatUserName`（默认「包仔」，⚙️ 小橘设置「互动」组 text 行）。
- `replaceUserReference(text)`：把记忆流/行为流内容里指代用户的「你/你们/用户」替换为称呼。单趟正则 `你们|你|用户` + 替代回调（正则引擎左到右匹配，`你们` 优先于 `你`），不会二次扫描引入的称呼。
- **只作用于喂 AI 的 prompt 文本，不写盘**（存储格式冻结——铁律 1）；只在「把记忆/行为内容喂给 AI」的调用点应用：
  - formatMemoriesForPrompt / formatMemoriesForPromptWithRefs（聊天相关记忆、主动关心、懂你上下文）
  - 反思证据编号行 + 原文摘录、行为小结行为文案行、情绪追标编号行
  - 周报洞察清单行、特质归因洞察行、懂你上下文块生成行（「你通常在…」「你和小橘的关系」）
- **边界（刻意不做）**：模板/人物设定句不做替换——「你是小橘」中「你」指小橘（AI 自身）；候选既有洞察块头「你既有的相关洞察」同样指小橘；dossier 叙事输入为模板拼装（无「你/用户」）不替换；打分/书评等非「调用记忆流/行为流」的通道不动。

## Considered and rejected

- **只改 prompt 文案不加硬截断**：LLM 输出不可控，10 条复现说明光靠提示没用——必须 `.slice(0,N)` 铁闸。
- **替换写回存储**（description 直接改）：破坏记忆流原始数据与 dossier 正则匹配（「你读完了《X》」等句式是冻结契约）——只在 prompt 拼装时替换。
- **候选块也做称呼替换**：块头「你既有的相关洞察」的「你」指小橘，整块替换会扭曲语义——块内描述保持原文（防重复参照材料，主内容路径已替换，一致性影响可忽略）。
- **来源分布给「我的/日记」也按追查目录分行**：日记目录条目 source=diary 已在来源表（「日记」），无需再分行。

## 存量数据兼容

零迁移：三个新设置键缺省即生效（称呼默认包仔、洞察上限 3）；来源分布为纯展示口径，不触碰数据；旧 note 条目（未命中配置目录）回退「记忆目录」标签照常显示。
