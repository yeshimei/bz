# 0013 黑匣子条目 schema 第一版定全（为 AGI 预留维度）

黑匣子（bz 第 19 域）的数据单元经 grilling 演化为**三类条目 + 派生层**，全部冻结于 v1：

- **概念与实体**：纯知识卡片（名称 + AI 生成定义 + AI 自动构建的关联），**无感触外壳**；
- **文献笔记**：摘抄文本 + 来源 + 名词表关联（AI 提取概念供用户勾选）；
- **核心知识**：用户想法；
- **感触外壳**（文献/想法持有）：时间（自动）+ 情绪标签（24 词固定词表，单条最多 3 个，**无强度**——用户决策去掉 1-5 强度）+ 涉及的人（画像选择器）+ 场景/指向/链接（可选）；
- **派生层**：人物画像（印象字段级锁 + AI 观察区 + 事件投影 + 情绪聚合）与事件（全自动提炼 + 推测标记），字段同样 v1 冻结。

用户决策：维度"越多越好"，理由是"现在还没有实现 AGI，但尽量把多的维度写进去，在以后可能会有帮助——AI 记录了我此时此刻的所有"。项目铁律「数据格式稳定」（`CONFIG/STORAGE/*.json` 字段一律不改）使 schema 一旦落盘即不可逆，维度与词表必须在 v1 定全。决定：**字段、情绪词表（24 词）、条目类型在 v1 冻结**，后续只加语义不改字段；录入弹窗默认只展示必填项，可选维度折叠展开（维度全、默认全空），以平衡录入负担。

**Consequences**: 未来 AGI/次级内容读取直接消费结构化字段，无需迁移；若日后确需新维度，只能以版本化扩展（如 v2 并存）而非改字段，代价高于首版深思熟虑。情绪词表扩展同理（改词表 = 改代码 + 升级，不改存量数据）。
