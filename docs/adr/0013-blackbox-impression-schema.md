# 0013 黑匣子感触条目 schema 第一版定全（为 AGI 预留维度）

黑匣子（bz 第 19 域）的基本单元「感触」承载多维字段：必填（时间/素材/感受）+ 情绪（24 词固定词表，单条最多 3 个 + 强度 1-5）+ 可选（场景/涉及的人/指向/链接）。用户决策：维度"越多越好"，理由是"现在还没有实现 AGI，但尽量把多的维度写进去，在以后可能会有帮助——AI 记录了我此时此刻的所有"。项目铁律「数据格式稳定」（`CONFIG/STORAGE/*.json` 字段一律不改）使 schema 一旦落盘即不可逆，维度与词表必须在 v1 定全。决定：**字段、情绪词表、强度语义在 v1 冻结**，后续只加语义不改字段；录入弹窗默认只展示必填项，可选维度折叠展开（维度全、默认全空），以平衡录入负担。

**Consequences**: 未来 AGI/次级内容读取直接消费结构化字段，无需迁移；若日后确需新维度，只能以版本化扩展（如 v2 并存）而非改字段，代价高于首版深思熟虑。情绪词表扩展同理（改词表 = 改代码 + 升级，不改存量数据）。
