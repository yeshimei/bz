# ADR-0138 AI 语义挂载建议：词句级锚点，不挂 related

- 状态：已接受（2026-09-14，挂载画布评审拍板；设计定稿，未实现）
- 关联：ADR-0137（卡片挂载点）/ issue 298（link agent 迁移搁置——本 ADR 是其复活形态）/
  ADR-0135/0136（知识盒录入）
- 影响：`src/knowledge/*`、`src/secondbrain/*`（向量检索复用）、`src/core/link-now.ts`（LinkBridge 语义改造）

## 背景

ADR-0137 的自动挂载以 frontmatter related 为源——related 是「整篇对整篇」的粗粒度链接，
且知识盒关联分析、link agent、用户落卡都在写同一个键，语义混装。

用户拍板：**不挂载 related**。AI 改为按内容语义匹配，粒度细化到——
正文中的**每个词或某一句话**，可以和另一篇笔记的**某一段、一个标题或整篇**产生关联建议。

同时采纳挂载画布的后续功能清单（见文末），其中「AI 建议挂载」由本模型承接。

## 决策

### 1. 建议的最小单元 = 「锚点 → 目标」

- **source 锚点**：卡片正文中的词或句子（位置锚定，即原型中的圆点锚点）
- **target**：另一篇笔记的整篇 / 标题+内容 / 段落（块引用）/ 图片 / 视频 / 卡片（六类形态不变）
- AI 产出候选 = {锚点位置, 目标, 形态, 置信度/一句话理由}；呈现为虚线 + 「AI 建议」徽标

### 2. 不写 related

- AI 建议只存在于画布的候选层，**不落 frontmatter related**——接受 Obsidian 图谱看不到 AI 建议
- **固定** = 用户认可该建议：在正文锚点处写入 `[[wikilink]]`，建议转为用户双链（实线）
- **取消** = 丢弃候选，锚点还原为普通文本
- related 键回归单一语义：只承载用户显式双链（含落卡互链），不再被 AI 写入

### 3. 检索与产出链路

- 复用第二大脑向量索引（块级 chunk 已有，ticket 110 起剥 frontmatter、标题并入首块）：
  词/句嵌入 → 近邻召回 → AI 裁判（沿用 link agent 的「只链实质关联，存疑不链」原则）
- 产出时机与知识盒录入的关联行同频（AI 出内容即起跑，`link-now` LinkBridge 语义改造）

### 4. 建议按卡生成，展示按主卡过滤（2026-09-14 补充拍板）

- 每张卡都以**自身为主卡的视角**生成建议集——包含指向其他卡、乃至指向其父卡/祖先的条目；
  回指建议是真实数据，不删除。
- 单向流只是**展示层规则**：画布以当前主卡为根做方向过滤，指回祖先的建议隐藏
  （该关系若已由父侧的建议表达，则不重复显示）。
- 切换主卡 = 切换视角 = 切换可见的建议集；同一份建议数据在不同主卡下呈现不同的子集。
- AI 建议徽标只标在当前主卡上。
- 弱关联（仅任务级/提及级，无实质语义关联）的建议不在画布显示；与当前主卡无直接关系的卡片（二度建议/链目标）也不显示——切主卡即切换整套可见集。

### 5. 挂载画布采纳的功能路线图（2026-09-14 拍板）

采纳：反向视图、引用计数徽标、孤儿卡检测、面包屑+树内定位、布局持久化、拖拽改父、
盒外双链来源标注、AI 建议挂载（本 ADR）、复习域到期联动、smartcat 行为流接入。
不做：结构笔记/MOC、画布内提炼成卡。

> **2026-09-14 修订（ADR-0139）**：**布局持久化（⑥）作废**——白板位置零落盘、改用力导向确定性种子（ADR-0139 §2）。其余项的落地口径另见挂载树实现包：反向视图 = 右键「看谁挂了我」临时翻向；引用计数只数用户双链；孤儿卡检测落卡片列表筛选 + 标记；面包屑+树内定位与上四项同包交付；拖拽改父 / 盒外双链来源标注 / 复习联动 / smartcat 行为流仍留后续。

## 后果

- related 语义单一化后，Obsidian 图谱/反链面板只反映用户双链——AI 建议的可见性完全依赖挂载画布
- 词/句级锚点要求正文位置在编辑后可重定位（按文本内容匹配而非字节偏移优先）
- 检索量 = 词句数 × 全库块数，向量化与裁判成本需要批处理与阈值控制（沿用 link agent 的批次/锁经验）
