# ADR-0103 · 影院风格框架：单键三风格 + 午夜场语言共享件

日期：2026-09-07 ｜ 关联：issue 236、issue 232（原型批）、docs/prototype-first.md

## 背景

影院域内原型（探索稿五版 → 拍板三风格 → 午夜场完整功能版）定稿后落域。皮肤层已拍板砍去
（每风格仅一套视觉），需要决定风格在插件中的接线方式。

## 决策

1. **单键三风格（分批上岸）**：清单唯一事实源 `CINEMA_STYLES` 上岸 `constants.ts`；设置键
   `cinemaStyle`（默认 `midnight`）为扩展口。用户拍板：本批仅午夜场实现上岸，设置 schema
   暂不出「风格」行（仅一风格时无选择意义），gazette/booth 落地时补行。不做皮肤层；若未来加副肤，
   扩展口是 `.bz-cinema-skin--<id>` 纯 token 覆盖块（亮暗成对），不写结构规则。
2. **风格 = 面板壳级分支**：`createOverlay` 按风格渲染对应 desk 壳（桌面 900×620）或 mob 壳
   （移动独立自绘 DOM，真全屏挂 `.bz-win-mfs`）；重开面板生效。
3. **共享件以午夜场视觉为通用语言**：详情/表单/菜单/抽屉/确认/AI/分析只有一套（午夜场语言），
   三风格共用。实现上弹窗宿主是 `display:contents` 的 `.bz-cinema--midnight` 锚类容器，
   共享样式（scoped 在午夜场锚下）对任意风格面板生效，CSS 零复制。
4. **两套壳各自完整，非缩放**：desk 与 mob 是两套 DOM（原型 1:1），按 `Platform.isMobile`
   渲染其一；共享业务层（数据/事件/持久化）不分叉。
5. **落域适配显式登记**（原型不出，非视觉调参）：移动头行补 ✕ 关闭钮（真全屏无遮罩可点；
   先例收藏本 issue 228）；演示按钮（模拟失败）退役；分析页空态「添加影视」动作保留
   （ADR-0090 功能面）。

## 后果

- 域内 CSS 三段（午夜场/场刊/放映室）+ 共享弹窗段 + 落域适配段，全部 scoped 在锚类下，
  特异性 ≥0,2,0 抗 core reset。
- 旧组件库面板骨架（bz-panel-head/bz-rail/bz-main-head/bz-mobstrip）在影院域退役，
  core 共享类不受影响；域内自绘菜单/抽屉沿用 issue 227 豁免先例。
- 后续加风格 = 新增锚类段 + CINEMA_STYLES 项 + 设置选项，共享件不动。
