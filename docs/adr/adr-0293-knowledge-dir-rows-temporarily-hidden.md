# ADR-0293：知识盒设置暂时只暴露文献目录（卡片 / 主题两行隐藏）

- 状态：已采纳
- 日期：2026-11-07
- 相关：ADR-0112（三部重构）、ADR-0141（三盒为自动关联范围）、ADR-0273/0274（域目录与未配置引导）

## 背景

知识盒的「目录与分类」组原本暴露五个目录相关项：文献文件夹、图版图片文件夹、卡片文件夹、
主题文件夹、领域词表。2026-11-07 用户明确：知识盒的实际使用只需要配文献目录，卡片与主题
两个目录平时不调，先把这两行从设置面板收起来。

这两项与普通可选设置不同——它们同时是**未配置闸门**的必填字段（`core/folder-setup`）。
只藏面板不动闸门，会出现「面板里没有可填的行、空态却永远消不掉」的死锁：用户配完文献仍进不去
知识盒（`folderState('knowledge').missing` 里还挂着两个没有入口的键）。

## 决策

1. **面板不暴露**：`knowledgeSettingsSchema` 的「目录与分类」组在构建 schema 时过滤掉
   `knowledgeCardboxDirectory` / `knowledgeTopicDirectory` 两行（`HIDDEN_DIR_SETTING_KEYS`）。
   在 schema 层过滤而不是加 `visibleWhen: () => false`——组卡项数、可见项计数、移动端
   「设置项」搜索缓存三处都以 schema 行表为源，留空壳行会让三处各算一遍（搜索还会命中一行
   点进去看不见）。
2. **退出闸门**：`FOLDER_PLANS.knowledge.fields` 同步摘掉这两项，只留文献文件夹（必填）与
   图片文件夹（图片类永不参与闸门）。空态行为随之变成「配好文献即可进域」。
3. **其余一律不动**：设置键、缺省名（`卡片盒` / `主题盒`，`core/knowledge-boxes`）、部贰/部叁
   的扫描展示、自动关联的三盒范围、第二大脑索引语料、老库里已填的旧值，全部照旧。卡片 / 主题
   目录按缺省名或旧值继续工作。

## 后果

- 设置面板里知识盒的可见项从 22 降到 20（`tests/sp-contract-lock.test.ts` 基准同步）。
- 面板改不了卡片 / 主题目录了；老值仍生效，但暂时没有修改入口。这是「暂时隐藏」的代价，
  恢复方式写在代码注释里：删 `HIDDEN_DIR_SETTING_KEYS` 与 rows 末尾的 filter，把
  `folder-setup` 两行加回，基准 +2。
- 图版图片文件夹保留，其默认落点仍是 `<卡片文件夹>/assets`；卡片目录不在面板上时，用户
  看到的是「卡片盒/assets」这个固定缺省，要改只能单独填图片文件夹（用户 2026-11-07 确认保留）。
- 空态文案（`四类各放一处：长文献、卡片、主题，外加配图`）与「自动关联」组的三盒说明按用户
  要求保持原文，不随本次隐藏调整。
