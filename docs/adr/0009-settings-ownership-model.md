# 0009 — 设置归属模型：全局设置页 + 域设置弹窗 + 共享数据路径

## Status

Accepted（grilling 会话敲定，2025 用户决策）。

## Context

初始实现把全部域设置集中在 Obsidian 设置页 `BzSettingTab`（12 个 tab：AI、备忘录、日记本、归物本、剪藏本、密码本、收藏本、书库、影视、复习计划、AI Agent、闪念）。问题：

- 改一个域的行为项要翻设置页并定位 tab，设置不就近；
- 部分面板右上角已有 emoji 按钮，但名不副实——影视的 ⚙️ 打开的是「筛选与排序」弹窗，书库的 ⚙️ 打开的是「视图与筛选」弹窗（均为筛选类，非设置）；
- 各域数据文件路径字段（todoFilePath、belongingsDataFolder、pwStoragePath、favoritesStoragePath、reviewStoragePath、META_PATH、VEC_PATH 共 7 个）默认全部指向 `CONFIG/STORAGE`，重复且无独立配置价值；
- 备忘录、归物本、收藏本、日记本、剪藏本、密码本、复习计划等面板无设置入口，设置项只能从设置页改。

## Decision

1. **设置归属两分**：全局项留设置页，域行为项进各功能主面板右上角 ⚙️（域设置弹窗）。
2. **全局设置页单页化**：`BzSettingTab` 去掉 12 tab，改为单页平铺，只含两个区块——「🤖 AI」（AI 服务商、DeepSeek/OpenCode Go API Key）与「📂 数据存储路径」（共享 `storagePath` 一个字段）。
3. **共享数据路径**：新增 `storagePath` 字段（默认 `CONFIG/STORAGE`），7 个 JSON 数据文件路径字段统一由它收敛；旧字段保留在接口与 data.json 中（兼容读取、降级不破），UI 不再暴露。迁移规则（首次加载）：旧 7 字段全部相同 → 用该值初始化 storagePath；参差 → 用默认值并启动 Notice 列出被忽略的自定义路径。
4. **域设置弹窗**（⚙️，复用各域 modal 风格，可下沉 core 工具）：
   - 备忘录：启动时自动弹窗；
   - 日记本：日记目录、影视目录、信目录、每批加载数量、显示标签计数、使用文件日期；
   - 归物本 / 收藏本：空弹窗（无任何设置项，仅保持入口一致性）；
   - 剪藏本：剪藏目录、每批加载数量、自动摘要开关（仅这三项）；
   - 密码本：密码生成字符集、密码生成长度、安全模式；
   - 书库：书库文件夹、读书笔记路径、书籍识别标签、显示文件大小/阅读时长/划线数/想法数/书评摘要；
   - 影视：影视文件夹、每页加载数量、海报抓取提示；
   - 复习计划：检查间隔、启用逾期通知 + 做题家 5 项（允许多选、每笔记题目数量、打乱顺序、难度、做题决定难度）；
   - 闪念：17 项全量（含 AI 项，Ollama URL/模型/DeepSeek 模型等）。
5. **筛选弹窗独立图标**：影视「筛选与排序」、书库「视图与筛选」统一改挂 🔀；⚙️ 只表示真设置。
6. **内容目录字段不进共享路径**：日记目录、剪藏目录、书库文件夹、影视文件夹等笔记目录各域天然不同，保留各自字段，归各域设置弹窗（书库/日记/剪藏/影视 ⚙️ 内）。
7. **AI Agent 设置不暴露**：aiAgentEnabled / enableAIClipMatch / aiAgentWatchedFolders / aiAgentModel 从 UI 移除，运行时读字段（默认值兜底，尊重旧 data.json 值）。
8. **入口页不新增设置**：编辑模式控件（文字显隐、手势、列数）即入口页设置入口；移动端列数由编辑模式列数控件按平台读写。

## Considered Options

- **维持 12 tab 集中设置页**：改设置不就近、tab 膨胀；筛选/设置图标语义混杂——否决。
- **全部设置拆到面板、设置页只剩 AI**：全局路径无处安放，闪念/入口页等无面板域悬空——否决。
- **每域保留独立 JSON 路径字段**（不收敛）：7 个字段默认值相同、无独立配置价值，设置页平铺冗余——否决，收敛为共享 storagePath。
- **筛选弹窗沿用 ⚙️**：用户否决（🎛️ 候选亦否决），最终选 🔀。

## Consequences

- 设置就近：域行为项在各功能面板 ⚙️ 修改，全局项在设置页；设置页从 12 tab 瘦身为单页两区块。
- 数据格式仍稳定：只加 `storagePath` 字段，旧字段不删（兼容读取）；迁移一次性 Notice 提示被忽略的自定义路径。
- 老用户自定义过独立 JSON 路径的（如 pwStoragePath 改过）升级后该值不再生效，需按 Notice 手动迁移文件。
- 设置页测试（settings-tab.test.ts）重写为单页 + 迁移测试；各域新增设置弹窗测试。
- 后续新增域默认遵守：行为设置进本域 ⚙️，JSON 数据一律走 `storagePath`。
