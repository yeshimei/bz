# ADR-0070: 文献盒 v3.1 UX 整改——历史独立弹窗/去行内重试/状态计数/完成态步骤文案/弹窗遮罩统一

日期: 2026-08-29
状态: 已采纳
前置: ADR-0065（视频转文献面板与批量处理）；ADR-0066（文献盒 v2）；ADR-0067（文献盒 v3 断点续跑/历史归档/行内信息）；ticket 134/ADR-0068（聚合讯预填入口）

## 背景

文献盒 v3 上线后的一轮 UX 评审（2026-08-29 用户逐项拍板）识别出若干体验摩擦：失败行内「重试」按钮与批量处理按钮语义重复（批量处理范围本就含待处理+失败）；历史视图就地切换主面板（🕘 切换标题与列表），层级不清晰；历史条带「历史 · N 条 + 清空历史」占一行且清空入口太顺手；历史行成功徽标冗余（进历史即成功）；同一视频多条文献笔记（不同分P/起止段）在历史里散成多行不好找；未解析任务行裸显长链接；步骤时间线已完成步骤重复显示「XX中」文案；添加弹窗无遮罩且有取消按钮，与其他域弹窗形态不一致。

## 决策

1. **重试 = 再次点击 ▶️ 批量处理**：移除失败行内「重试」按钮与悬浮菜单「重试」项；批量处理范围本就 = 待处理 + 失败（ADR-0067），失败后再次点击 ▶️ 即重试（断点续跑自动从出错步骤继续）。`TasksData.retryTask` 数据层方法保留（数据层能力，非 UI 契约）。
2. **历史改独立弹窗**：🕘 打开独立「文献盒 · 历史」弹窗（自有遮罩 + bz-win-head + ✕，ESC 关最上层：历史 → 添加弹窗 → 主面板）；主面板恒为任务列表，不再就地切换视图（`mode`/`toggleMode` 移除）。
3. **历史形态精简**：去掉「历史 · N 条」条带行与「清空历史」按钮（移入 ⚙️ 设置面板按钮行，确认弹窗后清空）；去掉历史行「成功」徽标（进历史即成功）；**同视频多条文献笔记归并一张分组卡片**（按 url 分组，组内按完成时间正序、组间按最新完成倒序），每条任务一行「📄 笔记路径 ⏱ 完成时间」（无左边距，与标题对齐），点击打开笔记，行级右键/长按操作（打开笔记/复制视频路径/移出历史）；UP主名去「UP主」前缀、紧随标题之后（并入标题行）。
4. **头部状态计数**：主面板标题旁显示「N 待处理 · N 处理中 · N 失败」非零项，一眼看清队列健康度。
5. **步骤时间线完成态文案「已…」**：已完成步骤显示完成态——「解析中→已解析」「下载中→已下载」等（映射表 + 「XX中」通用规则）；当前步骤仍显示进行时文案。
6. **未解析任务行显短链接**：优先提取 BV 号 / b23.tv 短码，其余链接截断 28 字符加省略号；完整链接保留在悬浮 title。解析回传后仍切换为标题文字链接（ADR-0067 不变）。
7. **添加弹窗遮罩统一**：添加/编辑弹窗加独立遮罩层、移除「取消」按钮——遮罩点击 / ESC 关闭，与主面板及其他域弹窗形态一致。

## Consequences

- 插件侧：ui.ts 重构（历史弹窗独立生命周期、ESC 分层、`biliTasksSettingsSchema(opts)` 增加可选清空历史按钮行）、styles.css（去 retry/hstrip 样式，增计数/历史笔记行样式）；数据格式、命令 id、DOM id 契约（bili-tasks-popup 等既有 id）全部不变；新增 `bili-add-mask`/`bili-history-popup`/`bili-history-mask` 等新 id。
- 测试：ui.test.ts 全面更新——历史独立弹窗/分组/无徽标无条带、清空历史走设置按钮行、无重试入口、状态计数、完成态文案、短链接、弹窗遮罩与 ESC 分层、destroy 全量清理。
- 已知取舍：移动端历史弹窗同样只读可看（无处理能力不变）；未解析任务的移动端仍显示短链接（HTTP 预填标题方案评审中未拍板，未实施）。
- 兼容性：数据格式零变更（铁律 1）；文案变更为用户拍板的 UX 整改（铁律 1 文案豁免，仅限本决策列举处）。

## 未采纳方案

- 行内保留「重试」按钮 + 批量按钮双入口：语义重复（用户拍板去除）。
- 历史行内保留「清空历史」：高频破坏性入口距列表太近，移入设置（用户拍板）。
- 面板内粘贴链接直达添加 / 未保存修改防关闭 / 断点续跑缓存标注：本轮评审不采纳（用户拍板）。
- ESC 双层同关修复：复核确认现状并无双层同关（ESC 逐层关闭），不改。
