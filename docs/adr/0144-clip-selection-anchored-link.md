# ADR-0144 划词锚定（名词/段落）：别名双链直达预览，不用块 id

- 状态：已接受（2026-09-15，grill 拍板；**设计定稿，未实现**）
- 关联：issue 329 / ADR-0082（剪藏本）/ ADR-0116（术语来源 source 键）/ ADR-0122（文献预览与渲染契约）/ ADR-0068（B站保存分流先例）
- 影响：`src/clipbook/ui.ts`（阅读器渲染层 + 划选工具框 + 点击拦截）、`src/clipbook/save.ts`（保存物化）、`src/clipbook/data.ts`（侧写划词标记）、`src/knowledge/index.ts|ui.ts`（文献预览跨域直达 + 录入预填）、相关测试

## 背景

剪藏本阅读器与知识盒的联动此前只有 B站条目「保存至文献」一条（ADR-0068）。用户要阅读器式的划词直达：
阅读区选中文字弹工具框 → 存为名词 → 原文里留下锚定，阅读时点得回去。

初版构想是「段落尾隐藏块 id（`^bz-xxxx`）+ 名词 source 写 `[[路径#^块id]]`」，评审时用户主动砍掉：
**「不需要用块 id 了」**——锚定粒度从段落级降为选区级别名双链，换取零块 id 维护。

## 决策

### 1. 划选工具框（桌面/移动同套）

- 阅读区选中文字 → 光标上方浮出工具框：**复制（Markdown 源语法，用户拍板非纯文本）/ 存为名词 / 存为段落**；
- **单击图片** → 图片工具框：**保存图片 / 存为图版**（不复用 item-actions 右键/长按菜单）；
- 工具框发起的名词/段落/图版录入复用知识盒录入面板（选中内容预填），生成后**不自动打开笔记**
  （区别于知识盒命令入口「确认写入并打开」流程，不打断阅读）。

### 2. 锚定双链 = 别名 wikilink，无块 id

选区原文字替换为 `[[名词笔记|原文字]]`——显示不变、Obsidian 链接原生下划线、点击跳名词。
**不写块 id、不动段落结构**；同段多次划词即多条独立双链共存，段落本身无锚（接受的代价）。

「存为段落」**套用同一机制**（用户拍板，同一篇里体验对称）：选区替换为 `[[段落笔记|原文字]]`，其余全同名词。

### 3. 点击直达 = 知识盒文献预览，不是打开 md

剪藏本阅读器内拦截该双链的导航，改为打开知识盒「文献预览」弹层（按 path，`openPreview` 同款
渲染契约，ADR-0122）。需要在 knowledge 域暴露按 path 直达预览的跨域 API。在 Obsidian 原生
打开剪藏 md 时链接维持原生行为（跳 md 文件），不拦截。

### 4. 落盘两路：已保存直写，未保存渲染层 + 保存物化

硬约束：未保存条目正文在 news.json，是外部抓取的双写数据，插件侧不写 `articles.body`。

- **已保存剪藏 md**：划词确认后直接替换写入文件；
- **未保存 news 条目**：只在阅读器渲染层做内存替换（渲染前替换 body 字符串再交
  MarkdownRenderer，符合 ADR-0122「渲染前容器清空、追加渲染」契约），划词标记暂存
  clipbook.json 侧写（按 articleKey）；**保存为剪藏那一刻物化**——md 替换写入、侧写标记清除。

### 5. source 两态同步（名词/段落/图版一致）

复用术语来源键（ADR-0116），**名词 / 段落 / 图版三态一致**（图版无正文锚定，仅 source 跟随，
用户拍板）：未保存时 source = 原文外链 URL；保存物化时回写为文章内部路径
`[[剪藏路径|标题]]`（无块 id）；已保存文章发起录入则落盘时即是内部路径。

### 被否的备选

- **段落块 id 锚定**（初版构想）：用户拍板砍掉——「不需要用块 id 了」；
- **划词即强制先保存剪藏**：每划一次落一个 md，打断阅读动线；
- **未保存条目不标记**：已划的词无任何反馈，工具框动作一半失效。

## 后果

- 阅读器渲染管线新增「选区→双链」前置替换层，替换稿交 MarkdownRenderer；news.json 永不被写。
- 复制 = Markdown 源语法：渲染层持原文 body，选区文本回查源片段写剪贴板（非 DOM textContent，保语法）。
- 侧写划词标记随 news 过期清理自然失效（保留无害）；物化后即删，改为纯 Obsidian wikilink——
  名词笔记改名由 Obsidian rename 原生改写；未物化标记记录路径字符串，改名后断链静默（接受）。
- 描述不进此机制：图片锚定走「保存图片 / 存为图版」，无文字选区语义。
