# ADR-0089：归物本出离闭环（出离日期 + 转卖可选售价，推翻 ADR-0083「转卖不填价」）

- 状态：已采纳（2026-09-04）
- 关联：ADR-0083（收藏本/归物本 UI 重设计——本 ADR 明示推翻其「转卖不填价」一点）、ADR-0074（收藏归档冷存——ticket 188 加找回入口不改冷存语义）、ADR-0009（统一存储路径）、issue 188/189

## 背景

ADR-0083 落码时以「真实 belongings.json 8 字段无售价/转卖日期字段」为由，把原型的「转卖填回本价 + 回本显示」整体砍掉（转卖 = 直接状态流转），并写明「留待未来加字段再做售价语义」。2026-09 全域审查后用户在增强包拍板会话中**明示翻案**：出离（转卖/丢弃）应记出离日期封口陪伴天数，转卖可选记售价、统计可算回本——数据结构是本插件的实现细节，不应反过来锁死统计能力；售价走可选字段即不破坏零迁移。

同批拍板的收藏本/归物本体验增强（归档找回、撤销接全、统计联动、防丢补全、贴链搬家、头行钮规格）随本 ADR 一并落码（issue 188/189）。

## 决策

1. **出离字段加法扩展（零迁移）**：`BelongingsItem` 增可选字段 `exit_date?: string | null`（出离日期，YYYY-MM-DD）与 `sold_price?: number | null`（转卖售价）。旧数据无字段 = 未出离/未记售价，照常可读（对齐 favorites `archived` 可选字段先例）。状态流转入「已转卖/已丢弃」时自动写 `exit_date = 当天`；回「使用中/闲置」清除；丢弃态清 `sold_price`（无售价语义）。
2. **陪伴天数封口**：`data.calculateDaysUsedUntil(purchaseDate, endDate?)`——出离条目已用天数封在 `exit_date`，不再随时间增长；非出离条目与旧口径一致（截至今天）。
3. **回本口径生效**：日均成本 =（总购入 − Σ已转卖售价）/ 累计持有天数（ADR-0083 原型公式的延迟落地；未记售价 = 0 回本，旧数据统计结果与旧口径一致）。总资产（在用+闲置原价）与在册件数口径不动。物件行转卖副行「陪伴 N 天」追加「售出 ￥x」（记了售价才显示）。
4. **撤销接全**：状态流转 notifyUndo（回写旧状态 + 清出离日期）；删除确认弹窗保留但去掉「此操作不可撤销」威慑文案，删除后 snapshot 经 notifyUndo 一键写回。
5. **同批体验拍板**（收藏本 issue 188 / 归物本 issue 189）：收藏归档撤销 + 左栏「已归档」视图 + 搜索归档命中提示（ADR-0074 冷存数据位置不变）；搜索覆盖 URL + 域名徽章；贴链自动搬家；两域表单防丢基线补全；收藏保存先落盘、余额查询后台化；关联笔记 vault 候选补全；年节当年/上一年默认展开更早折叠；统计卡可点（总资产=在用+闲置合成筛选、在册件数=回全部，口径不动）；头行图标钮间距 ≥8px + 移动端大按钮档。年份筛选维持下拉、批量打标不做（拍板）。

## 理由

- **翻案理由（用户原话意译）**：售价是转卖事实的一部分，不记等于数据缺失；「8 字段零迁移」约束的是**读兼容**，不是禁止加法扩展——可选字段旧数据天然可读，迁移成本为零。
- 封口陪伴天数是记出离日期的直接收益：否则转卖物品的「陪伴 N 天」逐年虚增，日均成本随之失真。
- 售价设为可选：不是每次转卖都知道/想记卖价；留空时统计自动退化为旧口径，无数据突变。
- 撤销接全延续 ticket 141 以来的「事后兜底优于事前威慑」方向（core/notice notifyUndo 先例）。

## 后果

- belongings.json 新条目在出离态才写 `exit_date`/`sold_price`（在用态编辑不给老记录补写冗余 null）。
- smartcat `belongingsEditChanges` 增「改了售价/改了出离日期」α 变化项；收藏本增 `unarchive` 事件（观察文案「你把《X》恢复了归档」）。
- 收藏本归档 toast 文案变为「已归档收藏「X」」（带标题，对齐删除文案结构），已归档视图动作含取消归档。
- 测试：两域 data/ui 测试扩展 + 回归（归档撤销/找回、贴链搬家、后台余额、防丢、年节折叠、统计联动、出离封口、售价回本、删除撤销）。
