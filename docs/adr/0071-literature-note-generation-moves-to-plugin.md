# 文献笔记生成回迁 bz 插件，外部工具去 AI 去网页版

文献盒改版（ticket 136）拍板：文献笔记的 AI 生成（标题/标签/简介/润色 + 文献类型/领域）从外部工具 `tools/bili-downloader` **整体回迁到 bz 插件**（core/ai），外部工具不再调用任何 AI；同时**移除 bili-dl 网页版**（`server.js`/`public/` 与插件 `bz-bili-open` 命令），工具只保留 `--batch` 无头批处理（解析/下载/剪辑/压缩/转文字/交付），产出**转录临时文件**交插件做 AI 与笔记落盘。理由：视频文献与术语文献的笔记模板、文献类型、领域分类在插件侧同构统一、一次 AI 调用，避免两套生成路径不一致；网页版已无实际用途（用户拍板）。取舍：备选「插件后处理补写 frontmatter」会多一次 AI 调用与一次文件改写，弃用。
