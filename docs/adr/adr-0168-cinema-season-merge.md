# ADR-0168 影院剧集按季合并（渲染层分组，零存储）

- 日期：2026-09-18（2026-09-20 修订）
- 状态：已采纳
- 相关：issue 376、issue 387；ADR-0104（渲染纯层）、ADR-0105（布局分层）

## 背景

用户片库里同一部剧按季各建一篇笔记（`《老友记 第一季》.md` … `《老友记 第六季》.md`），
一屏看下去被同一部剧刷屏。用户要求「多一个设置选项，把相同的影视按季合并在一起」，
并在四版卡片呈现方案（角标 / 海报堆叠 / 季签行 / 季进度条）中**选定「季进度条」**。

## 决策

1. **合并只发生在渲染层**。新增纯加工层 `src/cinema/seasons.ts`：条目列表 + 合并开关显式入参，
   `mergeSeasonCards()` 产出 `CardEntry[]`（`single` / `series`）。**不写盘、不改笔记、不加存储**，
   关掉开关即回到逐季一卡。设置键 `cinemaMergeSeasons`（布尔，默认关）。
2. **归一名称是唯一合并判据**，单源落在 `seasons.ts`：剥掉「第X季 / Season N」后完全相同才归一部，
   且限「剧集 / 动漫」两组、库内 ≥2 季才合并。`S1` / `EP1` / `第N部` 一律不认——片名里出现
   `S1` 的误伤概率远高于收益，`第N部` 是电影续集语义。禁第二套判定。
3. **卡片一个出口**。`shared.ts::cardHtml(entry, posterUrl, fetching)` 同时渲染普通卡与合并卡；
   `pcardHtml(it, …)` 退化为单条目薄封装（既有调用点与测试语义不变）。
   季进度形态（用户 2026-09-18 定稿，方位由「右下」订正为**左下**）：**海报左下角一排圆点 + 零文字**——一个圆点 = 一季
   （金实=已看 / 橙实=在看 / 空心描边=未看），季多时换行且仍右对齐。
   两个硬约束：① 圆点**绝对定位在 `.pw` 内**，既不占卡片高度、也不受 `.pw` 的 `overflow:hidden` 影响
   （挂到 `.pw` 之外的普通流兄弟元素会被裁掉，2026-09-18 原型踩过）；② 圆点坐在海报图上而非面板底上，
   故自带一层**不随亮暗翻转**的半透明深色底衬，颜色也不用主题变量。文字去掉后补 `role=img` + aria-label。
4. **计数口径随卡片**。rail 与列表头行的「· N 部」按卡片数（合并后 2 张就是 2），否则点了筛选器
   看到的数量与网格对不上。分析页不受影响（仍按笔记条数统计，合并是展示层的事）。
5. **合并卡上只有「看合集」一种动作**：左键 / 右键 / 长按都开各季明细弹窗。标记在看、编辑、删除
   都作用在「一季的笔记」上，合集上无处落地；要动某一季就点进那一季。合集弹窗因此**不放动作行**。
6. **季圆点兼作悬浮预览入口（issue 377）**：鼠标移入第 N 枚圆点 → 卡片正脸临时换成那一季
   （海报 + 名字/meta/星级），离开复原。三处口径固定下来：
   ① 「海报内芯 + 名字 + meta + 星级」四件只有一个出口 `shared.ts::facePiecesHtml`，
   静息态渲染与换脸共用，禁第二套格式；② 换脸只重写 `.pw-face` 一层（圆点/角标/遮罩是兄弟节点）；
   ③ 复原回 `WeakMap` 快照而非重算——合并卡静息态口径（归一名称 + 最新已评季评分）与单季不同，
   重算必然还原错。仅桌面壳挂（触屏 tap 有 mouseover 无 mouseout 会滞留）。
7. **不臆造全剧总季数**：笔记里没有可信来源（`季集` 是每季集数，实测 `"13"`）→ 进度条 y 恒为库内季数，
   不补「未入库空段」。

## 代价

- 合并卡的正脸是「最近看的那一季」，海报/年份/导演会随最近观看变化，不是固定的系列主视觉。
- 季数很多的剧（20+ 季）分段条会变细密，注释靠省略号截断。
- 状态筛选打开时，某剧只剩 1 季命中 → 该卡回落普通卡（这是正确行为，但同一部剧的形态会在筛选间变化）。

## 2026-09-20 修订（issue 387）

背景：同一部剧的电影版 / 特别篇 / 外传与剧集**不同组**（豆瓣把电影版按「电影」收录、幕后片按「纪录片」），
合并后它们仍各自出卡；而合集卡的手势全被导向季弹窗，与单卡浮层手势不一致，弹窗里的行也没有动作落点。

1. **默认开**：`cinemaMergeSeasons` 缺省由关改开（合并已是常态视图）。
2. **特别篇前缀并入**（补决策 1）：`<剧名>` + 分隔符 `[\s:：·\-—－]+` + 非空副标题 → 并入该剧合并卡
   （`SeriesCard.specials`）。**只按片名前缀认**：不看组、不做 `is_tv` 落盘兜底、不抓豆瓣「相关书影音」；
   **分隔符刻意不含「之」**（复合词误合比漏合更伤：漏合改名可补，误合会悄悄吞掉一部片）。
   只有已建成的合并卡（同组同名 ≥2 季）才吃特别篇，孤立特别篇照旧普通卡（与「单季回退」同口径）；
   命中最长 base 优先；已并入的不再单独出卡；**不占季号、不进季圆点**。
   评分与聚合状态**含**特别篇（badge 读作「最近在追的那部」），正脸仍是「最近看的那一季」。
3. **季弹窗收口**：不区分季与特别篇（顺排在季后面，无分隔标题）、去掉分节小标题与操作提示；
   头部计数**按并入条目的类型**分组（`共 2 季 · 2 部电影`），类型为空回落所属组；
   首行与头部的间隔由新增的 `.s-list` 给（原靠小标题的 border-top + margin 顶着）。
4. **手势重排（改决策 5）**：左键 = 各季明细弹窗；桌面右键 / 移动长按 = 与单卡同款浮层，
   但**只有一条**「查看全部」——合集没有具体条目可指，标记在看 / 编辑 / 删除都是笔记级动作，合集上不落。
5. **弹窗行级手势（新）**：桌面右键该行 → 该行的跟手菜单；移动长按该行 → 底部抽屉。
   三个坑位写进口径：行内条目**触发时现取**；长按回调里**不关弹窗**（元素被移除后 `longPress` 的
   合成 click 落到 document 会被 item-actions 当作外部点击，抽屉开出即关）；动作**先收弹窗再执行**。
6. **评审壳**：影院原型加「分季合并」开关（默认开，关时向 iframe 传 `?merge=0`；
   插件侧该键走插件设置页，原型没有设置页入口）；演示数据补 9 条特别篇样例与反例。
