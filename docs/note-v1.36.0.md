# 更新日志

## 新功能

- **域目录** ：日记、剪藏、影视等六个板块的存放位置默认不再替您猜，第一次用时会有引导卡带您指一次就好
- **保险库** ：四个板块第一次设置主密码时，共用同一块设置面板

## 体验优化

- **界面** ：在弹窗里选字、滑动时不会再误点外面把弹窗关掉
- **自动更新** ：默认打开
- **自动更新** ：更新时只下载插件本身和外部工具包，皮肤等在线资源不再跟着动
- **保险库** ：第一次设密码时输入框改为明文显示，两个输入框上下排列
- **域目录** ：图片附件统一存进对应目录下的 assets 子文件夹
- **域目录** ：图片没单独配目录时，界面直接显示图片实际存到了哪，并跟着 Obsidian 的附件设置走
- **自检** ：手机上断网页面的三个按钮放不下会自动换行，并加了「连不上？看视频」教程入口
- **其他** ：断网时打开插件不再重复请求更新，启动更快

## 问题修复

- **保险库** ：全新的库第一次设置主密码不再失败
- **番茄钟** ：重新打开番茄钟不再丢失正在进行的倒计时

# 使用

1. 到 [Releases](https://github.com/yeshimei/bz/releases) 下载最新的 `bz-1.36.0.zip`
2. 解压到 `<你的 vault>/.obsidian/plugins/` 下，得到一个 `bz/` 文件夹
3. 重启 Obsidian → 设置 → 第三方插件 → 找到「bz」→ 启用

# 离线资源包

在线资源（皮肤、工具包、手册、影视索引）下不动时，用 `bz-offline-1.36.0.zip`。解压出的 `downloads/` 整个放进插件目录，再回插件点一次下载——本地校验通过就直接用，不联网。

```text
.obsidian/plugins/bz/
├── main.js
├── manifest.json
├── styles.css
└── downloads/
    ├── manifest.json
    ├── skins/
    └── tools/
```
