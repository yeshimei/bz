# 465 — 数据源弹窗「同步」按钮

## Parent

`issues/460-people-face-restructure-spec.md`（spec）。门禁与工作流按 `AGENTS.md`。

## What to build

把数据源弹窗右上角的「重扫」换成「**同步**」——语义从"重读目录"变成"从微信重新取数"。点一下由插件调用工具跑完整条 sync，弹窗内走**一条进度行**（不占画像生成的进度块）；运行中该位置只出「停止」；完成后刷新联系人列表并标出哪几位有更新，**不自动导入**。

## Acceptance criteria

- [ ] 按钮文案与提示说明「从微信重新解密并导出，需要微信已登录」
- [ ] 点按后弹窗内出现进度行，逐段更新到完成；不占用画像生成的进度块
- [ ] 运行中只出现「停止」一个动作（不与「同步」并列）；点停止能真的停下
- [ ] 微信未开 / 工具未装 / 依赖缺失时，弹窗内给中文原因与下一步动作（含去哪配路径），不抛栈
- [ ] 完成后列表刷新并标注更新数；**不自动导入预览**
- [ ] 同步进行中「画脸谱」入口置灰
