# 258 · 术语录入弹层完整化（词典皮回补：标题栏/字段标签/试试示例/取消/说明行）

用户复核 issue 257 成果后反馈：「术语界面太简洁了，按照风格把它做的完整一点」——ticket 142 把术语面板削成极简版（无标题/无标签/无说明），与 ADR-0112 评审通过的原型（.zcode/ui-prototypes/knowledge-box-c，词典纸墨皮）不符。本票把弹层穿回原型的完整形态，**交互契约不变**（142/155 的预览只读、自动生成、ADR-0116 来源行全保留），只补皮与引导：

- 标题栏「文字录入 · 术语」（衬线、宽字距）+ 右侧 ✕ 关闭（委托 `data-term-close`）
- 「术 语」字段标签（div.lb，10px 宽字距；仍无原生 `<label>`、无 placeholder）
- 试试示例行：`试试：昼夜节律`——点击回填输入框、不自动生成（原型同款）
- 按钮组改为原型结构：生成 + 取消（取消=hideTermEntry；Enter 生成不变）
- 琥珀左边条说明行：「生成是纯预览、不落盘；确认写入才产生文件。」
- 预览态补「写入去向」说明行：`写入 → <文献目录>/<术语>.md。它是「未消化」素材，等被主题笔记引用、被提炼。`（目录随设置 `knowledgeDirectory`；重名 `_2` 由落盘层兜底，说明为近似路径）
- 预览出现后 `scrollIntoView` 滚入视口（移动端软键盘场景；jsdom 无该方法可选调用）
- 样式：`.bz-lit-sheet-head/-title/-close`、`.bz-lit-term-field/-lb/-hint/-note`；删除死样式 `.bz-lit-term-inputrow`

## 验收

- 打开术语录入：有标题栏与 ✕、术 语标签、试试示例（点击回填）、来源行（257）、生成+取消、纯预览说明
- 生成后：属性卡（术语/领域/日期/来源）+ 内容卡 + 总结/确认写入 + 写入去向说明；预览滚入视口
- ✕ / 取消 / ESC / 点遮罩 均可关闭；关闭后重开为全新状态（257 语义不变）
- 全量门禁绿（knowledge 111 用例含完整版契约断言）
