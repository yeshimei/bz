# 469 — 画脸谱阶段机：prep 接进任务引擎

## Parent

`issues/460-people-face-restructure-spec.md`（spec）。门禁与工作流按 `AGENTS.md`。

## What to build

点「画脸谱」后，任务引擎先跑**工具段**（媒体导出、语音转写），进度块逐步显示 `媒体导出 312/1631` → `语音转写 45/1289`。全程可暂停（在这一批 / 这一条做完后停）、可关面板转后台、可重启续跑；中断后出「继续生成」而**不自动跑**；保险库上锁时自动暂停。

状态机归插件（工具只保证单步幂等），断点状态落数据根——**跟数据走，不跟人走**。

## Acceptance criteria

- [ ] 点「画脸谱」后进度块按阶段推进，阶段行带 `已完成/总数`
- [ ] 点暂停：在当前批 / 当前条完成后停下并给出状态；再点「继续生成」从断点续，**已完成的不重做**
- [ ] 关面板转后台继续跑；重启后任务显示为「中断」并给出「继续生成」，**不自动开跑**
- [ ] 完成后该联系人的数据里，转写与图片关联已并入聊天仓（合并动作由插件执行，不是工具写回）
- [ ] 同步进行中不可画脸谱；画脸谱进行中不可同步（双向互斥）
- [ ] 保险库上锁时任务转入暂停
- [ ] 工具段的暂停是**协作式让行**（进程不硬杀、不因此丢进度）
- [ ] 失败分流：密钥 / 解密类硬失败整链停并给中文原因；单条媒体 / 语音失败计失败数继续
