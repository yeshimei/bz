# 467 — 保库记录：脸谱数据整体入保险库

## Parent

`issues/460-people-face-restructure-spec.md`（spec）。门禁与工作流按 `AGENTS.md`。

## What to build

脸谱的全部数据（人物卡 + 聊天仓 + 任务队列 + 头像）搬进保险库，**每个联系人一条加密记录**，与保险库 / 密码本**共锁同库**（同一主密码、同一清单）。联系人索引也加密，打开面板先要求解锁；上锁即清明文缓存并暂停后台任务。存量那几位已导入的联系人被迁移过来。

头像不再以「明文文件夹名 = 人名」的形式留在库里——**那份目录本身就是一份明文联系人名单**。

## Acceptance criteria

- [ ] 解锁后打开脸谱面板，联系人列表与各人数据（人物卡 / 聊天数据 / 任务 / 头像）与迁移前一致
- [ ] 保险库里每联系人一个加密文件；**库内不再有明文聊天数据**
- [ ] 联系人索引同样加密——未解锁时读不到任何联系人名
- [ ] 未解锁时打开面板先要求解锁；解锁取消/失败则不展示数据
- [ ] 上锁后：明文缓存被清、后台任务暂停、面板变为不可读
- [ ] 头像从加密记录渲染出来（解密为内存图，不落明文文件）；原明文头像目录不再被创建
- [ ] 存量迁移一次完成且幂等；迁移后旧明文文件被清理
- [ ] 未解锁状态下「数据体检」跳过脸谱域而不报错
- [ ] 多设备同步加密记录时，主密码相同即可读（不额外处理）
