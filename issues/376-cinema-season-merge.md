## 口径与边界

| 项 | 口径 |
|---|---|
| 可合并组 | 剧集 / 动漫（电影/纪录片/公开课无季语义，不参与） |
| 归一 | 名称剥掉「第X季 / Season N」后**完全相同**才算一部；`S1`/`第N部` 刻意不认（误伤 > 收益） |
| 门槛 | 库内 ≥2 季才合并；单季照旧一卡（不为了统一把单季塞进合集） |
| 落位 | 合并卡落在该剧**首季**在原列表中的位置，排序语义不变 |
| 计数 | rail 与头行「· N 部」按**卡片数**（合并后网格 2 张就是 2，不是 4 篇笔记） |
| 卡面文字 | 合并卡**不出任何可见文字**（只有圆点）；进度信息走 aria-label |
| 不改的 | 笔记、frontmatter、存储、分析页统计（分析页仍按笔记条数） |
| 合并卡上的动作 | 只有「看合集」一种：左键/右键/长按都开各季明细——标记在看/编辑/删除都是单季笔记级动作，合集上无处落地 |

## 不做（本轮明确排除）

- 不臆造「全剧共 N 季」的空段：笔记里没有可信的总季数来源（`季集` 字段是每季集数不是季数，实测
  《夏目友人帐 第一季》`季集: "13"`）→ y 恒 = 库内季数。原型里老友记那条 10 段的演示是拿常识补的，
  真实现不这么做。
- 合集弹窗不放 找同类/编辑/删除（同上「单季动作」理由）；要动某一季就点进去。
