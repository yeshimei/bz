# 188 — 收藏本用户增强包（归档找回 / 搜索 URL / 贴链搬家 / 防丢补全 / 保存不阻塞 / 笔记候选 / 头行钮）

## 背景

全域审查（2026-09）收藏本体验线 + bug 线产出，用户逐项拍板「做」。基线：ADR-0083 P1「标签工作台」、ADR-0074 归档冷存。

## 用户拍板（全部「做」）

1. **归档撤销 + 找回**：归档动作后 notifyUndo（回写 archived=false）；左栏「全部」下加「已归档」入口（归档视图可取消归档/删除）；搜索无结果时提示「归档中有 N 条匹配」。不动 ADR-0074 拍板：归档数据仍在 favorites.json。
2. **搜索覆盖 URL + 域名徽章**：haystack 加 `it.url`；卡片 meta 行尾加弱化小域名徽章。
3. **贴链自动搬家**：添加表单 #fz-title 监听 paste，URL 形态内容自动移入 #fz-url 并回焦标题。
4. **表单防丢检查补全**：脏表单 baseline 纳入 标签 / 置顶 / 关联笔记 字段（原机制只盯标题/链接/简介/keys/余额URL）。
5. **保存不被余额查询阻塞**：保存先落盘关表单，余额查询后台刷新，失败静默写 balanceError + warning。
6. **关联笔记选择器**：#fz-note 输入时 vault 笔记候选自动补全（对照 belongings categoryPicker 范式）。
7. **头行图标钮间距/尺寸**：2px → ≥8px；移动端换 `--bz-icon-btn-lg` 大按钮档。

## 明确不做

- 年份筛选平铺、批量打标（belongings 侧拍板，与本票无关）；归档条目进标签计数（仍排除）。

vitest 全量 + tsc --noEmit 全绿；数据层 + UI 层回归测试；worktree 开发合并回 master。
