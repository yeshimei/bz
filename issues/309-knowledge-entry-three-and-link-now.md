# 309 知识盒录入入口收成三名词 + 关联改「生成即起跑」的显式通道

- 状态：完成（2026-09-14 原型评审迭代，待合并主仓）
- 关联：ADR-0135（本 issue 与 310 的决策记录）/ 前身：issue 298（文献笔记生成即跑，本轮**替换**）、ADR-0112（知识盒三部）、ADR-0116（来源行）

## 背景

用户 2026-09-14 在知识盒原型评审里提出四条：

1. 入口名改成简单名词，并新增一类：「文字录入 · 术语」「视频录入 · 任务」→ **名词 / 段落 / 影像**；入口按钮下的灰色说明小字全部去掉。
2. 新增**段落录入**：用户把一段文字粘进文本框，AI 自动生成标题 + 文献笔记。
3. 名词与段落的**属性区都展示一行「关联」**：AI 一生成出内容就立刻走第二大脑的自动双链，返回前 loading、完成后就地显示。
4. **去掉「文献笔记保存后」的自动双链流程**（issue 298 的 `knowledge:tasks` 订阅生成即跑）——那条路径不向调用方回报进度，面板无从显示。

用户口头复核追加：去掉「取消」与「打开笔记」两个按钮；关联分析期间禁用「重新生成 / 总结 / 确认写入」；「重新生成 / 总结」要重跑关联分析；「确认写入」直接关窗。

## 交付（全部完成）

- [x] 段落录入：与名词**同壳双态**（`data-lit-entry="term|passage"`；首行单行 input ↔ 多行 textarea，来源行完全同构）；`note-gen` 增加 `generatePassageDraft` / `generatePassageNote`（AI 出标题 + 领域 + 整理正文，落 `type: passage`，与名词同目录）；回车换行、Ctrl/Cmd+回车生成
