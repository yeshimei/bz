# 484 脸谱同步进度显示——阶段切换 + 已耗时 + 当前联系人

## 背景

实测全量同步约 5 分 21 秒（57 联系人 / 72,436 条消息，[bz-result] ok）。期间解密阶段 `[bz-p]` pct=null 不出进度条，导出阶段虽有 contacts 百分比但阶段主文案不切换，弹窗长时间停在「解密数据库（增量：已解密的库自动跳过）」一行——用户以为卡死（2026-09-27 实报）。

## 方案（dsSyncLine / sync 状态机）

1. **已耗时心跳**：同步进行中每秒刷新「已 X 分 X 秒」，任何阶段都显示——慢不再像死。
2. **阶段主文案跟随 [bz-step] 切换**：取密钥 → 解密数据库 → 导出聊天与头像源；导出段显示 `N/57 位联系人`（contacts pct 换算）。
3. **当前联系人副文案**：消费 `[bz-info] {"phase":"contact"}` 事件的 name/status，滚动显示最近一位（如「大琳 · ok · 20,773 条」），跳过的空联系人不上屏。
4. 解密阶段 pct=null 时进度条保持不定态样式，但主文案+耗时照常走。

## 门禁

tests/people/ 同步 UI 状态机测试（阶段文案 / 耗时 / 联系人副文案）+ tsc + build-preview freshness。
