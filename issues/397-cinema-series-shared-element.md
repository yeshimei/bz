## 背景

396 只覆盖「网格点单季卡」。用户 2026-09-21 在预览上追加两条口径：

> 合集季也采用相同的动画，从合集中打开某个列表也采用相同的动画（不同的是，图片是从列表的小图片变大的），点击列表打开详情页，列表页面不会消失，关闭时也会插入到原位置

> 合集季中的列表也要移除掉，和在卡片列表中一样

即：① 点合集卡（分季合并卡）开各季明细 → 与单卡同款过渡；② 在合集弹窗里点某一季 → 该行从明细列表**抽离**（其余行补位，与网格里整卡抽离同一形态），海报从**行内小图**长成详情海报；合集弹窗**留着**（列表页不消失），关闭时行让位、海报飞回行内原位。

## 决策（2026-09-21 用户拍板）

1. 合集卡开面板 = 与单季卡**完全同款**（整卡抽离 + 其余卡 FLIP 补位 + 关闭插回），不另做一套。
2. 合集行钻入 = **整行抽离**（不是只把小图变隐形、留个空位）——用户明确「也要移除掉，和在卡片列表中一样」。
3. 列表页不消失：单季详情**叠在**合集弹窗之上，关合集弹窗仍走原路径（只有左键钻入保留弹窗）。
4. 返程落点 = 行内小图的矩形；行抽离后面板变矮、flex 居中会带动整块面板位移，面板一并进 FLIP 集合（滑过去而不是硬跳）。

## 关键实现口径

- **行模式与卡模式同构**：唯一差别是容器与件选择器；`taken` 恒等于「被抽离的那一件」（卡 / 行），图则是卡面海报（`.pw img`）/ 行内小图（`.s-thumb img`）。
- **`.cn-fly` 必须高过 `.cn-ovl`（50）**：返程克隆挂共享宿主（`display:contents`，坐标系=面板根），合集弹窗还开着时克隆与弹窗层同处一个层叠上下文——压在弹窗下就看不见海报飞回行里（用户报「图片层级在面板下面，被遮挡了」）。A/B 实测：旧值 5 时命中栈 `[s-list, cn-modal, cn-ovl]`（被盖），新值 60 时 `[img, cn-fly, s-list]`（在最上）。
- **量在演之前**：`reinsertSrc` 的返程落点要在 FLIP 动画**开跑前**量——合集模式下面板也在 FLIP 集合里，一开跑，行的矩形就跟着祖先的 transform 走，量到的是被污染的假坐标（实测偏 39px），海报落一条行高再弹回来 = 用户报的「插回时有一些抖动」。故 `flipReflow` 拆成 `measureFlip`（mutate 前后各量一次，只量不动）+ `playFlip`（按量好的差演），落点夹在两者之间取。
- 合集弹窗关时若单季详情还开着：两条返程各自跑，父面板先移除 → 行的返程落点已不在线（`reinsertSrc` 返回 null）→ 动效自行收尾，不留半藏状态。
- 行右键/长按动作仍按老口径「先收弹窗再执行」（`deferClose`）：只有左键点击钻入保留合集弹窗，分层正是用户要的形态。

## 遗留

- 面板整刷丢「抽离」态（396 遗留）对合集行同样成立（行 `display:none` 是行内样式）。
- 行抽离让合集弹窗变矮，flex 居中带动整块面板位移 30px：面板已进 FLIP 滑过去，但弹窗**高度**变化仍是瞬时的（底边一跳）。用户未提，先记下。
- 合集弹窗里右键/长按的「打开详情」仍走老路径（先关弹窗再反查卡片；合集模式反查不到 → 无过渡）。带过渡的只有左键钻入。
