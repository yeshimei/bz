# 401 影院既有动效修正（手势一律整卡、往返同曲线、接力不断档、打断即折返、展开类统一）

## 背景

走查 2026-09-21 已落地的动效，发现五处「自己跟自己不一致」：

1. **卡片 hover 只抬海报**：`.pcard:hover .pw` 抬 7px，而 `.pname` / `.pmeta` / `.pstars` 是
   `.pw` 的兄弟（`shared.ts` 片卡 markup），片名与星级不动 —— 鼠标下卡片内部间距在变化。
   且抬升 .28s 与海报推近 .44s 是两个时长，收势时图还在放大。
2. **同一个「面板展开」，去程与返程两条曲线**：去程 clip-path 撑开走揭示曲线，返程折回走飞行曲线
   （`ui.ts` 的 `land` / `willClose`），往返不同缓动会让「关」比「开」急。
3. **内容接力在第 6 块起断档**：`.cn-modal--detail > *:nth-child(n+6)` 全部 .25s 同时出现；
   而详情弹窗的直接子元素 = 头部 + **每一条豆瓣信息行**（`shared.ts` detailModalHtml），
   一部片常有八到十个直接子块 → 后半段变成「齐发一坨」。
4. **压掉入场靠 `!important`**：`.cn-modal--fly > *{animation:none !important}` 之所以要
   `!important`，是因为内容接力选择器带 `:nth-child` 权重更高。需要 `!important` 才能关掉的动效，
   说明两条入场语法本来就不该同时存在。
5. **飞行途中关闭是硬切**：`phase === 'flying'` 时直接 `restoreSrc(); finish()`，海报凭空消失，
   既不折返也不淡出，与「涟漪 / 高亮都可中断」的口径不齐。
6. **展开类只有下拉做了**：`.dm-pick-list` 有 max-height 过渡，而详情里同语义的
   短评「展开全文」是 `is-fold` 类硬切（line-clamp 无中间态）。

## 决策（2026-09-21 用户拍板「按照你的来」）

- 位移一律作用在**整卡**（`.pcard`）而不是海报层：海报与片名同起同落，间距不动；
  抬升与推近统一走揭示档（`.28s`），一个手势一个时长。
- 面板 clip-path 的**去程与返程同曲线**（`--cn-e-out`），只在时长上区分（去程与返程同 .2s）。
- 内容接力阶梯排到第 10 块（步进 .03s、上限 .27s），不再「第 6 块起齐发」。
- 去掉 `!important`：把压入场的规则写成同权重且更晚出现
  （`.cn-modal--fly.cn-modal--detail > *`，权重与带 `:nth-child` 的接力规则相等，靠文件次序取胜），
  两条入场语法的从属关系改由显式类表达。
- **打断即折返**：起飞途中被关，面板立刻隐藏、遮罩淡出，**海报克隆带着图飞回源卡矩形**，
  落地才收克隆并 finish（与返程同一条语汇，不新增机制）。
- 短评展开走高度动画（实测 `scrollHeight` → 展开、收回到 3 行高 → 收起，收尾写 `max-height:none`
  让文本自然回流）；文字折叠仍由 line-clamp 负责，动效只补中间态。无几何环境（jsdom）回落即时切换。

## 落地

| 文件 | 改动 |
|---|---|
| `src/cinema/styles.css` | hover/active 位移改 `.pcard`；`.pw img` 推近 .28s；接力阶梯排到 `n+10`；`.cn-modal--fly.cn-modal--detail > *` 去 `!important`；短评展开态样式 |
| `src/cinema/ui.ts` | `willClose` 的 flying 分支改折返；`land` 的曲线改台账常量；短评展开/收起接高度动画 |
| `tests/cinema/ui.test.ts` | 打断折返（克隆归位后才 finish）；短评展开（无几何回落即时切换、有几何走动画） |

## 验证

- 单测（`tests/cinema/ui.test.ts` 新增 describe）：①飞行途中关闭——起飞件两段动画（去程 + 折返）、
  层已撤、飞行件不留、卡归位；②短评展开两条路径——无几何回落即时切换（不演动画）、有几何走
  `maxHeight` 从全高到 3 行高的中间态并清掉内联样式。
- 原型自检（真浏览器，jsdom 量不到的部分）：①`fly` 通道下 `.cn-modal--fly` 与其直接子元素的
  `animationName` 均为 `none`——去掉 `!important` 之后靠「同权重 + 排更后」取胜的约定由这条守；
  ②起飞途中点遮罩：飞行件仍在（折返中）、随后层撤 + 飞行件不留 + 卡归位。
- 打坏验证：把台账 token 改成 `.31s`、幽灵上限改 0、跳过落位闪——三条对应断言当场红（见 issue 402/403 验证）。
- 全量 `pnpm test` + `tsc --noEmit` 绿；原型自检 95/95。

## 遗留

- 面板整体入场（`cnModalIn` 的 `translateY(12px)`）是「凭空从下」而非「从来源」——共享元素通道已用
  clip-path 生长取代它，非 fly 通道（无海报 / 图对不上）仍是这一套。两条语法彻底合并需要更多几何条件，
  留待后续。
