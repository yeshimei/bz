# 442 · 脸谱域增强（五）：UI 深化（卡墙排序筛选 / 导出 / 合并重复人）

- 状态：待开发（2026-09-25）
- 关联：issue 435 / 436 / 438 / ADR-0101（域 UI 域内自绘口径）

## 范围

1. **卡墙排序 + 筛选 + 搜索**：
   - 排序：最近互动（默认）/ 消息量 / 建卡时间 / 名字
   - 筛选：按关系标签（`PersonProfile.tags`）
   - 搜索：按称呼 / 标签 / 备注关键词
   - 工具条追加在卡墙上方，不挤压现有头部（品牌区 + 统计条）结构。
2. **导出为 markdown**：详情页把该人的脸谱导出成笔记进 vault（默认 `我的/脸谱/<名字>.md`）：
   - 内容：画像 + 关系时间线 + 代表原话 + 事件列表 + 档案（有则含）
   - 用 vault 的 `create` 写入；同名文件存在时提示并追加序号（不静默覆盖）。
3. **合并重复人物**：卡墙卡片提供「合并到…」入口，把当前人并进另一位（用于同一人两个 wxid 的情况，如数据里的两个「冰玉」）。
   - data 层方法已就绪：`mergeInto(fromId, toId)`（批次 1 地基）。
   - 交互：选择目标人物 → 二次确认（说明「A 的导入记录与随手记会并到 B，A 将被删除」）→ 执行 → 提示重画脸谱。

## 非目标（本票不做）

- 详情页四区块折叠、时间线可视化竖轴（改动面与详情页中部结构冲突大，留到后续单独票）。

## 技术要点

- 排序/筛选状态放模块级变量（与 `stage` / `selected` 同款），`renderList` 读取后应用。
- 导出用 `app.vault.create`；文件名非法字符要清洗（`\ / : * ? " < > |`）。
- 样式追加到 `src/people/styles.css`；`:hover` 包 `@media (hover: hover)`；不自造滚动条（铁律 4 / ADR-0122）。
- 二次确认复用 `src/core/confirm`（若有）或域内既有确认口径。
