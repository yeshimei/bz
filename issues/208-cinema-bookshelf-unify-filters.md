# 208 — 影院交互回归原型 + 全域筛选「再点回全部」统一 + 网格列数设置 + 影视表单/详情精简

用户实测（2026-09-06 截图反馈），影院为主 + 全域统一交互 + 书库/影院各一项设置。

## 影院（cinema）

1. **类型树去三角**：剧集/动漫等带二级的组行尾 chevron 三角删除（回归原型「二级展开无三角」定稿；`bz-rail-caret` 唯一使用点，core components.css 死规则同清）。
2. **再点组取消**：选中组（如剧集）再点 = 取消筛选回「全部」，二级列表随之收起（展开态本就绑定期选中，取消自动收）；组内二级再点 = 回该组全部（不变）。
3. **「全部」加图标**：类型全部 / 状态全部行头补 lucide 图标（`layout-grid`，对齐收藏本/归物本行头惯例）；交互语义参考待办域——「全部」保留，点全部 = 回全部，再点其他选中项 = 跳回全部。
4. **移动横滑 chips 同步**：全部/状态全部 chip 加图标（renderAll 补 mountIcons）；类型 chip 再点取消回全部。
5. **表单去观影日期**：添加/编辑表单删除观影日期字段（不允许用户修改）；想看/在看态的字段显隐只剩评分/影评。
6. **日期自动维护**：创建影视 → 观影日期 = 当前时间；编辑时状态变更 → 刷新为当前时间，状态未变 → 保留原日期；右键「标记在看/已看」→ 状态流转即刷新（原 CM1 仅已看刷新语义扩为任意流转）。
7. **详情弹窗去「豆瓣页面」按钮**：保留豆瓣链接文本行（可点），按钮删除——打开豆瓣统一走右键菜单「在豆瓣打开」。
8. **去掉点状态灰字开快速面板**：海报卡想看/在看灰字改纯展示（去 data-cinema-upgrade / 可点态样式），快速状态窗（openQuickStatus）整体退役——状态流转统一走右键菜单「标记在看/已看」与编辑表单。
9. **网格每行列数设置**：`cinemaGridColumns`（string 键数字，默认 5，钳制 2~12；原固定 6 列），CSS 变量消费，移动端 3 列媒体查询不受影响。

## 书库（bookshelf）

10. **再点取消回全部**：状态行/分类行（桌面左栏 + 移动筛选抽屉同款）再点当前选中项 = 回「全部」；「全部」行图标已有，不动。
11. **网格每行列数设置**：`bookshelfGridColumns`（默认 6，钳制 2~12；原 auto-fill minmax(140px,1fr)），移动端 2 列媒体查询不受影响。

## 全域统一（保留「全部」，再点选中回全部）

12. **剪藏本（clipbook）**：桌面 rail 源行 / 移动 chip 再点当前选中源 = 回「全部未读」。
13. **文献盒（literature）**：领域筛选行「全部」按钮加图标（领域按钮再点取消已有）。
14. **已达标域不动**：待办（参考范式：layers 图标 + 再点回全部）、收藏本、归物本、回忆墙（无全部行，标签再点取消已有）。

## 验收

- 影院：剧集展开后再点剧集 → 回全部 + 二级收起；类型/状态再点选中项 → 回全部；全部行带图标无三角。
- 影院表单无观影日期字段；新建/改状态落盘观影日期为当前时间；只改评分/影评不刷日期。
- 详情弹窗无「豆瓣页面」按钮；点想看/在看灰字不再弹窗。
- 书库/影院网格列数随设置变化（重开面板生效），移动端列数不受影响。
- 剪藏本再点当前源回全部未读；文献盒全部按钮带图标。
- 全量 pnpm test + tsc --noEmit 绿。
