# 214 · 剪藏本桌面端编辑部印刷风换肤（P1 定稿落地）

## 背景
三栏原型 p1-editorial 经 10 版左栏对照（p1-spine-10.html）拍板 **V1 点线索引**；
完整交互定稿原型 `p1-final.html` 已验收（含四处去除 + 动作进右键菜单）。
本 issue 把定稿视觉落到 `src/clipbook` 桌面端（移动端双屏不动）。

## 拍板项
1. 左栏 = V1 点线索引：衬线名 + 点线引导 + `未读/总数` 计数（未读橘粗），
   选中 = 行首墨色小方块 + 橘名；源徽标/图标在剪藏本 rail 内隐藏；搜索框留在 rail 顶部、rail 右键批量动作保留。
2. 头行：去「未读流与剪藏」副题；新增 期号行「YYYY 年 M 月 D 日 · 第 N 期」（N=news 总条数，随数据刷新）；⚙/✕ 保留（issue 201 范式）。
3. 中栏 = 目录：serif「目录」栏头（无副题小字）；条目前置大号序号，
   **未读唯一视觉 = 序号颜色**（未读橘 / 在读琥珀 / 其余灰），状态圆点桌面端退役（移动端保留）；
   排序未读在前（组内保持最新在前）。
4. 阅读面：去站点独立行（favicon+站点并入 meta 行）；serif 大标题；
   正文两端对齐 + 首段首字下沉；去文章底部「查看原文」链接与动作按钮
   （原文/已读/保存在右键菜单已有；剪藏条目保留「打开笔记」编辑部文字脚 links，data-clip-open-note 不变）；
   字号分段、摘要块保留并做编辑部化处理。
5. 右键菜单（core item-actions）在剪藏本面板内做域内编辑部换肤（纸底/墨框/衬线/橘悬停），
   只作用于 `.bz-clip-frame` 子树，不影响其他域。

## 边界
- 数据层（news.json / clipbook.json / flow / store 查询口径）零改动；排序为 UI 展示层。
- 移动端双屏、增强包（搜索防抖/阅读动线/撤销/尺寸记忆/favicon 链）行为零改动。
