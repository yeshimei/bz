# 218 书库面板换血：书脊墙 1:1 复刻（原型 p4-full）

日期：2026-09-06　域：bookshelf　ADR：0096

## 需求
用户拍板：1:1 复刻 bookshelf-10/p4-full.html 书脊墙布局，完全抛弃旧书库布局——原型里没有的一律不要（统计卡/月柱/纪念日卡/左栏/封面网格/筛选抽屉/移动专用布局全退）。

## 实现
- ui.ts 整体换血：刊头（书脊墙·SPINE WALL）+ 纸质统计标签行（全馆/已读讫/在读抽出/未读倒叠 + 分类册数；点选筛选再点回全）+ 工具行（检索 + 最近读完/时长最长/书名三档）+ 动态装箱墙体 + 倒叠区 + 墙尾格言；移动端同构。
- 书脊：高度=时长、厚度=字数（data.ts 新增 wordCount/pages 解析，EPUB 回退批注密度）、分类色 ±7% 抖动、主/副题双列竖排（：拆分 + upright + 14→9px + 64px 上限）。
- 借书卡详情：纸卡 1:1 + 全编辑融卡（状态/进度/读完日期/书评/直达/笔记/删除/撤销），EPUB 只读不变。
- 报告：容器与命令链路保留，墙面无入口（ADR-0096 决策 7）。
- 十肤随迁：--bz-* token 层 + --bsw-* 墙变量映射（styles.css）。
- 设置收敛：bookshelfGridColumns 键全删；排序存量值零感知映射（applyDefaultView）。
- 测试：ui.test.ts 重写（27 例）、notes-ui 选择器/文案随借书卡口径、default-view/walkthrough C-1/C-3/C-5 契约更新。门禁：pnpm test 4174 全绿 + tsc 干净。
