# 464 — `sync` 子命令：从微信取数到 chat.json 与头像源

## Parent

`issues/460-people-face-restructure-spec.md`（spec）。门禁与工作流按 `AGENTS.md`。

## What to build

`bz-face sync` 一次跑完：取密钥 → 解密数据库 → 逐联系人导出 `chat.json`（文本 + `[表情·名]` + 图片定位 + 音频路径/时长）→ 从微信头像库抽出该人头像落到其目录。幂等可重复跑，进度经四行协议吐出。

**转写、媒体导出、图片描述都不在本票。**

## Acceptance criteria

- [ ] 一次 `sync` 后，数据根下各联系人目录出现/更新 `chat.json` 与头像源文件
- [ ] `chat.json` 只含「从微信解出来的事实」——**不含语音转写文本、不含图片描述**（语音保持 `[语音 N秒]`、图片保持 `[图片]`）
- [ ] 表情命名在本次生成时**一次写入**（不再有独立的「回写」步骤）
- [ ] 重复执行幂等：不重复搬、不破坏已正确的产物
- [ ] 微信未运行时立即失败并给中文引导，**不静默降级成读旧目录**（否则用户会误以为同步成功）
- [ ] 单个联系人导出失败不中断整体；末尾结果行报失败数
