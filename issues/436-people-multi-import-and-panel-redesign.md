# 436 · 脸谱域整改：多联系人勾选导入 + 主页面视觉重做

- 状态：开发中（2026-09-25）
- 用户原话①：「我这边是微信的备份，里面有很多人的聊天记录」→「导入的时候，让我勾选我想导入的内容」
- 用户原话②：「目前你的界面没有背景色」+「能不能像其他域一样，做一个完整的独立主页面，把所有的操作都集中在一起，并且要有设计感、好看」+「你做的太简陋了」
- 关联：issue 435 / ADR-0191（脸谱域首版——本票是用户实机反馈后的整改票）/ ADR-0101（域 UI 域内自绘口径）

## 范围

1. **多人备份导入**：parse 层改为按 talker 分组（`ParsedWechatExport.contacts: ContactGroup[]`），覆盖四种形态——CSV talker 列分组 / JSON 数组元素 talker 分组 / JSON keyed 对象（`{ wxid: [...] }`）/ JSON 单对象（老形态）；导入向导新增「联系人勾选」步（checkbox + 每人可改称呼 + 消息数/跨度 + 全选/全不选），勾选后逐人提炼生成。
2. **主页面重做**：完整独立主页面——亚麻纹理底板（favorites 同款双斜纹配方）+ 印章式品牌区（朱红「脸」印 + 标题/副标题）+ 统计条 + 卡片墙（圆形首字头像按名 hash 取色）+ 三步向导条 + 生成进度旋转指示 + 入场动效；亮暗双主题；窄容器单列。
3. 批量生成逐人进度（「正在生成 老王（2/5）」+ 批进度子行）+ 失败名单汇总（单点失败不中断整批）。

## 非目标（沿用 ADR-0191）

- 手动档案区 / 随手记事件流 / 跨人向量检索 / Jev 亲疏提醒（后续票）。

## 技术要点

- 主色改朱红（戏台/脸谱意象）：`--acc: #a8433c`（亮）/ `#c0645a`（暗）。
- `:hover` 全量包 `@media (hover: hover)`（呈报#9 F4 守卫）；滚动条藏而不自造（ADR-0122）。
- 头像色板 8 色按名字 hash 取；wxid 形态展示名截前 10 字符。
- 解析层保持嗅探式；分组排序 = 消息数降序（并列字典序）。
