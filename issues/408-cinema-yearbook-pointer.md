# 408 · 观影志指针层：26 幕的鼠标干扰与交互全部接线

用户原话（2026-09-22）：「鼠标移动对元素的动态干扰和鼠标交互哪些页面可以实现一些动态效果呢？」
→ 给出分档清单后：「全都做」。

前情：指针层机制在 issue 406 就搭好了（引擎归一化指针 → 每幕表演），但只有 01 开卷真的用了
（粒子斥力），13 幕还留着一截算了平滑却什么都不做的死代码。这一批把 26 幕接满。

## 交付

**工具箱（`src/cinema/yearbook/kits.ts`）**
- `PointerAt{cx,cy,px,py}`：客户端坐标（命中判定、浮签定位）+ 归一化 -1..1（视差/斥力）；
- `localAt(host, p)`：宿主内比例坐标，出界给 null（画布类命中判定）；
- `nearest(spots, at, r)`：比例坐标里最近的一枚（等分栅格、星图节点）；
- `under(p, sel)`：`document.elementFromPoint` + `closest`——**不逐元素量 rect**；
- `tip(root, html, cx, cy)`：全片共用一个浮签节点（挂 `.bz-yb`），传空串即隐藏；
- `toward()`：逐帧朝目标挪（跟手量不跳变）。

**运动层（`motions.ts`）**：`Perf` 加 `move/down/up` 三个钩子，26 幕逐幕接线——
跟手（04 日晷 / 09+11 河流 / 13 散点 / 16 领奖台 / 17+25 板墙 / 25 磁吸）、
悬停读数（03 / 05 / 06 / 10 / 12 / 13 / 23 / 24）、联动（08 条↔星图 / 14 同档两侧 / 12+13 压暗其余）、
动词（07 尺子读数 / 15 按住天平 / 19 弧线站出来 / 20 扇面摊开 / 22 卡片倾斜 / 26 翻页钟倾斜）、
23 弹幕悬停减速（位移从无状态取模改成逐帧累积）。

**版式层（`scenes.ts`）**：浮签文案在 build 期就写成 `data-tip`（片名、日期、部数、集数），
运动层不再回算一遍——两处各写一份必然漂移。`title` 全部换成 `data-tip`（免得原生与自绘两套气泡）。
新增 `.yb-rread`（07 尺子上的读数线）。

**引擎（`engine.ts`）**：`pointermove/down/up` 只发给当前幕；翻幕 / 指针离场 / `stop()` 收浮签。
`buildPerfs(root, data, host)` 第三个参数 = 浮签挂载点（必须与引擎清理时用同一个元素）。

## 踩到的坑（都留了注释）

1. **浮签挂错宿主**：表演拿的是影片根、引擎清理拿的是整屏根 → 一边建一边清，
   切幕后上一层楼的读数赖在画面上（截图实拍发现）。修法：`buildPerfs` 第三参数统一挂载点。
2. **jsdom 没有 `document.elementFromPoint`**（连属性都没有，`vi.spyOn` 直接报 not defined）→
   `under()` 里 `typeof` 判断 + try/catch，测试用 `withHitTest()` 临时装一个假命中判定。
3. **翻幕那 160ms 里幕还在动**：断言「切幕后不再吃指针」要等遮片合上、上一幕被推到终态再取基准值。
4. **`(t*speed)%420` 这种无状态位移没法慢放**：弹幕减速必须改成逐帧累积（`t<.1` 时归零重来）。
