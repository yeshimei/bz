# 529 · 详情页「查看聊天」+ 本人头像可上传（默认用微信里扒出来的本人头像）

## 背景（用户原话）

> 「脸谱详情页的中间的合上这页按钮改成查看聊天（改成更符合的含义），然后打开一个和微信界面一样的
> 聊天排版界面，排版界面复用录音的查看轮次的界面，把这个界面改得更像微信」
>
> 「在脸谱的设置界面增加一个选项，可以让用户上传一张图片当头像，默认使用从微信数据里面扒出来的图片」

三处澄清（开工前逐条问过，均按推荐项拍板）：

1. 改的是**详情页动作签里那枚**「合上这页」（页眉右上角那枚继续关页）。
2. 「上传头像」指**「我」那一侧的头像**（设置里现有的「我的头像」文本路径行）；默认值取微信头像库里
   本人账号的头像。
3. 聊天页读**真实聊天仓**（多的两万条）：默认最近若干条，往上滚 / 点「更早的消息」继续加载。

## 一、查看聊天（详情页动作签 → 仿微信聊天页）

### 现状

- 详情页动作签最后一枚是「合上这页」（`data-people-act="back"`），与页眉右上角那枚完全重复——
  而聊天仓里那几万条消息在面板上**没有入口**（只能画脸谱时被 AI 消费）。
- 录音页签的「查看轮次」已经是一版微信式会话流（`recTurnsPreview`：头像 + 气泡、我方靠右绿气泡），
  但只有最朴素的骨架：无时间分隔、无媒体标签形态、无底部栏。

### 拍板

- 动作签「合上这页」→「查看聊天」（`data-people-act="chat"`，lucide `message-circle`），打开册页弹窗
  `dialog.kind = 'chat'`（沿用册页外壳：页眉 + 可滚正文 + 页脚）。
- **会话流单源**：抽出 `ChatLine` + `chatStream`（render.ts），「查看轮次」与新聊天页共用同一份渲染——
  用户说的「复用录音的查看轮次的界面」即此。两处只在头部说明行与「更早」入口上有别。
- 更像微信的四件事：
  1. **时间分隔条**：与上一条间隔 > 5 分钟才出一条（今天 `HH:mm`、昨天 `昨天 HH:mm`、
     今年 `M月D日 HH:mm`、更早 `YYYY年M月D日 HH:mm`）——微信同款。
  2. **媒体标签**：`[图片]` / `[语音 12秒·平静]` / `[表情·名]` 这类前缀剥出来单独成签（带 lucide 小图标），
     标签后面的描述 / 转写作气泡正文。
  3. **群聊显示名**：会话里除「我」之外有多个发送者时，气泡上方出名字（单聊不出）。
  4. **微信底栏**：只读提示 + 「回到最新」；进页落到最新一条，往上滚加载更早（哨兵自动 + 按钮兜底）。

### 分页口径

- 每人聊天仓最多两万余条，**不整页铺**：常量 `CHAT_PAGE = 50`，进页只上屏最近 50 条；
  `data-people-chat-more` 哨兵进视口（`IntersectionObserver`，`rootMargin: 600px`）自动再放 50 条，
  点哨兵同样放（IO 缺席的环境兜底）——与留影网格的分片是同款范式（issue 519）。
- 加载更早是**往上长**：重画前记「离底距离」，重画后按同一距离还原（`scrollSnapshot` 记的是
  `scrollTop`，对往上长内容的场景不够用，聊天页单开 `chatAnchoredBottom` 通道）。

## 二、本人头像可上传（默认取微信里的本人头像）

### 现状

- 设置里「我的头像」是一个**文本路径行**（`peopleMyAvatar`），要用户自己填一个库外绝对路径；
  留空 = 聊天里「我」一侧落首字印。
- 数据根里只有**联系人**头像（`<数据根>/<联系人>/avatar.<ext>`）；本人头像在微信头像库
  `head_image.db`（键 = 账号自己的 wxid），**工具侧从来没导出过**——所以插件无从「默认」。

### 拍板

- **工具侧补一次导出**（`tools/obsidian-face/python/bz_sync.py`）：sync 轮解出账号 wxid 后，
  把本人头像按字节比对幂等地落到 `<数据根>/.bz-face/me/avatar.<ext>`（放 `.bz-face` 下，
  不进联系人目录 = 不会被数据源扫描误当成一位联系人）。
- **插件侧默认值**：`peopleMyAvatar` 空 → 读 `<数据根>/.bz-face/me/avatar.<ext>` 的字节转 data URL
  （与「我」此前读库外路径同一条通道：`readAvatarInput` + `localImgOf` 缓存）；读不到才落首字印。
- **设置行改成上传**：`text` 行换成 `custom` 行——头像预览 + 「上传图片…」（系统文件选择器）
  + 「恢复默认」（清空键值）。上传的图**复制进 vault** 的 `CONFIG/FACES/我/avatar.<ext>`
  （历史明文头像目录，467 后退役但仍在；库内相对路径走 `getResourcePath`，两端都能加载），
  键值存这条库内相对路径——用户换机 / 同步 vault 也带得走。

## 明确不做

- **不在聊天页渲染图片 / 语音本体**（只出标签 + 描述 / 转写文本）：列表动辄上千张图，
  逐张读字节转 data URL 是开页冻死的病根（issue 519 的教训）；留影页签已有网格大图入口。
- **不给聊天页做输入框**（只读数据，不做假输入）：底栏只出只读说明与「回到最新」。
