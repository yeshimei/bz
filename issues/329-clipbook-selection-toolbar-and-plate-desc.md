# 329 · 剪藏本划选工具框 × 知识盒直达 + 图版描述

- 状态：已实现（2026-09-15，grill 拍板 → 双 worktree 并行开发 → 串行合并部署，ADR-0144/0145）
- 关联：ADR-0144（划词锚定）/ ADR-0145（图版描述语法）/ ADR-0116（术语来源 source 键）/ ADR-0122（文献预览与渲染契约）/ ADR-0068（保存分流先例）/ issue 328（名词重名防护，录入面板继承）

## 用户原话拆解

1. 「桌面端和移动端可以复制文字和保存图片」→ 阅读器式**划选工具框**（澄清轮拍板，非右键菜单），双端同套。
2. 「接入知识盒的名词，段落和图版，可直达」→ 工具框动作直达知识盒录入（预填选中内容）；
   锚定双链点击**直达知识盒文献预览**（第三轮拍板，非打开 md）。
3. 「图版增加描述输入框……创建文献笔记时放到 [[图片路径|描述]]」→ 语法拍板选三
   `![[路径|描述]]`（描述占嵌入尺寸位，依赖用户侧渲染插件显示）；每图一框；描述喂 AI。
4. 第二轮拍板：单击图片弹工具框；图片落剪藏附件目录 + 已保存条目自动换链。
5. 第四轮拍板：段落同名词锚定机制；图版 source 跟随名词逻辑；描述喂 AI；复制 = Markdown。
6. 「不需要用块 id 了」（第三轮拍板简化）——砍掉初版段落尾 `^bz-xxxx` 方案。

## 修订

- **2026-09-16 正文无法选中修复**：阅读窗格与移动详情层显式 `user-select: text`（`.bz-clip-read` /
  `.bz-clip-mob-detail`）——自定义面板不在 Obsidian 阅读视图的选择豁免内，移动端壳层默认禁选、
  长按不出选区，划选工具框由此完全不可用。桌面 Obsidian 壳层（asar 逐条核对仅 PDF 阅读器禁选）、
  本插件 CSS、社区插件与快照均无全局禁选规则；显式放开为双端零风险兜底。

## 追加修订（2026-09-16 第三批 · 移动端四 bug）

- **工具框被系统选择菜单遮挡**：`placeSelBar` 移动端加 48px 系统菜单让位（上方放不下翻下方同理），
  桌面行为不变。
- **动作后详情层不即时重渲**：`handleAnchorCreated`/`actSaveImage` 原只调 `renderReader()`（桌面右栏），
  移动详情是独立渲染路径——新增 `refreshReadingViews`，`M.mobDetailOpen` 时连 `renderMobDetail()`。
- **点锚定双链崩溃**：锚定链接是裸 basename，`resolveInternalTarget` 只认全路径 → 拦截必失败走原生
  导向（崩溃发生在这条未预期路径）。补第三级解析：`metadataCache.getFirstLinkfileDest` 按 Obsidian
  原生口径把 basename 解析为全路径，命中文献盒即直达预览，盒外维持原生导航。
- **保存后 source 未升级**：`addArticleMark` 只记 marks、从不登记 pendingSource，物化升级名单恒空。
  双修：划词时补 `addPendingSourceNote`；物化名单改 `pendingSource ∪ marks.notePath` 并集
  （顺带救回修复前已划词未保存的存量数据）。

## 追加修订（2026-09-16 第二批）

- **图片命名去文章标题**：新增 `imageNameFromUrl`——优先取 URL 自带文件名（剥 query、清洗、须带图片
  扩展名），取不到回落 `clip-<yyyymmdd-hhmmss>-<序>`（扩展名由 content-type 映射）；单图保存与全量
  保存同源，撞名仍由永不覆盖 `_2` 兜底。
- **保存剪藏全量图片本地化**：覆盖确认后、写 md 前提取正文全部外链图（去重保序），侧写 savedImages
  命中直接复用不重下，其余逐张下载落盘；src→local 全量映射走既有 `applyBodyTransforms` 换链管线
  （与划词替换同一变换）；单张失败保留外链不阻断；progress 通知原地更新、结果按可感知性原则收口。
- **条目菜单补「复制原文链接」**：news 分支补上（保存之后、标读之前）——此前仅已剪藏条目有复制动作，
  移动端抽屉与桌面右键共用 `buildItemActions`，一处接入两端生效。
- **抽屉头部对齐核心**：自绘 `sheetHead`（`.bz-clip-sheet-*`）退役，改核心标准 `sheetTitle/sheetSub`
  （与 memo/favorites 同款两行省略），域内三行自绘样式删除。

## 设计

### A. 剪藏本：划选工具框

- 文字选区 → 光标上方浮框（桌面/移动同套）：**复制 Markdown / 存为名词 / 存为段落**；
  图片单击 → 浮框：**保存图片 / 存为图版**（不复用 item-actions 菜单）。
- 复制 Markdown：渲染层持原文 body，选区文本回查源 markdown 片段写剪贴板（非 DOM textContent，保语法）。
- 工具框发起的录入动态 import knowledge 录入面板（`openTermNote`/`openPassageNote`/`openImageNote`
  扩展预填参数：选区文字、图片 data URL、原文 url+标题），生成后**不自动打开笔记**。

### B. 划词锚定双链（ADR-0144）

- 选区替换 `[[笔记|原文字]]`，无块 id；剪藏本阅读器内点击拦截导航 → 知识盒文献预览
  （knowledge 域新增按 path 直达预览 API，`openPreview` 同款渲染契约）；
  Obsidian 原生打开剪藏 md 时维持原生跳转。
- 落盘两路：已保存 md 划词即直写；未保存条目渲染层内存替换 + 侧写标记
  （clipbook.json 按 articleKey），**保存物化**时替换进 md 并清标记。
- 保存物化同场加演：此前「保存图片」已落盘的本地图一并在 body 换链
  （外链 → `![[本地路径]]`，依据侧写 src→local 映射）——与划词物化同一变换管线。
- source 两态（名词/段落/图版一致，图版无正文锚定仅 source 跟随）：未保存=外链 URL；
  保存物化时回写 `[[剪藏路径|标题]]`；已保存文章发起录入则落盘即内部路径。

### C. 保存图片

- 目录：新设置键「剪藏图片文件夹」，默认 `归档/网页剪藏/assets`（回落范式同 knowledge
  `resolveImageDir`）；文件名取条目标题判重永不覆盖。
- 已保存条目：存图后立即把正文该外链换成本地嵌入（md 直写）；未保存：仅落盘
  （news.json 外部双写不可写），保存为剪藏时随物化换链。

### D. 图版描述（ADR-0145）

- 图版态缩略图网格逐图描述框；删图连描述一起没（作废草稿既有语义协同）。
- 写入 `![[路径|描述]]`，无描述 `![[路径]]`；描述随读图请求喂 AI；不设 frontmatter 键。
- 从剪藏本发起时图片预填进内存（data URL 管线复用，确认写入才落盘）。

## 测试面

  图片换链（立即 / 物化两路）。
- 工具框：桌面/移动出现逻辑、五动作触发、录入预填参数、复制 Markdown 剪贴板内容。
- knowledge：按 path 预览直达 API；图版逐图描述框渲染与写入；`generateImageNote` 描述拼接
  （有/无描述分叉）；描述进读图 prompt；source 两态回写（物化时改写 frontmatter）。
- 回归：ADR-0122 追加渲染契约（渲染前清空容器）；ADR-0143 名词重名拦截继承；
  news fetcher / 保留策略不受渲染层替换影响。
