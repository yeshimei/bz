# 396 · 详情弹窗共享元素过渡：海报抽出飞入 + 面板从海报生长 + 关闭返程

> labels: feat ｜ map: cinema ｜ status: done ｜ assignee: — ｜ blocked-by: 395
> 上游：issue 395（双面翻转卡片与影院全域动效的延续）
> 实现于 `wt/bz-cinema-parse`

## 背景

点卡片开详情原来是硬切（`el.remove()` 同款瞬间出现/消失）。用户拍板做共享元素过渡：

> 点击卡片，这张卡片就像从列表中抽出来，移动到对应的位置（刚好是详情界面的海报的位置），让详细界面再从海报中生长出来。

中途三次改口径：先嫌「动画时间很短很短」，后明确**图片飞行 0.2s**；再要求抽离形态从「留空框压暗」升级为**整卡从列表抽离、其余卡动画补位，关闭时列表让位、卡片插回原位**。

## 决策（2026-09-21 用户拍板）

1. **时长**：图片飞行 **0.2s**、撑开/折回 0.2s（开 ≈0.4s，关 ≈0.4s）。刻意**不做** prefers-reduced-motion 放缓分支——用户本人系统即报 reduce，时长是明确给的口径，放缓分支等于替他改决定（与 395 翻转卡「放缓」分支的口径差异在此，是有意的）。
2. **抽离 = 整卡从列表消失**：不是留空框压暗——`display:none` 抽走，其余卡以 FLIP 动画**补齐空位**（只演视口内的卡，视口外的跳变看不见，也省下几百个合成层）。
3. **关闭 = 直飞插回**：面板折回海报矩形（clip-path 逆放 + 遮罩同步淡出）→ 列表**让出空位**（其余卡反向 FLIP）→ 海报从详情海报位**直飞**回空位，落地卡片显形。（「绕右上角再插入」是用户报的 bug——返程瞄准坐标被源卡自己的纠正动画污染，已修；曾被误当需求实现过一版绕行，已拆。）
4. **时长用户说了算**：是他试出来的偏好，不是可访问性参数。

## 关键实现口径

- **飞行件是目标尺寸的盒**，用「平移 + 非均匀缩放」对到两端（卡片 2:3 与详情 7:10 差约 5%，飞行中不可辨）——transform 动画全程不触布局，不重蹈 395 翻转卡顿的覆辙。
- **clip-path 只揭示不位移**：面板撑开/折回都是裁剪窗变化，海报原地不动，才谈得上「从海报生长/缩回海报」。终帧外扩 64px 罩住面板投影（clip-path 连投影一起裁，不外扩收尾会闪掉影子），fill 缺省 none 不留常驻裁剪层。
- **来源卡反查**：菜单/抽屉动作手里只有条目，`openDetail` 按键反查同一张卡；季明细钻入时源是合并卡正脸、与钻入季可能不同图——图对不上就不飞（硬飞会在落地瞬间跳图）。
- **归位路径分三条**：返程落地（正路）、跳过返程 / 异常时由宿主 MutationObserver 兜底（遮罩被移除且不在关闭流程 → 归位）、关闭流程中归位由返程落地负责（观察者刻意不抢，抢了就是飞行途中卡片先长回列表）。
- **FLIP 集合必须排除源卡本体**：`display:none` 的卡矩形是全零，混进补位/让位集合会领一条「从 (0,0) 飞到空位」的纠正动画，而 `getBoundingClientRect` 连 transform 一起量——返程瞄准坐标被污染，海报飞到面板角落（2026-09-21 实测 bug，探针落点断言 dCenter (−183,−128) → 修复后 (1,1)）。
- **时长没有 reduce 分支**：`seDur` 的 ×1.4 曾实现后被撤——用户本人系统报 reduce，放缓分支直接违背他给的 0.5s。

## 测试

- `tests/cinema/`：275 条通过（jsdom 无布局几何，`begin` 的几何门槛正确落入「不飞」分支，既有详情用例不受扰）。
- 原型自检 63/63（新增 fly 通道 / 落地卸裁剪 / 关闭返程归位三条，轮询不拍死等待）。
- CDP 探针（真浏览器）：去程 50% 帧（海报离卡、源卡空框压暗、背景淡入）、返程中段帧（海报飞回、卡片保持抽走态）、终态四项（遮罩移除 / 克隆移除 / 海报归位 / 卡片归位）全过。
- 全量：473 文件 / 7031 用例通过；`tsc --noEmit` 零错。

## 遗留

- **面板整刷会丢「抽离」态**：`display:none` 是行内样式，后台抓取完成触发 `renderSoft` 重建网格后，源卡片会回到列表（详情仍开着）。要根治得给网格重建加「借出中」记忆，成本大于收益，先记下不做。
- **关闭只有折回 + 飞回**，没有再做面板整体的 3D 翻转——「翻过来放回去」按「折回海报再放回卡位」理解落地；若要翻转语义再加。
