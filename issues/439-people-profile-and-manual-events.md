# 439 · 脸谱域增强（二）：手动档案 + 随手记

- 状态：待开发（2026-09-25）
- 用户原话：「我可以导入微信的聊天记录，然后输入关于这个人的各种信息，比如他的社交账号、我和他发生的一些事情等等」（issue 435 立项时的原始诉求，436 列为非目标挂账）
- 关联：issue 435 / 436 / 438 / ADR-0191（背景写明「聊天记录是素材来源**之一**而非全部」）

## 范围

1. **人物档案**：详情页新增「档案」区块，可编辑并落盘 `PersonEntry.profile`（schema 已在批次 1 地基定好）：
   - 社交账号（多条：平台 + 账号，可增删）
   - 生日、认识方式、认识时间、家乡/现居、职业
   - 关系标签（自由标签，可增删）
   - 一句话备注
2. **随手记一笔**：不依赖导入，随时给某人加一条事件（`ManualEvent`：日期 + 一句话），可删除；落盘 `PersonEntry.manualEvents`。
3. **重画画像时合并手动素材**：`manualEvents` 与导入提炼的事件一并进时间线素材（口径：手动记的优先级不低，但要在时间线里与提炼事件自然融合）。
4. 没有档案/随手记的人物，详情页保持现状（不出现空区块）。

## 非目标

- 手动编辑 AI 生成的事件 / 画像（后续票）。
- 独立于人物的全局随手记（那是 diary 的活）。

## 技术要点

- data 层方法已就绪（批次 1 地基）：`updateProfile` / `rename` / `addManualEvent` / `removeManualEvent`。
- 表单交互走事件委托（与既有 `data-people-*` 属性同款），不改现有委托入口的结构。
- 样式追加到 `src/people/styles.css`，遵守：`:hover` 包 `@media (hover: hover)`；不自造滚动条（铁律 4 / ADR-0122）。
- 新增样式文件不需要动 `scripts/build-css.mjs`（people 已在清单内）。
