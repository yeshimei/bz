# 459 脸谱二期：画脸谱管线——`prep` + 图片描述 + 画像生成 + 进度暂停

## 背景

一期（issue 458）打通了「同步」与加密聊天仓。二期补上用户要的那条链：

> 当用户对某个联系人进行画脸谱，流程从原始数据中导出各类媒体资源，完成后 ① 本地模型语音条转文字 ② 用 bz 中 AI 设置的服务商指定模型处理图片描述（用户二次确认才开始）③ 调用 AI 生成脸谱（用户二次确认才开始），整个流程可暂停，可中断恢复，完整的进度通知。

决策依据见 ADR-0196（阶段切分 / 协作式暂停 / 进度层级）与 ADR-0197（素材源与写入语义）。

**阶段切分（A 案）**：`sync`（全量、轻）与 `prep`（按人、重）分离；**画脸谱 = `prep` → 图片描述 → 画像生成**。

## 改动

### 1. 工具侧 `bz-face prep <联系人>`

- 媒体导出：`image/`（含 `.dat` 解密与 `wxgf` 解码）、`video/`、`file/`、`voice/`（silk → wav）+ **`desc/` 派生档**（长边 1280 / JPEG q80，供 AI 描述；`thumb/` 实测 115×120px 读不出截图文字，不用）。
- 产旁路表 `image_map.json`（图片↔消息关联，**不写 `chat.json`**）与 `voice.json`。
- 语音转写：按 AI 面板 `asrEngine` / `asrWhisperModel` 下发（SenseVoice-Small 缺省）；一个进程吃完全量，按 wav 幂等跳过已完成。
- 幂等续跑 + `.bz-face/state.json` 断点 + `.bz-face/control.json` 协作式暂停（步骤边界与每条媒体之间让行，**不硬杀**——funasr 冷加载按分钟计）。

### 2. 插件侧数据接入

- `readContactBundle` 扩展：读旁路表并按 `key` **upsert** 合并进聊天仓（`img` / 转写 → `text`）；保留 `readContactBundle` 的 extras 兜底语义。
- `jobs.ts`：job 扩 `preprocess` 阶段（工具段作为前两阶段）；**指纹从「条数 + 末条派生键」改为组装素材的内容哈希**——回写让「条数不变、内容变了」成为常态，旧指纹会拿旧素材静默续跑。

### 3. 图片描述（AI，插件侧）

- 批次 **20 张/次**（`peopleDescBatch` 可调）+ 上下文窗 = 该批首图 ct 前 1 小时 ～ 末图 ct 后 1 小时内的对话，**字符上限 6000**（超限按距图片的时间远近裁两端）。沿用 `.ctx` 的时间戳行格式。
- 读 `desc/` 档字节 → `imageDataUrl` → `core/ai` 的 `{text, images}` 通道；复用 AI 面板的服务商与当前模型（**不新增视觉档设置键**；`peopleImageDescMode` 的历史占位值 `'ai'` 退役）。
- **断点粒度 = 批**：已落盘的批不重跑；单批失败只废这一批、可重试。
- 结果合并进聊天仓对应条目的 `text`（`[图片] 描述`）。
- **二次确认弹窗**：`用 <服务商>/<模型> 描述 N 张图片，约 M 次调用；已完成 X 张，本次从第 X+1 张开始`，按钮 **开始 / 跳过图片描述**（跳过 = 图片以空 `text` 进仓，流程继续走到画像生成）。

### 4. 画像生成

- 接现有三次调用（其人 → 我们 → 时间线），素材从聊天仓按 `text !== ''` 组装。
- **二次确认弹窗**：`用 <服务商>/<模型> 画《X》的脸谱，素材 M 条、约 K 次调用`，按钮 开始 / 取消。
- **零媒体联系人自动跳过** `prep` 与图片描述两段（不为 0 张图弹确认）。
- 增量：已画过的人再次画只跑增量（`planIncremental` / `watermarkSid` 既有机制）。

### 5. 进度、暂停、互斥

- 生成进度块步骤行：`媒体导出 312/1631` → `语音转写 45/1289` → `图片描述 3/82 批` → `其人` → `我们` → `时间线`。
- 系统通知只在**完成 / 失败 / 转后台**三个阶段发，不逐步发。
- 暂停文案沿用「这一批做完就暂停」/「继续生成——已完成的批次不重画」；工具段暂停走 `control.json`。
- 失败分两类：密钥/解密 = 硬失败整链停；单条媒体/语音 = 计失败数继续，末了 `[bz-result]` 报 `failed:N` 并提供「重试失败项」。
- 同步与画脸谱**互斥**（同步期间画脸谱入口置灰）；**中断不自动续**（崩溃遗留 `running` → `interrupted`，出「继续生成」）；**上锁暂停**（与保险库 `unlock-changed` 联动）。

## 验收

- 测试：批切分与上下文窗（纯函数，含字符上限裁剪）；描述结果合并进 `text`；断点续跑（已完成批不重跑、中断后从批边界续）；`preprocess` 阶段推进与快照；零媒体跳过；互斥守卫（同步中不可画、画中不可同步）；`text` 空串不进素材；指纹改哈希后的判废/续跑矩阵。
- 门禁：`pnpm test` + `tsc --noEmit` + 自审 + diff 审查 + 主仓 `pnpm run build`。
- 人工：拿一个真实联系人（大琳级别：1631 图 / 1289 语音）跑完整条，**中途暂停 / 中断 / 恢复各验一次**；另拿一个零媒体联系人（如七七）验自动跳过。

## 遗留

- `synthesize.py` 的「连发归组」确认退役（不实现）。
- `parse.ts` 留痕通道仍冻结。
- 图片描述的模型档（是否给脸谱单独的视觉档）留待实际成本数据出来后再议。
