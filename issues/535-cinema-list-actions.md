# 535 · 影院：合并卡的片级动作 + 抽屉「移出<片单名>」直出行 + 侧栏计数按片单收敛

## 用户要的（2026-10-01 原文三条）

1. 合并卡的条目抽屉增加「归入片单」（一次性把所有影视加入到片单）和「加入重映厅」；
2. 加入片单的影视和合并卡的条目抽屉增加「移出片单」（片单换成对应的片单的名称）；
3. 选中片单后，除了「全部」，其他统计数量都以片单为准；点击「全部」后，改为主视图的。

## 三条口径拍板（问过才动手）

| 分叉 | 选定 |
|---|---|
| 合并卡「移出<片单名>」出现条件 | **任一成员命中即出现**（= `cardInList` / 片单筛选 / 侧栏计数同一口径——卡片能在片单视图里被看见靠的就是这条，「看得见就该退得掉」）；动作作用于**全部成员** |
| 合并卡重映厅行 | **沿用单条目「已看」门控**（聚合状态 `seriesStatus` 非已看则不给入口）；但**已在架中一律给出口**——否则状态退回在看之后成员会卡在重映厅里、卡上无路可退 |
| 计数收敛范围 | 只收敛**类型组 + 状态组**；「全部」保持库内总数（它是回主视图的出口），片单组各行保持各自成员数（本就是清单级计数，若也取交集其余行会整排归零） |

另：合并卡的重映厅文案与单条目**同词**（放入 / 移出），不另造「加入」——同一动作一个动词。
