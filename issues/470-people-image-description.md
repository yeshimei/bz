# 470 — 图片描述（AI）

## Parent

`issues/460-people-face-restructure-spec.md`（spec）。门禁与工作流按 `AGENTS.md`。

## What to build

工具段跑完后，用 AI 服务商**当前的模型**给这批图出描述。先弹一次确认，报清用哪个模型、多少张图、约多少次调用、从第几张开始；可以**「跳过图片描述」**——图片以空文本进仓、整条链继续走到画像生成（跳过 ≠ 取消）。

分批 20 张（可配），每次带上该批时间窗内的**对话上下文**（这是描述质量的关键：现有高质量描述全靠"读了前后聊到哪"）。批级断点，已完成的批不重跑。

## Acceptance criteria

- [ ] 开始前弹确认窗：显示服务商 / 模型、待描述张数、约调用次数、本次起始位置；按钮为「开始」/「跳过图片描述」
- [ ] 点「跳过」后：图片以空文本进仓，整条链**继续走到画像生成**（不中断）
- [ ] 进度块显示 `图片描述 已完成批数/总批数`
- [ ] 每批 20 张（可配）；上下文取该批首图前 1 小时 ~ 末图后 1 小时内的对话、**上限 6000 字**（超限按距图片的时间远近裁两端）
- [ ] 输入图取**派生档**，不取原图、不取微信自带缩略图（约 120px 读不出截图里的字）
- [ ] 批级断点：中断后续跑只做未完成的批；单批失败只废该批并可重试
- [ ] 结果合并进聊天仓对应条目的派生文本；**不调用外部进程、不改写数据根**
- [ ] 零媒体联系人自动跳过本阶段且**不弹确认**
