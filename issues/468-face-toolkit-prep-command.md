# 468 — `prep <联系人>` 子命令：媒体导出 + 关联 + 转写

## Parent

`issues/460-people-face-restructure-spec.md`（spec）。门禁与工作流按 `AGENTS.md`。

## What to build

对一个联系人按需跑重活：从原始数据导出该人的图片 / 视频 / 文件 / 语音，生成供 AI 描述用的**派生图片档**（长边 1280、质量 80），产图片↔消息**关联表**与**转写结果表**（**不写回 `chat.json`**），并跑本地语音转写。

单人是重活（实测某位联系人 1631 图 / 1289 语音 / 2.8GB，转写 20–60 分钟），所以必须幂等可续，并支持在步骤边界与每条媒体之间**让行暂停**（不硬杀进程——本地语音模型冷加载按分钟计，杀一次白付一次）。

## Acceptance criteria

- [ ] 一次 `prep` 后，该联系人目录出现媒体文件（含自研容器解码为图）、派生图片档、图片↔消息关联表、转写结果表
- [ ] **不改写 `chat.json`**（语音仍 `[语音 N秒]`、图片仍 `[图片]`）
- [ ] 派生图片档长边与质量可配、默认 1280 / 80；微信自带缩略图（约 120px）**不被当作 AI 输入**
- [ ] 语音转写按 AI 面板的引擎设置走，按已完成的音频幂等跳过
- [ ] 重复执行只补缺口，不重做已完成部分
- [ ] 控制文件出现暂停指令时在安全点让行（进程不退出、不丢进度）；收到中断则留状态退出
- [ ] 单条媒体 / 单条语音失败计失败数继续；末尾结果行报失败数
