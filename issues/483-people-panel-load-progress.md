# 481 — 解锁后打开脸谱面板的加载进度指示

## Parent

`issues/460-people-face-restructure-spec.md`（spec）。门禁与工作流按 `AGENTS.md`。

## What to build

刚解锁（或上锁再解锁）后第一次打开脸谱面板，`readAll` 要逐人解密整库记录（人多 / 记录大时明显），面板会空白一小会儿。这段空白换成**加载指示**：面板骨架先出（壳 / 标题 / 分区占位），内容区显示「正在解密联系人数据… N/M」式进度（能拿到逐人完成数就报数，拿不到就转圈 + 文案），加载完原地替换成真实数据。重开面板（缓存命中）不重复显示。

## Acceptance criteria

- [ ] 解锁后首次打开面板不再白屏：骨架 + 加载文案（或逐人进度）立即可见
- [ ] 加载完成后原地替换为真实数据，无二次闪动
- [ ] 缓存命中的重开路径不显示加载态（或一闪而过不误导）
- [ ] 上锁 → 再解锁的同一路径行为一致
- [ ] jsdom 测试覆盖加载态出现与消除
