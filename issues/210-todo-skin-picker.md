# 210 — 待办面板皮肤：纸感手账 / 编辑部 / 默认 + 设置页顶部卡片选择

用户拍板（2026-09-06，5 套风格原型 `.zcode/ui-prototypes/todo-styles/` 中选 2 + 默认）：
待办设置页最顶部加「面板皮肤」视觉卡片选择（预览卡 + 名称，无编号无描述），
皮肤作用于待办主面板。

## 拍板项

1. **三选一**：`default`（默认，现状）/ `paper`（纸感手账）/ `editorial`（编辑部）；
   设置键 `todoSkin`（string，默认 `default`），未识别值按默认渲染。
2. **卡片选择器**（index 原型方式）：迷你预览窗 + 名称，无 `01/02` 编号、无描述文案；
   选中品牌描边；放待办设置「显示」组最顶部（= 设置页最顶部）。
3. **设置行类型**：schema 新增 `choiceCards` 行类型（判别联合十一类），core ⚙️ 渲染器与
   设置面板渲染器同源支持；组件库新工厂 `uiCardChoice`（.bz-cardpick），预览变体视觉
   由 todo 域样式提供。
4. **皮肤机制**：面板根挂 `bz-todo-skin-{paper|editorial}`，作用域内覆盖 `--bz-*` 色彩/
   圆角 token + 局部结构覆盖（墨边硬阴影/衬线/方角等）；色值为皮肤专属固定明度
   （不随 Obsidian 明暗），域内直给；编辑器/添加场景等二级弹窗不跟随皮肤（范围控制）。
5. **热应用**：设置行 onChange 即时切换已开面板的皮肤 class；面板未开时下次打开生效。

## 验收

- 设置面板 → 待办 → 最顶部「面板皮肤」三张预览卡（默认/纸感手账/编辑部），点击即换
  即落盘；已开面板同步切换。
- 纸感手账：米纸点阵底、2px 墨边 + 9px 硬偏移阴影、衬线标题、贴纸化 chip、浮岛黑卡。
- 编辑部：白底黑框方角、衬线大标题、国际红单点强调、rail 左红条、底线式输入。
- 默认皮肤零变化（回归）。
- 全量 pnpm test + tsc --noEmit 绿。
