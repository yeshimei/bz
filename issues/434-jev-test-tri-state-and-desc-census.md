## 背景与目标

两件事：其一，`jevApiKey`/`jevModel` 全局键在博查入册后成为两家共用槽位，切服务商要手工搬值；
其二，「测试」钮的反馈靠弹通知，原型壳里 Notice 是静默空壳导致「点了没反应」。统一目标：
**按服务商分存 + 状态长在按钮本体上（转圈/绿框「已连通」/红框+简短原因），全程不弹窗**；
另将全域设置描述做普查精简（去留空/默认/回退缀语，保留关键功能说明）。

## 决策

1. **分存 = `jevApiKeys` / `jevModels` 两张 map**（键 = 服务商 id，空 = 删键回落），旧全局键经
   `migrateRetiredJevKeys` 一次性迁入 typesafe 槽位后退役；`resolveJevConfig` 只读当前服务商
   槽位，`isJevConfigured` 因此修正为「只看当前那格」。
2. **密钥/模型行改三函数绑定 + refreshKey**：切服务商显示值原地换槽；「获取模型」照 LLM 模型行
   补竞态护栏（拉取期间服务商被切 → 弃用并提示）。
3. **三态渲染协议进 RowAction**：`stateful?: boolean` + `core/settings-btn-state` 单源
   （`setRowBtnState` / `shortFailReason` / `ROW_BTN_RESET_MS`）。两渲染器同调：点击即 busy 转圈
   并禁点，resolve → 绿框「已连通」，reject → 红框 + 简短原因（归类器映射：密钥无效/无密钥/超时/
   网络不通/服务异常/响应异常/请求失败，超 6 字截断），2 秒复原。**不弹通知**。
4. **测试类 onClick 只做「落盘防抖值 → 真实调用」**：失败经 reject 交给渲染器翻红框。JEV 用
   `testJevConnectivity`（一道 noul 小题走完整判定链）；LLM 用 `testAIConnectivity(providerId)`
   （走现成 AI.ask 链路，字符串 override 不污染缓存；回复为空也算失败）。
5. **全域描述精简**：主设置页 20 条 + 全域 9 批 41+21+17+3 条，统一为「一句话功能陈述」；
   关闭行为不显而易见的开关与特殊值语义（0 = 不限量等）保留说明。copy-lint 钉住的 3 条旧文案
   与各域测试桩同步更新。
