## Parent

`issues/460-people-face-restructure-spec.md`（spec）。门禁与工作流按 `AGENTS.md`：worktree 开发 → 全量测试 + `tsc` + 自审 + diff 审查 → 主仓构建部署。

## What to build

把知识盒里那套「spawn 外部工具 + 逐行解析 `[bz-step]` / `[bz-p]` / `[bz-info]` / `[bz-result]`」的做法抽成核心层一个可复用模块：调用方给命令、参数与一组回调（步骤 / 进度 / 信息 / 结果），模块负责进程生命周期、stdout 逐行解析、畸形行容错、stderr 收集与退出码语义。

**知识盒本次不动** —— 它继续用自己的实现，本票只新增模块与其测试。这是后续所有外部工具集成的地基。

## Acceptance criteria

- [ ] 解析器对四类协议行各返回结构化事件（步骤名 / 阶段+百分比 / 信息体 / 结果体）；百分比允许 `null` 表示该阶段不可估
- [ ] 畸形行、空行、非协议输出、超长行都不抛异常（原样透传或忽略）
- [ ] 调用壳返回撤销句柄（可停止在跑进程），进程异常退出时给出带 stderr 的错误
- [ ] 有独立测试：喂预录 stdout 行断言事件序列；mock 进程断言停止语义与退出码分流
- [ ] 知识盒行为零变化（既有知识盒测试全绿，其源码未被改动）
