# 409 · 观影分析镶进影院面板（覆盖 + 点遮罩关）+ 影院交互三修 + 文案与间距

用户原话（2026-09-21，六条一次给）：

1. 把观影分析全屏弹窗镶嵌到影院中，去掉右上角的关闭按钮；
2. 侧边栏的背景滑块，观影分析也有，单击 AI 荐片和观影分析背景滑块会固定住；
3. 从合集季的圆点移开鼠标，下面的文字会闪烁两次；
4. 鼠标放到列表的卡片海报上，卡片会随着鼠标的位置倾斜（类似观影分析中的效果）；
5. 点击卡片海报，从小图展开界面的动画提前 0.2s（后改口径：**提前 0.1s**）；
6. 添加影片的背面，也类似详情页面，显示评分，观影日期和影评。

三轮澄清把第 6 项来回改了三遍——「不做鼠标悬停显示文字」「点击不会翻到背面，没有背面，只有添加影视」
「背面不需要任何记录区，不需要这个东西」，最后落到：**添加影视背面只读显示评分 / 影评 / 观影日期**
（不带记录区控件、卡片一律不做背面，见 ⑥）。另追加两条：观影志文案改「观影分析」、主界面列表 10px 内上边距。

## 拍板（2026-09-21）

- **镶嵌形态（Q1）**：观影志不再是挂 body 的整屏纸面，改为**正好覆盖影院面板矩形**的一层
  （桌面 900×620，移动端即面板矩形＝满屏），层内保留纸面；层外留遮罩层，**点遮罩关闭**，
  关掉露出影院面板（面板的筛选/滚动状态原样保留）。**桌面去掉右上角关闭按钮**；
  移动端保留（面板满屏时没有遮罩可点，退出路径不断）。ESC 与点遮罩同义。
  命令 `bz-cinema-analysis` 与侧栏「观影分析」入口：面板没开先开面板再盖层。
- **底片固定（Q2）**：只在 AI 荐片页——侧栏滑动高亮底片常驻停在点亮的「AI 荐片」入口上，不再隐去；
  悬停跟随与离开回落照旧。观影分析不需要（它盖住面板，看不见侧栏）。
- **背面（Q3/Q4/Q6）**：**卡片一律不做背面**（悬停、点击都不翻面；剧集合并卡同理）；
  「添加影视」的背面**只读显示**三项记录（见 ⑥）——不是记录区、不带控件。

## 交付

**① 观影分析覆盖层（`ui.ts` + `index.ts` + `styles.css`）**
- 层结构 ``.bz-yb`（fixed inset:0，透明，接外部点击＝关闭）> `.bz-yb-box`（面板矩形 + 纸面）>
  `.bz-yb-scroll` > `.bz-yb-film`；纸面背景从 `.bz-yb` 挪到 `.bz-yb-box`，`--yb-*` 变量仍挂
  `.bz-yb`（`palette(root)` 取色不变）。
- 面板矩形：开层时读 `[data-cinema-root]` 的 rect 写进 box 内联样式（left/top/width/height +
  同样的圆角），窗 resize 与面板 resize 各跟进一次。
- **基字号随层框派生**（不再 `1.15vmin + 4px`）：`clamp(12, 12 × min(w/900, h/620), 19)` px。
  理由：面板是固定 900×620，而 vmin 跟着窗口跑——大窗口下真机会把 26 幕排得比原型密一档，
  插件与原型从此同观感。
- 关闭按钮 `.bz-yb-close` 与样式段删除（桌面）；移动端（面板满屏）保留一个出口。

**② AI 荐片页底片固定（`layouts/midnight/render.ts`）**
- rail 底部工具里 `data-tool="ai"` 的入口在 `M.view === 'ai'` 时带 `is-on`，
  底片的「回落目标」自然落在它身上（`syncSlidePill` 找 `.is-on`），不再整块隐去。
- 观影分析入口不加 `is-on`（层盖住面板，没有可见的停留点）。

**③ 合集季圆点移开的文字闪烁（`ui.ts` restFace）**
- 根因：折回收尾 `done` 会被执行**两遍**——`fold.finished.then(done)` 一次、
  兜底 `setTimeout(done, PEEK_BACK_MS + 400)` 一次；`st.gen` 只挡「新一轮换脸」，
  挡不住同轮重入。`peekTextFade` 于是把文案淡入播两遍，肉眼就是「文字闪两次」。
- 修法：`done` 加单轮守卫（同一轮只收一次），动画事件与兜底定时器先到先用。

**④ 卡片海报悬停倾斜（`ui.ts` + `styles.css`）**
- 指针在海报上时整卡随位置做小幅 3D 倾斜（`perspective + rotateX/rotateY`，观感对齐观影志的跟手），
  只有悬浮能力的设备接（`hoverCapable()`）；`pointerleave` 归零；
- 点击进详情前先归零（共享元素过渡量的是静置矩形，带着倾斜量会把飞行起点算歪）。

**⑤ 开面板的节奏：不提前、撑开时长 .3s（`ui.ts` createSharedFlight.begin）**
- 原先是「海报飞满 200ms → 面板才撑开 200ms」串行；先试过「提前 0.1s 起撑」并于同日拍板**回退**（不提前）
  ——海报落地那一帧才起撑，先飞后开，落地不重复起撑。
- 撑开时长几经改口径定为 **.3s**（`SE_GROW_OPEN = 300`）：比台账四档都长的**揭示档**，
  按拍板取值、不新开时长档；关闭方向仍走 move 档 200ms——开是揭示、慢；关是收回、干脆。

**⑥ 添加影视的背面：把「我的记录」显示出来（2026-09-21 追加拍板）**
- 口径改了三遍，最终：正面选「已看」时填的**评分 / 影评**，加上这一笔存下去的**观影日期**，
  在解析翻面后与详情弹窗同形制显示（星级 + 分数、日期、影评文字）——**只读、不带控件**
  （`.j-rating` / `.j-review` 仍只在正面）。
- 日期与保存**共用同一判据**（`ui.watchDateOf()` 单源：状态变了取当下、没变沿用原有），
  各算一份必然出现「背面写的日期和真存下去的不是同一天」。

**⑦ 观影志文案改「观影分析」（`yearbook/motions.ts` + `scenes.ts`）**
- 01 开卷的粒子第二靶点 `观影志` → `观影分析`（四字，字号系数按位宽同比收，整串宽度与三字版持平）；
- 26 落款的 `data-foot` 副题同步改；`data-foot` 只作元数据，不上屏。
- 代码/文档里的域名词（yearbook、观影志注释）不改——改的是**用户看得见的字**。

**⑧ 主界面卡片海报列表 10px 内上边距（`styles.css`）**
- `.bz-cinema--midnight .d-scroll` 的 `padding:2px 20px 20px` → `10px 20px 20px`（列表专用容器，
  AI 页走 `.sp-body` 不受影响）。移动端 `.m-scroll` 不动（另一套间距节奏，需要再说）。
