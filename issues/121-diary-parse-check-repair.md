- 状态：已实现（master 直改；全量 2922 测试绿 + tsc 0 + 构建部署）
- 域：diary
- 来源：用户反馈「日记本检测出 24 个格式不对，只是一个弹窗，不知道是哪个笔记不对、哪里出错」→ 四轮盘问拍板（Q1/Q5/Q6/Q7/Q9/Q10/Q12）
- 关联：ADR-0054、issues/122（同日移动端防呆，独立域）、`src/diary/{store,parser}.ts`、`src/diary/ui/*`、`.scratch/memo-suite-plugin/spec.md`

## 背景

UX-9（25c79a7）给 `parseFile` 加「未解析行」统计，`loadAll` 结束弹一次性 warning toast「N 条未能解析，请检查日记文件格式」。真机审计：521 个日期文件中 24 条未解析行只来自 **3 个文件头行格式不合规**（`2023-04-22.md` L1 `# 🤝02:43` 缺空格 / `2023-10-27.md` L1 `# 📖 9:33` 单数字时间 / `2025-08-06.md` L1 `# 📖12:28` 缺空格），头行不被标题正则 `^#\s*((?:\S+)+)\s+(\d{2}:\d{2})` 识别 → 其下 21 行正文全变「游离非空行」被静默丢弃。解析行为自始如此，非回归；UX-9 只是把静默换成数字。

## 用户拍板（盘问结论）

1. **去掉启动自动 toast**（「不要在打开软件的时候弹出未解析通知」）——统计保留、不通知；
2. **入口**：日记面板 ⚙️ 设置弹窗加「检测日记解析」按钮；
3. **检测面板**：点击打开面板 → 进度条 → 逐文件解析全部日期文件 → 汇报；
4. **手动驱动修复**（「不是自动解决」）：可修项展示 文件×行号×修改前后预览 → 「一键修复全部」→ 确认后批量落盘 → toast 汇报；
5. **不可修项**（如时间越界 `24:99`）：清单列出，点击打开文件并**光标定位到该行**（编辑器 setCursor）由用户手工改；
6. **不额外备份**（Obsidian 文件历史/同步兜底），接受 mtime 副作用（smartcat ticket 077 产生「你更新了日记」观察）；
7. 规则白名单与冻结条款边界见 **ADR-0054**：只修不合规头行（R1 补空格 / R2 时间补零），正文一行不改（R3 归位），修复≠改格式。

## 设计草案（实现参考）

### 修复计划引擎（纯函数，`src/diary/repair.ts` 或并入 parser 侧）

- `buildRepairPlan(filename, content): { repair: RepairItem[]; unresolvable: UnresolvedItem[] }`
- `RepairItem = { file, line, kind: 'space'|'pad-time', before, after, reason }`
- 识别逻辑直接复用 headingRegex 语义：逐行扫描，首个条目之前：
  - 形似标题但缺空格（`# \S+` + 紧跟 `\d{2}:\d{2}`）→ R1；
  - 有空白但时间非两位 → R2；
  - 时间越界（匹配 `\d{2}:\d{2}` 但值非法）→ `unresolvable`；
  - 其余游离正文行 → **不单列**（随头行修复归位，防止把 18 行诗当 18 个修复项）；仅当文件无任何可修头行时其游离正文才有意义地进 unresolvable（显示为「游离于条目前的正文，需手工归档到某条」）。
- 注意：修复后的行必须能被原 `parseFile` 完整解析为合法条目标题；实现时以「修复后全文重新 parseFile 的未解析数=0」做自校验。

### 检测面板（`src/diary/ui/`，新 Modal）

- 打开即跑（或点「开始检测」）：分批并发读文件（复用 loadAll 的 BATCH_CONCURRENCY 模式）+ `parseFile` 的 onUnparsed 收集 → 进度条；
- 汇报两区：可修复区（预览列表 + 一键修复按钮 + confirm）／不可修复区（文件:行号 段 + 「打开定位」）；
- 「打开定位」：`workspace.openFile` 打开 md → 等待编辑器就绪 → `view.editor.setCursor({line, ch:0})` + 选区/滚动到行；
- 修复写回：`vault.modify(file, newContent)`（内容仅头行变更 → 重渲染刷新面板 + toast）；
- UI 类名 `bz-` 前缀，样式仅收根 styles.css；无新命令（入口=设置弹窗按钮 → smoke 无命令变更）。

### 设置弹窗按钮

- 日记 ⚙️ 设置弹窗 build 末尾挂「检测日记解析」按钮行（同现有风格，参考其它域按钮行）。
