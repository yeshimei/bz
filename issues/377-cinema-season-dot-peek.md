# 377 影院：季圆点悬浮预览（换脸 = 该季海报 + 信息）

- 状态：已实现（待主构建部署）
- 提出：2026-09-18 用户
- 相关：issue 376 / ADR-0168（季圆点形态）；本票只加交互，不改形态

## 用户原话

> 再增加一个功能：鼠标放在对应的圆点上，就显示对应的海报，还有下面的信息

## 形态

鼠标移入合并卡的第 N 枚季圆点 → **卡片正脸临时换成那一季**：

| 件 | 静息态 | 悬浮第 N 枚时 |
|---|---|---|
| 海报 | 最近观看那一季的海报 | 第 N 季的海报（无海报则首字占位） |
| 名字 | 归一名称（老友记） | 该季全名（老友记 第六季） |
| meta | 正脸季的 年份 · 导演 | 第 N 季的 年份 · 导演 |
| 星级 | **最新已评季**的评分 | 第 N 季自己的评分（未评 = 未评分） |

鼠标离开圆点即复原。角标（聚合状态）、抓取遮罩、圆点自身全程不动。

## 实现口径

- **markup 单源**：新增 `shared.ts::facePiecesHtml(it, posterUrl, { name?, rating? })` 作为
  「海报内芯 + 名字 + meta + 星级」四件的唯一出口——`cardHtml` 静息态与 ui.ts 换脸都走它，
  禁止行为层自己拼第二套格式（否则悬浮前后的排版口径会漂）。
- **只换一层**：海报内芯包进 `.pw-face`（绝对定位铺满），换脸只重写这一层；
  圆点/角标/遮罩是它的兄弟节点，原地不动。
- **复原靠快照不靠重算**：合并卡静息态口径与单季不同（名字是归一名称、评分取最新已评季），
  重算必然还原错 → 首次换脸前把四件 `innerHTML` 存进 `WeakMap<card, string[]>`（卡片每次
  重渲染都是新元素，旧键自然被 GC）。
- **事件委托**：`sec` 级 `mouseover`/`mouseout` 委托（网格每次重渲染换新卡片元素，逐个绑定会漏）。
- **只挂桌面壳**：触屏 tap 会发 `mouseover` 却不发 `mouseout` → 换脸会滞留；移动端已有长按抽屉。
- **圆点只作预览入口**：点圆点仍走整卡点击（开合集详情，里面可再钻单季），不改点击语义。

## 不做

- 不做移动端 tap 预览（见上，改用长按抽屉 / 合集详情里的各季明细）。
- 不换状态角标（角标表达「整部剧的聚合状态」，跟随单季悬浮会闪且语义漂）。
- 不加过渡动效。
