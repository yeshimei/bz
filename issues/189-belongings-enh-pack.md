# 189 — 归物本用户增强包（撤销 / 年节折叠 / 统计联动 / 出离闭环翻案 / 防丢 / 头行钮）

## 背景

全域审查（2026-09）归物本体验线 + bug 线产出，用户逐项拍板「做」。基线：ADR-0083 P6「状态边栏×时间轴」。

## 用户拍板（全部「做」）

1. **状态流转 / 删除接撤销**：流转成功 notifyUndo（回写旧状态）；删除留 snapshot 撤销写回；确认弹窗保留但去掉「此操作不可撤销」威慑文案。
2. **年节默认折叠**：当年 / 上一年默认展开，更早（含未标注）默认折叠；手动展开/折叠过以会话内状态为准。
3. **统计卡可点筛选**：「总资产」卡可点 = 在用+闲置合成筛选；「在册件数」卡可点 = 清筛选回全部。不动统计口径，只加视图联动。
4. **出离闭环（明示翻案 ADR-0083）**：出离（转卖/丢弃）记出离日期，陪伴天数封口；转卖可选记售价，日均成本扣转卖回本——推翻 ADR-0083「转卖不填价」该点，理由与新 ADR-0089 同步落 docs/adr/。
5. **表单防丢检查补全**：记一笔/编辑表单补 baseline + confirmDiscard 脏拦截（原版无防丢）。
6. **头行图标钮间距/尺寸**：同 favorites 档（≥8px + 移动大按钮档）。

## 明确不做（已拍板）

- 年份筛选维持下拉不改平铺；批量打标不做。

vitest 全量 + tsc --noEmit 全绿；数据层 + UI 层回归测试；worktree 开发合并回 master。
