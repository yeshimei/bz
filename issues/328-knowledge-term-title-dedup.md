# 328 · 知识盒名词录入防重名：输入实时提醒 + 确认硬拦截

- 状态：设计中（2026-09-15，grill 拍板，ADR-0143）
- 关联：issue 326（四入口与同壳三态、onTermConfirm 统一确认）/ ADR-0143（范围与口径）/ cinema 同名拒绝先例

## 用户原话拆解

1. 「知识盒四个入口，都加上防止标题重复」——grill 后收窄：只有名词标题是用户手输，
   「只查名词的重名，其他三个标题是 ai 生成的，重名了重新生成即可」（Q1 拍板）；
   影像「不查」（Q4 拍板）；段落 / 图版经第二轮确认维持不动。
2. 「选择1 然后再加一个，在标题输入框下面实时提醒」（Q2 拍板）——命中行为 = 拦截拒绝 + 输入框实时提醒。
3. 「仅确认写入时硬拦截」（Q3 拍板）——不提前锁流程，预览保留可改名重试。
4. 「只查文件名」（Q1 拍板）——口径与 writeUniqueNote 撞名判定同源。

## 设计

- **查重工具**（note-gen.ts，紧邻 sanitizeMdTitle）：扫文献目录（`knowledgeDirectory`）下 md 的
  basename，比对 `sanitizeMdTitle(term)` 结果；命中返回既有路径。与 `loadLiterature` 扫描口径同源。
- **实时提醒**：名词态输入框（`#lit-term-input`）下方内联提示行——input 事件防抖查重，命中显示
  「已存在同名文献笔记」提示，改名即消；不阻断输入、不锁生成按钮。
- **确认硬拦截**：`onTermConfirm`（ui.ts）非空校验之后、`termGenerating = true` 之前查重；命中 →
  `notice('已存在同名文献笔记：…', 'error')` + return，面板与预览保留。仅名词态查重
  （mode === 'term'），段落 / 图版直行。
- **不动**：`writeUniqueNote` 永不覆盖契约、段落 / 图版 / 影像全链路、frontmatter title 口径。

## 测试面

- note-gen 查重函数：命中 / 不命中 / 清洗后命中（非法字符与截断）/ 空目录。
- ui.test：名词输入命中 → 提示行出现、改名消失；确认命中 → notice error 被调、不写盘、面板不关；
  段落 / 图版同题不拦（回归：确认写入直行）。
- smoke：命令清单不变。
