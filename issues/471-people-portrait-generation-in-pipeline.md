# 471 — 画像生成接整链

## Parent

`issues/460-people-face-restructure-spec.md`（spec）。门禁与工作流按 `AGENTS.md`。

## What to build

把现有的双卷画像生成接进这条链的末尾：素材从**聊天仓**（派生文本非空的消息）组装，先弹**第二次确认**，再跑 `其人 → 我们 → 时间线`。已画过的人再次画只跑增量。

## Acceptance criteria

- [ ] 开始前弹确认窗：显示服务商 / 模型、素材条数、约调用次数；按钮「开始」/「取消」
- [ ] 进度块走完 `其人 / 我们 / 时间线` 三段（沿用既有阶段呈现）
- [ ] 素材来源是聊天仓；**派生文本为空的消息不进素材**
- [ ] 零媒体联系人跳过预处理与图片描述后，能直接生成画像
- [ ] 已画过的联系人再次「画脸谱」只跑增量部分
- [ ] **两次确认是两个独立弹窗**：跳过图片描述后，仍会为画像生成弹确认
