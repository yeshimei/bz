# 405 · 影院观影分析 → 滚动放映室（分析页整页重做）

## 背景

观影分析页（`M.view='stat'`）是 4 张统计卡 + 19 个条形板块的静态长列表，信息密度高但没有
观感记忆点。用户拍板（2026-09-22）：分析页做成一部**滚动放映室**——先在
`.scratch/cinema-stat-scroll-lab/` 出了三版可交互原型（8 幕 → 22 幕 → 幕单元放映模型），
逐幕截图验收后拍板落进实现。

## 决策（用户逐条拍板）

1. **整页是一部影片**：四本 22 幕，覆盖分析页真实数据维度
   （倒计时 / 长廊 / 星云 / 年份 / 编年 / 档期 / 排片 / 霓虹 / 片龄 / 导演 / 群像 /
   天平 / 连映 / 追剧 / 弹幕 / 名人堂 / 致谢 / 预告 + 4 张分本字幕卡）。
2. **没有全程自动放映**：滚轮拨到哪一幕，就从那一幕的开头放到它的 sticky 末端，
   放完即停；再拨一次进下一幕（幕单元放映模型）。
3. **每幕独立速率**（SCENE_RATE）：信息密的幕（编年/星云/致谢/名人堂）放慢，
   简单幕（排片/天平/追剧）放快，速率恒 2× 基准再乘幕系数。
4. **字幕卡常驻不淡出**（用户报「几秒就空场很突兀」）：进场后一直亮，翻幕滚动自然带出场；
   行程 220vh、降速 0.9，保证「第X本」可读。
5. **UI 极简**：无工具栏；右侧只有一根细轨 + 进度点 + 竖排当前幕名（点轨跳幕）。
6. **和影院皮肤一致**：随壳取色（当前唯一上岸的午夜场壳 = 暗调；亮色变量留基础层，
   gazette/booth 上岸即得亮色版）。

## 落地

- `src/cinema/stat-film.ts`（新）：
  - `deriveFilmData(items)` 纯函数：星期/年度/月度/片龄四桶/导演主演聚合（人→作品）/
    系列基名聚合（≥2 部）/ 追剧深度（基名聚合取最大季号）/ 宝藏与失望（个人 vs 豆瓣）/
    影评金句切句——口径对齐 analysis.ts 的 19 板块；
  - `statFilmHtml(data, posterOf)` 纯字符串：22 幕静态 DOM（用户文本全部 escapeHtml）；
  - `bindStatFilm(root, app, data)` 引擎：滚动容器是 stat 页的 `.sp-body`
    （不是窗口！）——rect 测progress、滚轮翻幕（惯性节流 + 680ms 缓动 snap）、
    幕内放映（scrollTop 推进）、22 幕逐幕驱动、颗粒/尘埃/划痕画布只在可见时绘制；
    旧引擎随 root 脱离 DOM 自灭（renderAll 整刷重建安全）；返回句柄供测试。
  - 无 WAAPI / 无 window 级监听：全程 scroller 上的 rAF + scrollTop 推进，
    面板关掉/切页引擎即停。
- `src/cinema/ui.ts`：`midnightInput(app, mob)` 分流——桌面 stat 走影片，
  **mob 保留 19 板块列表**（触屏没有滚轮翻幕，硬搬是伪交互，遗留见下）；
  renderAll 在 desk + stat 时 `bindStatFilm`。
- `src/cinema/styles.css`：影片样式段（`.bz-stat-film`，全部走 --sf-* 变量，
  幕高 = `--film-unit`（sp-body 客户高）× 幕系数，随 ResizeObserver 跟随面板尺寸）。
- 台账白名单扩充（motion-ledger.test.ts）：`.9s`（灯牌闪烁）/`9s`·`11s`（探照灯）/
  `14s`（放映机表盘）——氛围循环非交互时长；`1.1s`（跑马灯）本来就在名单里。
