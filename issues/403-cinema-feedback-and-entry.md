# 403 影院反馈与入口（星级点亮、落位闪、保存折回、看大图、键盘导航）

## 背景

前四批把「事件发生的那一刻」补上了，但几处**结果落地**仍无反馈：保存后面板直接消失、
状态流转后卡片悄悄换了位置、评分拖动只有数字在跳、详情海报不能看大、网格纯键盘不可走。
本批补的是「结果看得见」，全部复用已在线机制，不新增通道。

## 决策（2026-09-21 用户拍板「按照你的来」）

1. **星级点亮（表单与卡片同语汇）**
   - 表单评分是 1–10 的滑杆（`shared.ts` formModalHtml 的 `.j-range`），不改成点选控件
     （粒度与数据语义都不动）。拖动时在滑杆右侧**逐颗点亮**五颗星（半星粒度对齐
     `getStarString` 的 `rating / 2` 口径），越过每一颗时给一次微弹。
   - 保存后回到列表，刚评过分的卡星级**逐颗点亮**（步进 .04s）——把「分数记下了」变成看得见的动作。
2. **落位闪**：保存 / 快速标记后，受影响的卡在新网格里闪一下金边（`.is-flash`，一次脉冲），
   让「就是这张变了」有落点。按 `data-cinema-key` 定位，键不在当前筛选里就不闪。
3. **保存折回卡片**：表单保存后不再「面板凭空消失」——先把网格重渲染（issue 398「保存即齐」的数据侧
   已经做到），再把表单层按目标卡矩形收拢（clip-path + 遮罩淡出，与共享元素返程同一语汇），
   落到卡上才关层。新建同款（落到新卡上）；键不在当前视图里则退回即时关闭。
4. **看大图**：详情弹窗里点海报 → 全屏看图。**复用 core 灯箱 `openLightbox`**（单例、ESC、
   点背景关、滚动锁、z 发号都在 core），不自造一层——「ESC 与层级」正是最难做对的部分，
   为一段入场动画复刻一套是负收益（本条与原提议的「飞入」不同，取舍记在遗留）。
5. **键盘导航**：`.pcard` 已是 `tabindex=0 role=button`（Enter/Space 开详情在线），补：
   ①`focus-visible` 金色焦点环（现在纯键盘浏览没有可见焦点，属无障碍缺口）；
   ②方向键在网格内按**几何最近**移动焦点（左右 = 同行相邻，上下 = 下一行同列，跨列数自适，
   不依赖固定列数），并把目标卡滚进可视区。

## 验证

- 单测（`tests/cinema/ui.test.ts`）：①拖滑杆星预览逐颗点亮（9.6→5 颗、4 分→2 颗、往回拖不补微弹、
  9 分→4 颗）；②保存后落位闪（金边脉冲）+ 星级点亮 + 面板按目标卡矩形折回、折回结束层已收；
  ③方向键：右→同行相邻、下→下一行同列、左→回退、边界不吞键且焦点不动。
- 原型自检（真浏览器）：星预览 4 分=2 颗 / 9 分=4 颗；保存后 `clip-path` 折回动画存在、目标卡有
  `boxShadow` 闪现动画、层随后收掉；方向键焦点落到第二张。
- 打坏验证：跳过落位闪 → 「保存后目标卡落位闪」当场红。
- 全量 `pnpm test` + `tsc --noEmit` 绿；原型自检 95/95。

## 遗留

- 看大图走 core 灯箱，没有「从缩略位飞入」的观感（原提议的那段）——若要，需要给 core 灯箱加
  可选的出现矩形参数（跨域改动），留待灯箱批。
- 键盘导航只覆盖网格（侧栏 rail 的上下移动已有原生 tab 序），不给 rail 另外造一套。
- 表单评分仍是 1–10 滑杆（不改成点选控件：粒度与数据语义都不动），逐颗点亮只做预览。
