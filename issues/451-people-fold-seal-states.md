# 451 折子印章四态：未画谱 / 画谱中 / 画谱中断 / 已画谱

## 需求（2026-09-25 用户拍板）

折子封面卡的印章只有两态（`待画` / `已画`·`画到日期`），而「画谱中 / 画谱中断」只活在面板顶部
那块进度块里——那块**一次只显示一个任务**（running > 暂停/中断 > error > done 取首个），
多人排队时后面中断的人没有入口可以继续。

要求：**四态都要在界面（折子卡）上显示，并且每种状态都能从卡上继续进行**。

## 设计口径

### 四态判定（互斥，任务态优先于脸谱水位）

| 优先 | 态 | 触发 | 印章文字 | 印章皮（宣纸/朱红/鎏金） |
|---|---|---|---|---|
| 1 | 画谱中 | 任务 `running` | `画谱中` + `42%` | 金实印（金实线 + 金字） |
| 2 | 画谱中断 | 任务 `paused` / `interrupted` / `error` | `画谱中断` + `12/60` | 朱红破框（虚线 + 朱红） |
| 3 | 已画谱 | 有 `digest`（且无活跃任务 / 任务已 done） | `画到` + `26-03-12`（无锚点回落 `已画`） | 朱红实印 |
| 4 | 未画谱 | 无 digest、无任务 | `待画` | 灰虚印（沿用 447） |

### 动作（印章即入口；每态恰好一个，互不并列）

- 未画谱 → **画脸谱**（`draw`）：走预览桶素材单人生成（`generateOne`）。
- 画谱中 → **暂停**（`pause`）：本批做完停；可逆，且进度块一直有「继续生成」。
- 画谱中断 → **继续生成**（`resume`）：断点续跑，已完成批不重烧。
  漂移类失败（`DRIFT_ERROR`，消息集已变）不可续 → 改 **重新生成**（`redraw`）。
- 已画谱 → **补画**（`redraw`）：auto 模式走 `planIncremental`；**没有新消息由 ui 层预筛拦下**
  （通知「没有新消息、无需重画」），不烧 AI。

印章**本身就是按钮**，不往卡面加新元素——448 定的「合并 / 删除收进详情头、卡面不放动作」仍守。
合并流程中印章不可点（CSS `pointer-events: none`），点卡片 = 选合并目标这一语义不变。

### 刷新口径

引擎快照每帧**原位只换印章节点**（`[data-people-card]` 定位 → `replaceWith`），不重建整墙
——重建会打断合并点选态与滚动位置。

## 分工 / 接口

- **render.ts**（markup 单源）：新增 `foldSeal(p, job)` 纯函数 + `FoldSealState` / `FoldSealAction` /
  `FoldCardJob` 类型；`FoldCardOpts` 加 `job`；`foldCard` 印章由 `div` 改 `button`（带
  `data-people-seal-act` 钩子）。
- **ui.ts**：`applyWall` 传任务视图（快照 queue → talker 映射）；快照到来时 `syncWallSeals()`
  原位刷新；事件委托新增印章动作分支（**放在合并点选之后、开人物详情之前**）；
  `generateOne(id)` 收 id 参数（详情按钮传 `detailId`，卡上印章传卡 id）。
- **jobs.ts**：`resume()` 放宽接受 `error` 态——失败任务也能从已完成批续跑（450 的「不重烧已付批次」
  精神：`runJob` 本就从 `job.batchesDone` 起循环）。`DRIFT_ERROR` 的不可续判定留在 ui 层。
- **styles.css**：四态皮肤 + 印章按钮化（`pointer-events: auto` / `cursor: pointer` /
  `@media (hover: hover)` 提亮 + 微放大 / 字号与边框沿用现有变量）。

## 隐私

沿用 ADR-0191：本次改动只读任务元数据（批数 / 进度）与脸谱水位，不引入任何聊天原文。

## 验收

1. render 单测：四态 + error 两个分支（可续 / 漂移）的印章文字、类名、`data-people-seal-act`，
   以及「每态只出一个动作」。
2. ui 单测：列表点印章 → 暂停 / 继续 / 画谱 三条派发路径；快照推进时印章原位刷新（不重建墙）。
3. jobs 单测：`resume()` 接受 `error` 并从 `batchesDone` 续跑（不重烧已完成批）。
