# issue 276：文献标题（及剪藏标题）去新闻式问句，收敛为完整陈述句

日期：2026-09-11 ｜ 用户拍板（一句话需求）：生成的题目，是总结确定性的，而不带有新闻类的，没有脑子的立方水母为何拥有六只相机眼 正确的应该是 没有脑子的立方水母拥有六只相机眼 ｜ 关联：ADR-0122（第 3 条：域 UI 与术语命名的域归属纠偏）

## §1 对象澄清与纠偏

用户口中的「第二大脑域 / 生成的题目」经核实指向 **知识盒（knowledge）域**（`src/knowledge/`），不是第二大脑（`src/secondbrain/`，向量检索/自动双链域，无出题与文献预览）。截图里「文献预览 · 影像」弹层顶部那行「没有脑子的立方水母为何拥有六只相机眼」正是**文献笔记 frontmatter 的 AI 生成标题**，来源 prompt 明文允许疑问句式：

- `src/knowledge/note-gen.ts:120`（视频文献元数据）：`"title":"15-30字的中文完整陈述句或疑问句，禁止冒号、破折号、句中句号问号，需要连接时用逗号"`

AI 走 `deepseek-v4-flash`（`ai.json`，`src/core/ai.ts:542-547`），B 站视频原题多为悬念问句，prompt 又允许疑问句，于是标题被写成新闻式提问。复习计划（做题家）的四选一选择题题干（`src/review/quiz-core/generator.ts`）是另一条链路，**本次不动**。

## §2 修法契约（只改 prompt 措辞）

`src/knowledge/note-gen.ts:120` 的 title 指令改为：

```
"title":"15-30字的中文完整陈述句，不得使用疑问句或疑问语气（为何/为什么/怎么/如何/吗/呢），禁止冒号、破折号、句中句号问号，需要连接时用逗号"
```

`src/auto-summary/processor.ts:38`（`FIELD_DEFS.title`，剪藏摘要标题，同源同病）同步改为：

```
'"title": "生成中文标题，15-30字，完整陈述句，不得使用疑问句或疑问语气（为何/为什么/怎么/如何/吗/呢）。禁止冒号、破折号、句中句号问号，需要连接时用逗号"'
```

判定口径：以「没有脑子的立方水母为何拥有六只相机眼」为反例、「没有脑子的立方水母拥有六只相机眼」为正例，疑问词枚举是承重结构；两句其余禁项（冒号/破折号/句中句号问号）原样保留。

**不加**后置校验、不加 AI 改写兜底、不做本地剥问号（用户拍板「只改 prompt 措辞」）。理由：标题是给检索与列表看的摘要，改法越机械越容易产出不通顺的句子；prompt 层的显式否定枚举已足够。

## §3 存量与范围

- **存量笔记不迁移**：已生成的 frontmatter `title` 原样保留（用户可手改；无重跑标题入口，重跑等于重建笔记）。新生成生效。
- 术语文献标题不受影响（`title` = 术语词，非 AI 造句，`note-gen.ts:212-223`）。
- 文件名取 `sanitizeMdTitle(title)`，标题收紧后文件名同步受益，无额外改动。
