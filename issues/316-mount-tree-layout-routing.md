## 背景

原型已把视觉规格验收完（力导向网状、就近出盒、18px 栅格 A\* 避障、同级零连线、世界尺寸自算）。
本卡把它们搬进 `src/knowledge/`，并加一条原型没有的硬要求：**确定性**（同一份输入两次布局结果一致，可在 node 断言）。

## 交付

- [ ] `layoutTree(nodes, edges)`：斥力（`REP=150`，半径 `(w+h)/4`，远距截断 2.5×）+ 弹簧（`REST=160`）+
      软约束（子卡在父卡右侧 ／ `depth*640` 弱 x 锚）+ 60 轮最小穿透轴硬推开；种子 = 黄金角螺旋，**不吃随机数**。
- [ ] `routeEdges(...)`：就近出盒（**四边取最近，含左缘**）→ 18px 栅格**按格心**落墙 → 端点口袋（只解封格心不在卡内的格子、**用完还原**）
      → A\*（8 邻域、正交 10 ／对角 14、不许剪角）→ 拉直（精确判交，**不给源卡/目标卡豁免**）→ 逐段平滑（切向 1→0.55→0.3，压卡那段留直线）。
- [ ] SVG 连线层浮于卡上（`pointer-events:none` 根 + `.edge{pointer-events:stroke}`）；**只画严格跨代的边**。
- [ ] 平移 / 滚轮缩放（锚定鼠标）/ 适应窗口；世界尺寸由布局算出。
- [ ] **视口裁剪与栅格缓存留接口**（spec 风险 1）：超 120 卡自动降级（关 A\* 改直线 ／ 未展开层不参与布局）。
- [ ] 测试（`// @vitest-environment node`）：同输入两次布局一致；抽检「穿卡 0 条」（直线段精确判交 + 贝塞尔高密度采样）。

## 验收

布局与路由可单测；接进白板后实机看不到穿卡、看不到重叠、同级之间一根线都没有。
