# issue 374：游戏库「全量落盘 + 媒体全本地化」

- 日期：2026-09-18
- 状态：已实现
- 相关：ADR-0166（决策）／ADR-0163（被取代的旧取舍）／ADR-0164（媒体键拆分）

## 用户原话

> 成就图标保存在指定文件夹中，开工吧，所有数据，全量，完整，都存在本地

拍板前的口径（此前已说过两遍）：

> 数据全部存在笔记属性当中，不要 gameshelf.json，图标和图片存在本地指定的文件夹当中

## 做了什么

### 属性侧（全量）

- `成就`：每行 6 段 `显示名 | 描述 | 已解锁 | 解锁日期 | 全球率 | apiname`，
  `steam.ts::achRowText` / `achRowFromText` 一对纯函数负责序列化与反解；
- `截图源`（远端）+ `截图`（本地路径）**同序同长**，下载失败位留空串；
- `成就更新` / `截图更新` / `详情时间` 三个时间戳作为新鲜度与幂等标记。

### 媒体侧（全本地）

- 成就图标 `<appid>-ach-<apiname>-{on,off}.jpg`：**一个属性键都不占**（文件名可推导），
  两色都下、状态翻转零下载；灰图 Steam 没给时界面回落彩色 + CSS 灰度；
- 商店截图 `<appid>-shot-<n>.jpg`：原图前 8 张（`parseStoreMeta` 的 slice 上限）。

### 通道侧

- `GetSchemaForGame` 补 `&l=schinese` → **成就名与描述出中文**（此前一律英文）；
- 解析 `icongray`（未解锁用的灰图）；
- `appdetails` 的截图此前被评审壳的抓取脚本白名单漏掉（先按白名单过滤再判 `screenshots`），已修脚本并重抓。

### 交互侧

- 详情弹窗改「属性优先、零网络」，属性过期时后台静默刷新该项；
- 媒体队列下完图后回调 `M.modalRepaintFn`，弹窗里的图标从占位换成真图（否则要关掉重开）；
- 回填补跑判据扩到四件（商店／成就／截图文件／成就图标文件），各自独立。

## 门禁

  （它们的 `#preview-inputs` 清单里没有本次改动的文件，主仓复跑为绿）；
- `tests/gameshelf` 107 例（新增 `detail.test.ts` 8 例 + 成就属性行 6 例 + 媒体队列 12 例 + 回填判据 3 例）；

  截图段与「截图源」对账 / `截图` 本地路径写回）；
- 真实 Steam 抓取：商店 147/147（**2270 张真截图**）+ 成就 134 款真响应。

## 已知差距（不阻塞，留给下一轮）

- 评审壳罐头里的成就 schema 是**加 `l=schinese` 之前**抓的 → 壳里成就名是英文、且没有 `icongray`
  （界面因此走「彩色 + CSS 灰度」那条兜底）。真机走 `&l=schinese`，出中文名；代理可用时重跑
  `.scratch/refetch-gameshelf-detail.py` 即可补齐壳的罐头。
- 截图本地化体积约 460 MB（8 张原图 ×138 款），已向用户说明；若要压到 ~60 MB 改存
  `path_thumbnail` 即可，改动只在 `steam.ts::parseStoreMeta` 取哪个字段。
