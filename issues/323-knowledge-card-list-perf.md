# 323 · 知识盒「卡片」部切换卡顿：索引缓存 + 增量渲染

- 状态：已交付（2026-09-15）

## 现状与根因

列表本身已有 80 行分页 + 滚动加载（`cardsShown` / `onContentScroll`），卡顿不在首屏渲染：

1. **挂载索引每轮重算**：每次切到「卡片」部都跑 `loadMountIndex()` → `refCounts + orphanCards`
   全库扫描（1503+ 文件逐个出站链解析），这是最大头；
2. **全量 innerHTML 重建**：`moreCards()` 每次多 80 行都把整个列表（含已渲染的几百行）重拼重渲，
   滚动到底反复触发时 O(n²) 抖动。

## 口径

1. 挂载索引按**面板会话缓存**（脏标记：落卡 / 显式刷新才重算），切换部不再整库重扫；
   库内文件变更（vault modify/delete/rename，既有监听）同样置脏——改链 / 改名 / 增删卡即时跟随，
   但切部本身永远不重算；
2. 行渲染改**增量追加**：表头（孤儿芯片 + 总数）与行容器分离，`moreCards()` 只追加新行、原地更新
   「还有 N 张」页脚；徽标落地时原地补丁（querySelector 定位行内徽标位），不再整表 innerHTML；
3. 滚动加载阈值不变（距底 60px），首屏仍 80 行。
