## 现状

river 时间线顶部 `buildNotes`（640 行）规则点评只有「动手早晚几分钟」「连击提醒」两种句式；`home/shared.ts` 纯层渲染是零依赖契约（async 塞不进渲染管线）；首页要求秒开（缓存渲染优先）。

## 方案（按拍板改动）

规则点评先行照常渲染（秒开不阻塞）；当天视图进入后**自动**触发 LLM 细评（输入当天 RiverDay 的 events + summary + streak + counts，数据量小现成），结果**按天缓存**后异步填充到点评区。LLM 不可用/失败 → 静默保留规则点评，无感知降级。

## 落地

- [ ] async 挂 `home/ui.ts` 行为层（纯层 `shared.ts` 零依赖契约不动）；
- [ ] 当日缓存键 = 日期 + counts 签名（数据变化当日重判一次；面板重开/自动刷新命中缓存不重复烧钱）；
- [ ] 填充形态：AI 细评**并列**为「小橘细说」块，规则点评保留不被顶掉（规则点评是拍板过的产品语义）；
- [ ] 移动端同步。

## 测试

缓存命中零调用、失败静默降级、纯层渲染不受影响（冒烟）、移动端。
